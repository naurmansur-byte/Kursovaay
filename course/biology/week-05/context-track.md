15 минут после урока 10. Задание в формате ЕНТ 26–30: прочитай контекст — пепсин и среда — и ответь на четыре вопроса, в каждом один верный ответ. Ответы пришли строкой в Telegram вместе с вариантом A/B/C: `К: 1… 2… 3… 4…`. Решения открывай после попытки.

**Как читать опыт:** что меняли → что было одинаковым → контроль → что показали данные → вывод только в пределах данных.

### Контекст

В четыре пробирки положили одинаковые кусочки варёного яичного белка и поставили на 2 часа при 37 °C. Данные условные.

| Пробирка | Что добавили | Результат |
|---|---|---|
| 1 | пепсин + соляная кислота | белок растворился |
| 2 | пепсин + вода | почти без изменений |
| 3 | соляная кислота без пепсина | без изменений |
| 4 | прокипячённый пепсин + соляная кислота | без изменений |

**1. Один ответ.** В какой пробирке белок переварился?

- А) 2.
- Б) 3.
- В) 1.
- Г) 4.

**2. Один ответ.** Что показывает сравнение пробирок 1 и 2?

- А) Пепсину нужна кислая среда.
- Б) Кислота сама переваривает белок.
- В) Пепсин работает только после кипячения.
- Г) Белок не переваривается при 37 °C.

**3. Один ответ.** Зачем нужна пробирка 3?

- А) Проверить, что пепсин работает без кислоты.
- Б) Показать работу желчи.
- В) Проверить действие 37 °C.
- Г) Проверить, что сама кислота без фермента не переваривает белок.

**4. Один ответ.** Почему в пробирке 4 белок не переварился?

- А) Кислоты мало.
- Б) При кипячении фермент — белок — денатурировал и потерял активность.
- В) Пепсин работает только в щелочной среде.
- Г) Белок был варёный.
