# Сторис-шаблоны, пост для таргета, карусель Threads

Подготовил Макс 13.10.2026. Картинки: `deliverables/stories/`, `deliverables/ads/`, `deliverables/threads/`; пересобрать — `.venv/Scripts/python tools/social/social.py`.

## Шаблоны сторис (1080×1920)

Открыть Instagram → сторис → выбрать шаблон из галереи. Текст писать инструментом «Аа» поверх тёмной карточки: шрифт Strong или Classic, белый, акцент — красный.

| Файл | Для чего | Что добавить в Instagram |
|---|---|---|
| `story-new-reel.png` | Вышел новый рилс | Стикер «Фото» → скрин или обложка рилса → растянуть по красным уголкам. Стикер «Ссылка» на рилс |
| `story-announcement.png` | Объявление | Текст поверх карточки |
| `story-task.png` | Задача дня | Условие поверх карточки; внизу уже написано «ответ — в следующей сторис» |
| `story-answer.png` | Ответ к задаче | Решение поверх карточки |
| `story-question.png` | Вопросы подписчиков | Стикер «Вопросы» под заголовком |
| `story-blank.png` | Всё остальное | Что угодно |

Если нужен текст нашими фирменными шрифтами — пришлите текст Максу, он соберёт готовую сторис.

## Пост для таргета: химия + биология

Файлы: `target-feed-4x5.png` — лента (1080×1350), `target-story-9x16.png` — сторис и Reels (1080×1920, низ свободен под кнопку рекламы).

**Перед запуском проверить:** у биологии те же условия, что у химии (онлайн, группы по 5, старт 1 ноября)? Если нет — сказать Максу, он поправит плашки и текст.

- **Цель кампании:** сообщения (директ Instagram).
- **Основной текст:**

```text
Химия и биология на ЕНТ — это 100 из 140 баллов. Готовим к обоим профильным предметам онлайн, в группах по 5 человек: разбираем каждую тему, решаем задачи в формате теста, проверяем домашние задания.

Старт — 1 ноября. Напиши в директ — расскажем, как устроен курс.
```

- **Заголовок:** `Химия и биология к ЕНТ — онлайн, группы по 5`
- **Кнопка:** «Отправить сообщение».
- **Аудитория:** для подростков Meta разрешает настраивать только возраст и место — Казахстан, 16–17 лет. Отдельно можно взять родителей (35–55 лет, интересы «образование»).
- Без обещаний баллов и без «гарантий» — Meta такое отклоняет, и мы так не пишем.
