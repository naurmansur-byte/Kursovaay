# R002 — формула вещества по продуктам сгорания

Авторская задача повышенной сложности, не задание НЦТ. Подготовил Макс 13.10.2026. Проверка преподавателем ещё не проведена.

**Условие.** При полном сгорании 4,6 г органического вещества получили 8,8 г CO₂ и 5,4 г H₂O. Плотность паров вещества по водороду — 23. Найдите молекулярную формулу.

Варианты: А) C₂H₆ · Б) C₂H₆O · В) CH₄O · Г) C₃H₈.

**Решение**
1. n(C) = n(CO₂) = 8,8 / 44 = 0,2 моль → m(C) = 2,4 г.
2. n(H) = 2 · n(H₂O) = 2 · 5,4 / 18 = 0,6 моль → m(H) = 0,6 г.
3. m(C) + m(H) = 3,0 г < 4,6 г → в веществе есть кислород: m(O) = 1,6 г, n(O) = 1,6 / 16 = 0,1 моль.
4. C : H : O = 0,2 : 0,6 : 0,1 = 2 : 6 : 1 → C₂H₆O.
5. Проверка: M(C₂H₆O) = 24 + 6 + 16 = 46 г/моль; M = 2 · D(H₂) = 2 · 23 = 46 ✓.

**Ответ:** Б) C₂H₆O.

**Ловушка:** не проверить массу и решить, что вещество — углеводород: C : H = 1 : 3 → C₂H₆ (M = 30 ≠ 46).
