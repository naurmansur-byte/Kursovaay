# Проверяем реакцию
= Кислота + основание → соль + вода
- Na₂O, CaO, BaO с водой дают основания; CuO, FeO — нет
- SiO₂ с водой не реагирует; CO и NO — несолеобразующие
- Амфотерные оксиды и гидроксиды: с кислотой и со щёлочью
- Металл левее H + HCl → H₂; HNO₃ — исключение
- Соль + металл в растворе: не брать Li, Na, K, Ca, Ba
= Ca(OH)₂ + CO₂ → CaCO₃↓ + H₂O
! BaSO₄ и AgCl — осадки; H₂CO₃ → CO₂↑ + H₂O
> Cu(OH)₂ → CuO + H₂O — при нагревании

# Факты ЕНТ
- CaO — негашёная известь; Ca(OH)₂ — гашёная
- Известковая вода — раствор Ca(OH)₂, мутнеет от CO₂; CaCO₃ — мел, известняк
- NaCl — поваренная соль; NaHCO₃ — пищевая сода; KMnO₄ — марганцовка
- Н. Н. Бекетов (1863) — ряд активности металлов
- Лакмус: красный / синий / фиолетовый
- Фенолфталеин: бесцветный / малиновый / бесцветный
- Метилоранж: розовый / жёлтый / оранжевый
> Цвета: кислая / щелочная / нейтральная среда
