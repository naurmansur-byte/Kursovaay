# Сначала назови объект
= ω=m вещества/m раствора
= c=n/V раствора; n=cV; m=nM
- Долили воду: вещество то же, раствор больше
- Упарили воду: вещество то же, раствор меньше
- Смешали без реакции: суммы вещества/раствора отдельно
= m чистого=m технического×(1−ω примеси)
= Недостаток: меньшее n/коэффициент
= η=продукт практический/теоретический
! Обратно: теоретический=практический/η

# Факты ЕНТ недели
- Раствор — однородная система
- Растворимость — на 100 г растворителя при данной t
- Твёрдые обычно лучше при нагревании, газы хуже
- Насыщенный≠концентрированный
- Перенасыщенный неустойчив
- Учебные пороги: >10 г; <1 г; <0,01 г на 100 г воды
- ω по массе раствора; c моль/л раствора
- Реакция по чистому веществу и недостатку; выход к продукту
