В каждом наборе G/A/B/C: **8 тестов + 2 задачи в тетради + 1 разбор ошибки**. Общая часть — 35 минут после первого урока; вариант — 30 минут после второго. ДЗ занимает 65 минут, вся самостоятельная работа — 150 минут. В неделе 2 повторение недели 1: G1–G3 и первые три задания выбранного варианта, **6 из 22 = 27,3%**.

Пересчитаны все 64 тестовых ключа, решения и критерии. Учебные баллы: тест 10, тетрадь 8, ошибка 2; 20 за набор, 40 за общую часть и вариант. Ключи P1–P6 сохранены дословно. Нагрузка — план, пока без замера на учениках. Прежние ссылки на G1–G3 и старую структуру в планах уроков нужно согласовать Максу; по T09 эти материалы не менялись.

Памятка: две карточки по восемь строк, PNG 1080×1920. Использованы `cards()` и `card_html()` из штатного `tools/memo/memo.py` и неизменный CSS Макса. В облачной среде изображения получены через Chromium CDP (`node /workspace/scratch/t09-render/render.mjs`); HTML и вспомогательный запуск остались вне Git. PDF собран из этих PNG: две страницы, текст не выделяется. Обе карточки просмотрены; шрифты загружены, обрезки и наложений нет.

Штатная команда пересборки памятки: `python tools/memo/memo.py week-02` (пакет `markdown`, Chrome/Chromium; файлы из `exports/week-02/memo/` и `exports/week-02/memo.pdf` затем копировать сюда).
