## 1. Галогеналканы — связующее звено (Х10-2 § 83–85, с. 145–158)

- **Получение** (с. 145–147):
  - замещение в алканах на свету: C₂H₆ + Cl₂ → C₂H₅Cl + HCl (неделя 17);
  - присоединение HX к алкенам: CH₂=CH₂ + HBr → CH₃–CH₂Br; пропен + HCl → **2-хлорпропан** (правило Марковникова, неделя 18);
  - из спиртов: **ROH + HX → RX + H₂O** (C₂H₅OH + HBr → C₂H₅Br + H₂O; кислая среда).
- **Свойства** (с. 152–155): связь C–Hal полярна (на C — частичный «+»), поэтому галоген замещается.
  - с **водным** раствором щёлочи — **замещение → спирт**: C₂H₅Br + NaOH (вода) → C₂H₅OH + NaBr;
  - со **спиртовым** раствором щёлочи — **отщепление (элиминирование) → алкен**: C₂H₅Br + NaOH (спирт) → CH₂=CH₂ + NaBr + H₂O;
  - **правило Зайцева (1875)**: при отщеплении галогеноводорода водород уходит от соседнего **наименее гидрогенизированного** атома C (2-бром-3-метилбутан → в основном 2-метилбутен-2).
- **Через галогеналкан получают спирт из алкана** (Х10-2 с. 170): C₂H₆ + Br₂ → C₂H₅Br + HBr; C₂H₅Br + H₂O (щёлочь) → C₂H₅OH.
- **Фреоны** — хлорфторуглероды (хладагенты, аэрозоли): на высоте 20–25 км под УФ дают атомы хлора, которые разрушают озон; Монреальский протокол (1987), Нобелевская премия 1995 (Роуланд, Молина, Крутцен) (с. 148–149). Применение галогеналканов: йодоформ CHI₃ — антисептик, фторотан — наркоз, тетрафторэтилен → тефлон (с. 148).

## 2. Спирты: строение, классификация, названия, изомерия (Х9-2 § 63, с. 151–153; Х10-2 § 86, с. 159–161; § 88, с. 168)

- **Спирты** — производные углеводородов, в молекулах которых один или несколько атомов H замещены **гидроксильными группами –OH**; общая формула **ROH**; **предельные одноатомные — CₙH₂ₙ₊₁OH** (Х9-2 с. 151; Х10-2 с. 159). –OH — функциональная группа спиртов и фенолов.
- **По числу –OH:** **одноатомные** (метанол CH₃OH, этанол C₂H₅OH) и **многоатомные**: двухатомные (**этиленгликоль**, этандиол-1,2), трёхатомные (**глицерин**, пропантриол-1,2,3); у многоатомных –OH стоят при разных атомах C (Х10-2 с. 168). **По радикалу:** предельные, непредельные, ароматические (Х10-2 с. 159).
- **По атому C с –OH:** **первичные** (–OH при C, связанном с одним C), **вторичные**, **третичные** (Х10-2 с. 161).
- **Названия:** к названию алкана добавляют **-ол** и номер атома C с –OH; нумерация **с конца, ближнего к –OH**; многоатомные — **-диол, -триол** (Х10-2 с. 160–161, 168). Табл. 59 (с. 160): метанол (метиловый), этанол (этиловый), пропанол-1 (пропиловый), **пропанол-2 (изопропиловый)**, бутанол-1, бутанол-2, 2-метилпропанол-1 (изобутиловый), **2-метилпропанол-2 (третичный бутиловый)**.
- **Изомерия:** углеродного скелета и **положения группы –OH**; у C₄H₉OH — 4 спирта (бутанол-1, бутанол-2, 2-метилпропанол-1, 2-метилпропанол-2) (Х10-2 с. 160–161). Межклассовые изомеры спиртов — **простые эфиры** (неделя 17: этанол и диметиловый эфир).

## 3. Физические свойства спиртов (Х9-2 с. 152–153; Х10-2 с. 161, 169)

- До C₁₂ — жидкости, выше — твёрдые; все легче воды. **Метанол, этанол, пропанол смешиваются с водой в любых соотношениях**; с ростом молекулярной массы растворимость падает (Х10-2 с. 161).
- **Температуры кипения спиртов выше**, чем у алканов с близкой молярной массой, — из-за **водородных связей** между молекулами спирта (и спирта с водой) (Х10-2 с. 161).
- **Метанол** — t кип **64,5 °C**, **очень ядовит**: малая доза вызывает слепоту или смерть. **Этанол** — t кип **78,3 °C**, бесцветная жидкость с характерным запахом (Х9-2 с. 152; Х10-2 с. 161).
- **Этиленгликоль** — вязкая сладкая жидкость, t кип ~198 °C, **очень ядовит**; 60 %-й раствор замерзает при −49 °C → **антифриз**. **Глицерин** — бесцветная сиропообразная сладкая жидкость, t кип 290 °C (Х9-2 с. 153; Х10-2 с. 169).

## 4. Химические свойства одноатомных спиртов (Х9-2 с. 152; Х10-2 § 86, с. 162–163)

- **Кислотные свойства выражены слабо**: водные растворы спиртов **на индикаторы не действуют** (с. 162).
- **С щелочными металлами** (H группы –OH подвижен, связь O–H полярна): **2C₂H₅OH + 2Na → 2C₂H₅ONa + H₂↑** (этилат натрия — алкоголят).
- **С галогеноводородами** (конц. H₂SO₄): C₂H₅OH + HCl → C₂H₅Cl + H₂O.
- **Дегидратация** (конц. H₂SO₄): при сильном нагревании — **внутримолекулярная → алкен**: C₂H₅OH → CH₂=CH₂ + H₂O; при избытке спирта и более низкой температуре — **межмолекулярная → простой эфир**: 2C₂H₅OH → C₂H₅–O–C₂H₅ (диэтиловый эфир) + H₂O.
- **Окисление**: **первичные спирты → альдегиды**, **вторичные → кетоны** (Х11-1 с. 29). Опыт: раскалённая медная спираль, покрытая CuO, в этаноле **становится блестящей**, появляется запах уксусного альдегида: **C₂H₅OH + CuO → CH₃CHO + Cu + H₂O** (Х10-2 с. 163).
- **Горение**: C₂H₅OH + 3O₂ → 2CO₂ + 3H₂O; этанол горит голубоватым слабосветящимся пламенем, бутанол — светящимся (лаб. работа 9, с. 172).
- **Этерификация** (с карбоновыми кислотами, H₂SO₄) → **сложные эфиры** (CH₃COOH + C₂H₅OH → CH₃COOC₂H₅ + H₂O) — подробно в неделе 20.
- Из этанола по Лебедеву — **бутадиен** (неделя 18).

## 5. Получение спиртов; производство этанола (Х9-2 с. 151–152; Х10-2 § 87, с. 164–167; § 88, с. 168–169)

- **Метанол** — из **синтез-газа**: **CO + 2H₂ → CH₃OH** (220–300 °C, 5–20 МПа) (Х9-2 с. 151).
- **Этанол** — первое место по объёму производства среди органических веществ (Х9-2 с. 151):
  - **спиртовое брожение** сахаристых веществ (ферменты дрожжей): **C₆H₁₂O₆ → 2C₂H₅OH + 2CO₂↑**; из крахмала зерна через мальтозу — пищевой спирт; из **целлюлозы** (гидролиз древесины) — **гидролизный спирт** (Х10-2 с. 164–165);
  - **гидратация этилена**: **CH₂=CH₂ + H₂O ⇄ C₂H₅OH + 46 кДж**; 280–300 °C, **7–8 МПа**, катализатор **H₃PO₄** на носителе; реакция обратимая, экзотермическая, идёт с уменьшением числа молекул → давление повышают; побочный продукт — диэтиловый эфир (Х10-2 с. 165–166).
- **Этиленгликоль** — окислением этилена раствором **KMnO₄** (неделя 18); **глицерин** — расщеплением жиров или синтезом из пропилена (Х10-2 с. 168–169).
- **Применение:** метанол — формальдегид, полимеры, растворитель; этанол — синтетический каучук, уксусная кислота, диэтиловый эфир, медицина (дезинфекция), пищевая промышленность; этиленгликоль — **антифриз**, волокно **лавсан**; глицерин — **нитроглицерин** и **динамит**, мази, парфюмерия (Х9-2 с. 153–154; Х10-2 с. 166, 170).
- **Вред этанола:** наркотическое ядовитое вещество; в печени окисляется в **ядовитый уксусный альдегид** (Х10-2 с. 167).

## 6. Многоатомные спирты: свойства (Х10-2 § 88, с. 169–170; лаб. работа 9, с. 172)

- Как одноатомные: с **Na** выделяют H₂, с **HCl** замещают –OH.
- **Качественная реакция на многоатомные спирты:** свежий осадок **Cu(OH)₂** (CuSO₄ + избыток NaOH) с глицерином или этиленгликолем **растворяется** → **ярко-синий раствор** (глицерат меди); показывает, что у многоатомных спиртов **слабые кислотные свойства** (подвижность H растёт с числом –OH) (с. 169).
- **Нитроглицерин** — глицерин + 3HNO₃ (H₂SO₄) → C₃H₅(ONO₂)₃ + 3H₂O; это **сложный эфир** азотной кислоты (название историческое); 1 %-й раствор и таблетки — средство, расширяющее сосуды (с. 169–170).

## 7. Фенол (Х10-2 § 89–90, с. 173–178)

- **Фенолы** — производные аренов, у которых –OH **непосредственно связана с бензольным кольцом**; простейший — **фенол C₆H₅OH**; двухатомные: пирокатехин (1,2), резорцин (1,3), гидрохинон (1,4) (с. 173). Если –OH в **боковой цепи** — это **ароматический спирт** (бензиловый спирт C₆H₅CH₂OH), свойства как у предельных спиртов (с. 173–174).
- **Взаимное влияние атомов** (с. 174, 176): бензольное кольцо делает связь O–H **более полярной** — фенол **кислее спиртов**; группа –OH активирует кольцо в положениях **2, 4, 6**.
- **Физические свойства** (с. 176): бесцветные кристаллы с характерным запахом, на воздухе розовеет (окисление); t пл **40,9 °C**; в холодной воде малорастворим, при 70 °C — неограниченно; **ядовит, вызывает ожоги кожи**.
- **Свойства по группе –OH** (с. 176):
  - как спирты: 2C₆H₅OH + 2Na → 2C₆H₅ONa + H₂↑;
  - **в отличие от спиртов — со щелочами**: **C₆H₅OH + NaOH → C₆H₅ONa + H₂O** (фенолят натрия) — **слабые кислотные свойства**.
- **Свойства по кольцу** (с. 176–177):
  - **с бромной водой** → **2,4,6-трибромфенол** (белый осадок) + 3HBr — легче, чем бензол (без катализатора);
  - нитрование → **2,4,6-тринитрофенол (пикриновая кислота)** — взрывчатое вещество.
- **Качественная реакция:** с **FeCl₃** — **фиолетовое окрашивание** (с. 178); также бромная вода (белый осадок).
- **Получение** (с. 174–175): из **каменноугольной смолы**; **кумольный способ** — из бензола и пропилена через кумол получают **фенол и ацетон** (сейчас почти весь фенол); устаревший — хлорбензол + NaOH при 300 °C и 200 атм.
- **Применение** (с. 178): **фенолформальдегидные смолы** (пластмассы), лекарства, красители, взрывчатые вещества, пестициды, антисептики; раствор фенола — дезинфекция; пирокатехин → адреналин. Фенол ядовит и для человека, и для природы — сточные воды очищают.

## 8. Альдегиды и кетоны: строение, названия, получение (Х11-1 § 6–7, с. 27–31)

- **Карбонильные соединения** содержат группу **C=O**. **Альдегиды** — карбонил связан с атомом **H** и радикалом: **R–CHO** (у формальдегида — с двумя H). **Кетоны** — карбонил связан с **двумя радикалами**: R–CO–R'; простейший — **ацетон** (с. 27–28).
- **Строение:** C=O = **σ + π**, атом C — **sp²**; связь **полярна** (δ+ на C, δ− на O) (с. 28).
- **Названия:** альдегиды — суффикс **-аль**: **метаналь** (формальдегид, муравьиный альдегид) HCHO, **этаналь** (ацетальдегид, уксусный альдегид) CH₃CHO, 2-метилпропаналь; кетоны — суффикс **-он**: **пропанон (ацетон)** CH₃COCH₃, пентанон-2; нумерация с конца, ближнего к C=O (с. 28–29).
- **Изомерия:** у альдегидов — скелета и **межклассовая с кетонами** (C₃H₆O: пропаналь и ацетон); у кетонов — скелета и положения C=O (с. 28).
- **Получение** (с. 29–31):
  - **окисление спиртов**: первичных → альдегиды (CuO, KMnO₄, H₂O₂), вторичных → кетоны; **формальдегид** в промышленности — из метанола и воздуха над раскалённой медью или серебром: 2CH₃OH + O₂ → 2HCHO + 2H₂O;
  - **реакция Кучерова** (HgSO₄): ацетилен → **этаналь**; пропин → **ацетон** (неделя 18);
  - **окисление этилена** кислородом (PdCl₂, CuCl₂) → ацетальдегид — перспективнее, без ртути; пропилен → ацетон;
  - **кумольный способ** → ацетон и фенол.

## 9. Свойства и применение альдегидов и кетонов (Х11-1 § 8, с. 32–34)

- **Физические:** полярные; низшие растворимы в воде; t кип **ниже, чем у спиртов**; **формальдегид** — бесцветный **ядовитый газ** с резким запахом; **формалин** — 35–40 %-й водный раствор формальдегида; остальные альдегиды — жидкости, высшие — твёрдые; ацетон — легколетучая жидкость (с. 32).
- **Восстановление (гидрирование, Ni):** альдегиды → **первичные спирты** (HCHO + H₂ → CH₃OH), кетоны → **вторичные спирты** (с. 32).
- **Окисление альдегидов** (по связи C–H альдегидной группы) → **карбоновые кислоты** (с. 32–33):
  - **«серебряное зеркало»** — с аммиачным раствором Ag₂O при нагревании: **CH₃CHO + Ag₂O → CH₃COOH + 2Ag↓** (налёт серебра) — **качественная реакция на альдегиды**;
  - с **Cu(OH)₂** при нагревании: голубой осадок → жёлтый CuOH → **красный Cu₂O**: CH₃CHO + 2Cu(OH)₂ → CH₃COOH + Cu₂O + 2H₂O.
  - **Кетоны** Ag₂O и Cu(OH)₂ **не окисляются** — так альдегид отличают от кетона.
- **Присоединение** по C=O (нуклеофильное): HCN, NaHSO₃ — только вариант A (с. 33–34).
- **Применение** (с. 34): формальдегид — **фенолформальдегидные смолы**, красители, каучук, взрывчатые вещества; **формалин** — консервирование анатомических препаратов, дубление кожи, дезинфекция; ацетальдегид — получение **уксусной кислоты**; высшие альдегиды (C₇–C₁₆) — парфюмерия; **ацетон** — растворитель лаков и красок.

## 11. Углубление (вариант A и дополнительные слайды)

- **Механизмы для галогеналканов** (Х10-2 § 84–85): нуклеофил и электрофил, субстрат; **Sɴ2** (одна стадия, первичные и вторичные), **Sɴ1** (через карбокатион, третичные); элиминирование E1 и E2; конкуренция замещения и отщепления (водный или спиртовой раствор щёлочи).
- **Почему H фенола подвижнее, чем у спирта** — взаимное влияние фенила и –OH (Х10-2 с. 174, 176); у многоатомных спиртов — влияние соседних –OH (с. 169).
- **Нуклеофильное присоединение к C=O**: HCN → оксинитрилы, NaHSO₃ (Х11-1 с. 33–34).
- **Технология гидратации этилена**: обоснование условий (давление, температура, катализатор), контактный аппарат, параллельная реакция → диэтиловый эфир (Х10-2 с. 165–166) — связь с Ле Шателье (неделя 12).
- **Кумольный способ** — схема: бензол + пропилен (AlCl₃) → кумол → фенол + ацетон (Х10-2 с. 175; Х11-1 с. 30–31).
- **Генетическая цепочка**: метан → ацетилен → бензол → хлорбензол → фенол → 2,4,6-трибромфенол; этан → бромэтан → этанол → этаналь → уксусная кислота.

## 12. Расчёты: правила и образцы (числа новые, пересчитаны Максом)

Правила: по уравнению с учётом стехиометрии (H₂ от спирта: 2 ROH → 1 H₂; от глицерина: 1 моль → 1,5 моль H₂); с выходом и долей вещества в растворе (недели 4–5); вывод формулы (неделя 17); у смеси спирта и фенола — фенол считают по бромной воде, затем спирт по водороду.

1. **Этанол и натрий.** 9,2 г C₂H₅OH (0,20 моль) + избыток Na → H₂ 0,10 моль = **2,24 л**; этилат натрия **13,6 г**.
2. **Дегидратация с выходом.** 23 г этанола (0,50 моль) → C₂H₄ 11,2 л; выход 80 % → **8,96 л**.
3. **Брожение.** 36 г глюкозы (0,20 моль) → C₂H₅OH 0,40 моль = **18,4 г** и CO₂ **8,96 л**.
4. **Глицерин и натрий.** 9,2 г глицерина (0,10 моль) + Na → H₂ 0,15 моль = **3,36 л** (2C₃H₅(OH)₃ + 6Na → 2C₃H₅(ONa)₃ + 3H₂).
5. **Фенол и бромная вода.** 9,4 г фенола (0,10 моль) → 2,4,6-трибромфенол (M = 331) **33,1 г**; брома 0,30 моль = **48 г**.
6. **Фенол и щёлочь.** 4,7 г фенола (0,050 моль) + NaOH → фенолят натрия **5,8 г**; NaOH **2,0 г**.
7. **Смесь этанола и фенола.** С Na — 3,36 л H₂ (0,15 моль); с бромной водой — 16,55 г трибромфенола (0,050 моль) → фенол **4,7 г**, от него H₂ 0,025 моль; от спирта H₂ 0,125 моль → этанол 0,25 моль = **11,5 г**.
8. **Серебряное зеркало.** 4,4 г этаналя (0,10 моль) → Ag 0,20 моль = **21,6 г**; уксусной кислоты **6,0 г**.
9. **Альдегид и Cu(OH)₂.** 2,9 г пропаналя (0,050 моль) → Cu₂O 0,050 моль = **7,2 г**.
10. **Окисление спирта CuO с выходом.** 11,5 г этанола (0,25 моль) → этаналь теоретически 11,0 г; получено 8,8 г → выход **80 %**.
11. **Формалин.** 6,4 г метанола (0,20 моль) → HCHO 6,0 г → 40 %-го формалина **15 г**.
12. **Формула карбонильного соединения.** D(H₂) = 29 → M = 58 → **C₃H₆O**: пропаналь (альдегид, даёт серебряное зеркало) или ацетон (кетон, не даёт).
13. **Кучеров с выходом.** 5,6 л C₂H₂ (0,25 моль) → этаналь 11,0 г; выход 90 % → **9,9 г**.
14. **Гидрирование кетона.** 2,9 г ацетона (0,050 моль) + H₂ → пропанол-2 **3,0 г** (вторичный спирт).

## Факты ЕНТ недели (из учебников)

Спирты ROH, предельные одноатомные CₙH₂ₙ₊₁OH; первичные, вторичные, третичные · метанол — очень ядовит (слепота), t кип 64,5 °C; этанол — 78,3 °C · спирты кипят выше алканов — водородные связи · 2C₂H₅OH + 2Na → 2C₂H₅ONa + H₂; растворы спиртов индикатор не меняют · дегидратация: сильный нагрев → этилен, избыток спирта → диэтиловый эфир · первичный спирт → альдегид, вторичный → кетон; CuO — медная спираль блестит · метанол из CO + 2H₂; этанол — брожение глюкозы и гидратация этилена (H₃PO₄, 7–8 МПа) · этиленгликоль — антифриз, лавсан; глицерин — нитроглицерин, динамит · Cu(OH)₂ + глицерин → ярко-синий раствор · фенол C₆H₅OH: реагирует с NaOH (спирты — нет); бромная вода → белый осадок 2,4,6-трибромфенола; FeCl₃ — фиолетовый · кумольный способ → фенол + ацетон · альдегиды R–CHO (-аль), кетоны R–CO–R' (-он); формалин 35–40 % · серебряное зеркало и Cu(OH)₂ → красный Cu₂O — альдегиды, кетоны нет · альдегид + H₂ → первичный спирт, кетон + H₂ → вторичный · Кучеров: ацетилен → этаналь, пропин → ацетон · фреоны разрушают озон; водная щёлочь → спирт, спиртовая → алкен (Зайцев).

## Что легко перепутать (по учебникам)

- **Фенол ≠ ароматический спирт:** у фенола –OH прямо на кольце (реагирует с NaOH, бромной водой, FeCl₃); у бензилового спирта — в боковой цепи (как обычный спирт).
- **Со щёлочью реагирует фенол, а не этанол;** с натрием — оба.
- **Многоатомные спирты с Cu(OH)₂ — ярко-синий раствор без нагревания; альдегиды с Cu(OH)₂ — красный осадок Cu₂O при нагревании.**
- **Серебряное зеркало — альдегиды;** кетоны (ацетон) не дают.
- **Первичный спирт → альдегид, вторичный → кетон;** обратно: альдегид + H₂ → первичный, кетон + H₂ → вторичный.
- **Внутримолекулярная дегидратация → алкен** (сильный нагрев); **межмолекулярная → простой эфир** (избыток спирта, ниже температура).
- **Галогеналкан + водная щёлочь → спирт; + спиртовая щёлочь → алкен.**
- **Правило Марковникова — присоединение к алкенам; правило Зайцева — отщепление (H уходит от менее гидрогенизированного C).**
- **Метаналь = формальдегид = муравьиный альдегид; этаналь = ацетальдегид = уксусный альдегид; пропанон = ацетон.**
- **Формалин — раствор (35–40 %) формальдегида**, а не сам газ.
- **C₃H₆O — пропаналь и ацетон** (межклассовые изомеры); **спирты и простые эфиры** — тоже межклассовые изомеры.
- **Нитроглицерин — сложный эфир**, хотя назван «нитро-».
- **Метанол и этиленгликоль ядовиты;** глицерин — нет (мази, пищевая промышленность).
- **Брожение — из глюкозы этанол + CO₂;** гидратация этилена — этанол без CO₂.
