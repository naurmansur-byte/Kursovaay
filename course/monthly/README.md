# Проверка знаний за месяц — Google Формы

**Черновик, ждёт проверки преподавателя.** Задания авторские, по конспектам недель курса (учебники НЦТ). Это не задания НЦТ. Пробники недель и проверку понимания не повторяют.

## Как проводить

- **Когда:** в конце каждой четвёртой недели, около 40 минут. Ссылку на форму преподаватель кидает в чат группы.
- **Что внутри:** по 5 заданий на неделю в формате ЕНТ: 3 с одним ответом (1 балл), соответствие из двух пар (по 1 баллу за пару), несколько ответов — 3 верных из 6 (2 балла; в Форме только за полностью верный выбор). 7 баллов на неделю, 28 за месяц.
- **Что видит ученик:** после отправки — баллы, ошибки, верные ответы и объяснения.
- **Что видит преподаватель:** в таблице ответов лист «По неделям»: баллы каждого ученика по каждой неделе (зелёный 6–7, жёлтый 4–5, красный 0–3). Неделю, где у группы много красного, повторяем.

## Где лежит

Папка «4 Проверка знаний за месяц» в «ХимБио просто» на Google Диске. Генератор — `tools/forms/monthly.py` → `monthly.gs`, функция `createMonthlyChecks` в проекте Apps Script «ХимБио — стартовый тест (формы)».
