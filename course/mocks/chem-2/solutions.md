## 1–25

**1 — А.** Тема 01, нед. 6. 19 электронов — калий; 4s заполняется раньше 3d. Ошибка: принять 4s¹ за кальций (у него 4s²).

**2 — Б.** Тема 01, нед. 7. CaO — металл и неметалл, связь ионная; HCl и NH₃ — ковалентная полярная, Cl₂ — неполярная.

**3 — Г.** Тема 02, нед. 6. Вниз по группе радиус растёт, внешние электроны удерживаются слабее — металличность усиливается.

**4 — В.** Тема 03, нед. 9. K +1, O −2: +1 + x + 4 · (−2) = 0 → x = +7.

**5 — А.** Тема 03, нед. 10. Na⁺ из раствора не восстанавливается — на катоде H₂ из воды; Cl⁻ окисляется — на аноде Cl₂; в растворе остаётся NaOH. Ошибка: «натрий» — так только из расплава.

**6 — Г.** Тема 04, нед. 11. v = k · c²(NO) · c(O₂); при росте c(NO) в 3 раза — 3² = 9. Ошибка: забыть показатель степени 2.

**7 — Б.** Тема 04, нед. 12. Слева 2 моль газов, справа 1 — повышение давления смещает вправо; прямая реакция экзотермическая — нагревание смещает влево; катализатор не смещает.

**8 — В.** Тема 05, нед. 8. NH₄NO₃ — соль слабого основания и сильной кислоты: гидролиз по катиону, среда кислая. K₂S — щелочная; Na₂SO₄ и KCl не гидролизуются.

**9 — А.** Тема 06, нед. 13. Активные металлы (IA, IIA, Al) получают только электролизом расплавов; из раствора выделился бы водород.

**10 — Г.** Тема 07, нед. 13. Сода осаждает ионы Ca²⁺ и Mg²⁺ — устраняет обе жёсткости; кипячение — только временную (гидрокарбонаты).

**11 — В.** Тема 08, нед. 15. SiO₂ реагирует с HF — так травят стекло; с другими кислотами SiO₂ не реагирует.

**12 — Г.** Тема 09, нед. 15. Нитраты от Mg до Cu разлагаются до оксида металла, NO₂ и O₂: 2Cu(NO₃)₂ → 2CuO + 4NO₂ + O₂. Нитриты дают нитраты K и Na, металл — нитраты Ag и Hg.

**13 — Б.** Тема 10, нед. 16. Ba²⁺ + SO₄²⁻ → BaSO₄ — белый осадок, практически нерастворимый. AgNO₃ — реактив на галогенид-ионы.

**14 — В.** Тема 11, нед. 16. Cl₂ + 2NaOH (хол.) → NaCl + NaClO + H₂O — гипохлорит (жавелевая вода). Хлорат образуется в горячей щёлочи.

**15 — А.** Тема 12, нед. 14. 2 · (+1) + 2x + 7 · (−2) = 0 → x = +6; K₂Cr₂O₇ — сильный окислитель.

**16 — Г.** Тема 13, нед. 17. Изомеров: C₄ — 2, C₅ — 3, C₆ — 5, C₇ — 9.

**17 — А.** Тема 13, нед. 18. Ацетилен + вода (HgSO₄, Кучеров) → уксусный альдегид; этилен + вода → этанол.

**18 — В.** Тема 14, нед. 19. Фенол реагирует со щёлочью (спирты — нет) и с бромной водой даёт белый осадок; бензол бромную воду не обесцвечивает.

**19 — Г.** Тема 14, нед. 20. Эфир называют по спирту и кислоте: метанол + уксусная кислота → метилацетат CH₃COOCH₃.

**20 — Б.** Тема 15, нед. 21. Сахароза → глюкоза + фруктоза; лактоза → глюкоза + галактоза.

**21 — А.** Тема 16, нед. 21. Биуретовая реакция — на пептидные связи, фиолетовая, её дают все белки; ксантопротеиновая — жёлтая, только при бензольных кольцах.

**22 — В.** Тема 17, нед. 22. Полимеризация винилхлорида → ПВХ; тефлон — из CF₂=CF₂.

**23 — Б.** Тема 18, нед. 5, 20. CH₃COOH + C₂H₅OH ⇄ CH₃COOC₂H₅ + H₂O. n(C₂H₅OH) = 46 : 46 = 1 моль → теоретически эфира 1 моль = 88 г; выход 35,2 : 88 = 0,4 = 40 %. Ошибка: 35,2 : 46 = 76,5 % — масса продукта поделена на массу спирта.

**24 — Г.** Тема 19, нед. 22. n(CO₂) = 4,4 : 44 = 0,1 моль → C 1,2 г; n(H₂O) = 2,7 : 18 = 0,15 моль → H 0,3 моль, 0,3 г. m(O) = 2,3 − 1,2 − 0,3 = 0,8 г → 0,05 моль. C : H : O = 0,1 : 0,3 : 0,05 = 2 : 6 : 1 → C₂H₆O; M = 23 · 2 = 46 г/моль — совпадает. Ошибка: CH₂O₂ тоже 46 г/моль, но не подходит по числу атомов C и H.

**25 — В.** Тема 18, нед. 23. n(H₂) = 13,44 : 22,4 = 0,6 моль. x моль Mg, y моль Al: 24x + 27y = 12,6; x + 1,5y = 0,6. x = 0,6 − 1,5y → 14,4 − 36y + 27y = 12,6 → y = 0,2; x = 0,3. Mg 0,3 · 24 = 7,2 г; Al 5,4 г. Ошибка: 5,4 г — масса алюминия.

## 26–30. Контекст

**26 — Б.** Тема 09, нед. 15. Аммиак окисляют до NO на платино-родиевом катализаторе; без катализатора он горит до N₂. Fe — синтез аммиака, V₂O₅ — окисление SO₂.

**27 — А.** Тема 04, нед. 12. Охлаждение увеличивает выход, но реакция идёт слишком медленно — выбирают 450–500 °C; число молей газов от температуры не зависит.

**28 — Г.** Тема 18, нед. 5, 12. N₂ → 2NH₃: n(N₂) = 56 т : 28 = 2 Ммоль → NH₃ 4 Ммоль = 68 т теоретически; выход 34 : 68 = 50 %. Ошибки: 25 % — без коэффициента 2; 60,7 % — 34 : 56, массы разных веществ.

**29 — В.** Тема 18, нед. 23. Схема NH₃ → HNO₃: n(NH₃) = 34 т : 17 = 2 Ммоль → HNO₃ 2 Ммоль = 126 т теоретически; 126 · 0,95 · 0,90 = 107,73 т. Ошибки: 126 т — без выходов; 119,7 и 113,4 т — учтён только один выход.

**30 — Г.** Тема 03, нед. 9, 15. В NH₃ азот −3, в NO +2 — азот окисляется, NH₃ — восстановитель; кислород 0 → −2 восстанавливается.

## 31–35

**31 — БЕ.** Тема 05, нед. 8. KOH — щёлочь, HNO₃ — сильная кислота: сильные электролиты. CH₃COOH и H₂S — слабые; сахароза и этанол — неэлектролиты.

**32 — АГ.** Темы 06, 07, нед. 13. Al и Mg активны — их получают электролизом расплавов. Fe — восстановлением углём и CO; Cu — разными способами, в том числе электролизом растворов; Ag и Au встречаются самородными.

**33 — БГД.** Тема 13, нед. 18. Бромную воду обесцвечивают кратные связи: пропен, бутадиен-1,3, пропин. Пропан и полиэтилен — предельные, бензол бромную воду не обесцвечивает.

**34 — АВД.** Темы 14, 15, нед. 19, 21. Зеркало дают альдегидные группы: формальдегид, глюкоза, пропаналь. Уксусная кислота альдегидной группы не имеет (в отличие от муравьиной), фруктоза — кетоноспирт, ацетон — кетон.

**35 — ВЕ.** Темы 09, 11, нед. 15–16. В: концентрированная HNO₃ с медью — бурый NO₂. Е: F > Cl > Br > I. А — с соляной кислотой железо даёт FeCl₂; Б — горячая щёлочь даёт хлорат; Г — валентность азота IV, степень окисления +5; Д — нитрат серебра разлагается до металла.

## 36–40

**36 — А3 Б4.** Тема 01, нед. 7. K₂O — металл и неметалл, ионная; HBr — разные неметаллы, ковалентная полярная.

**37 — А3 Б2.** Тема 03, нед. 10. Br⁻ окисляется — на аноде Br₂; SO₄²⁻ не окисляется — на аноде O₂ из воды. H₂ выделяется на катоде, SO₂ при электролизе не образуется.

**38 — А2 Б1.** Темы 12, 07, нед. 8, 14. Fe³⁺ с роданидом — кроваво-красное окрашивание; Cu²⁺ со щёлочью — голубой осадок Cu(OH)₂. BaCl₂ — на SO₄²⁻; жёлтый осадок с AgNO₃ — I⁻.

**39 — А2 Б4.** Темы 14, 16, нед. 22. –CHO — альдегиды; –OH — спирты. –NH₂ — амины, –COOH — карбоновые кислоты.

**40 — А2 Б1.** Тема 17, нед. 22. Лавсан — полиэфир, поликонденсация с выделением воды; полистирол — полимеризация стирола. Вулканизация — путь от каучука к резине, крекинг — переработка нефти.
