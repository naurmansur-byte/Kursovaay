# Название ↔ формула

- Алканы CₙH₂ₙ₊₂; M = 14n + 2. CₙH₂ₙ — алкены и циклоалканы.
- Метан, этан, пропан, бутан, пентан, гексан, гептан, октан, нонан, декан.
- Радикалы: -ан → -ил: метил, этил, пропил, бутил.
= Главная цепь — самая длинная; нумерация — с конца, ближе к разветвлению
- Заместители — по алфавиту, одинаковые — ди-, три-; сумма номеров — наименьшая.
- Гомологи — разница CH₂; изомеры — одна формула, разное строение.
- Тип атома C — по числу соседних атомов C: 1, 2, 3, 4.
! «2-этилбутан» — это 3-метилпентан; «3-метилбутан» — это 2-метилбутан.

# Факты ЕНТ недели

- Органическая химия — Берцелиус, 1807; C четырёхвалентен, sp³, 109°28′, цепь — зигзаг.
- Изомеров: C₄ — 2, C₅ — 3, C₆ — 5, C₇ — 9; разветвлённый кипит ниже.
- C₁–C₄ — газы, C₅–C₁₅ — жидкости; метан — болотный и рудничный газ, без запаха.
- Свет: CH₃Cl → CH₂Cl₂ → CHCl₃ (хлороформ) → CCl₄, на каждой ступени HCl.
- 1000 °C: CH₄ → C + 2H₂; 1500 °C: 2CH₄ → C₂H₂ + 3H₂; синтез-газ — CO + H₂.
- Метан в воздухе взрывается при 5–15 %; CH₄ : O₂ = 1 : 2 — сильный взрыв.
- C₃, C₄ — газы, раскрываются; C₅, C₆ — замещение; циклогексан → бензол + 3H₂.
- Нафтены выделил Марковников; циклопропан — наркоз; фреоны разрушают озон.
