# Итоги диагностической недели

Скопировать только раздел «Отчёт» на одну страницу, заполнить поля и убрать подсказки в квадратных скобках. В каждой ячейке оставлять короткую фразу; пример в отправляемый отчёт не включать. В каждой строке оставить один подтверждённый навык и одну ближайшую трудность. Баллы, уровни и рекомендации сверить с ключами [химии](teacher.md) и [биологии](../biology/diagnostic/teacher.md); суммы не округлять. Пример ниже — отдельный образец заполнения.

## Пример

Баллы и ошибки условные; пример не описывает реального ученика.

**27 октября 2026**  
Химия — **17/28, уровень B**. Биология — **23,5/28, уровень C**.  
A — база устойчива; B — нужна адресная практика; C — нужна поддержка основы.

**Химия**

| Блок | Балл / максимум | Уровень | Что получается / что подтянуть |
|---|---:|:---:|---|
| Математика | 3,5 / 4 | A | Находит процент / проверить отношение части к целому. |
| Частицы и запись | 4 / 5 | A | Читает формулы / отдельно отличить индекс от заряда. |
| Валентность | 2,5 / 4 | B | Составляет простые формулы / проверить валентность без знака. |
| Уравнивание | 2 / 5 | C | Считает атомы в простом случае / менять коэффициенты, сохраняя индексы. |
| Классы веществ | 3 / 5 | B | Узнаёт часть классов / различать все четыре класса по составу. |
| Молярная масса и количество вещества | 2 / 5 | C | Находит отдельные молярные массы / выбирать действие для перехода между массой и количеством. |

**Биология**

| Блок | Балл / максимум | Уровень | Что получается / что подтянуть |
|---|---:|:---:|---|
| Математика | 1,75 / 4 | C | Находит процент / повторить отношения и перевод мм в мкм. |
| Клетка | 4,5 / 5 | A | Различает типы клеток / объяснить функции структур без подсказки. |
| Вещества клетки | 3,75 / 4 | A | Связывает вещества с их ролью / точнее объяснить роль фермента. |
| Питание | 4,5 / 5 | A | Различает питание растения и человека / закрепить роли органов пищеварения. |
| Дыхание и транспорт | 4,5 / 5 | A | Узнаёт пути переноса веществ / объяснить направление по новой схеме. |
| Схемы и график | 4,5 / 5 | A | Читает точки графика / ограничивать вывод показанными данными. |

**Конкретные ошибки**

1. Химия, №13: валентность записана со знаком, как заряд. Здесь нужна римская цифра без «+» или «−».
2. Химия, №14: для равенства атомов изменён индекс воды. Формула воды остаётся H₂O; менять нужно числа перед формулами.
3. Химия, №26: при поиске массы количество вещества разделено на молярную массу. Нужно умножить: 0,25 × 44 = 11 г.
4. Биология, №3: 0,012 мм переведены в 0,12 мкм. В миллиметре 1000 мкм, поэтому 0,012 × 1000 = 12 мкм.

**С чего начинаем**

- **Химия, ДЗ B с поддержкой слабых блоков:** 1) на теме уравнивания посчитать атомы до и после реакции, затем подобрать коэффициенты в трёх простых уравнениях; 2) на теме количества вещества повторить чтение формул, найти две молярные массы и выполнить три перехода между массой и количеством. Проверить каждый навык новыми условиями.
- **Биология, ДЗ C:** 1) назвать целое в задаче на отношение и отдельно перевести мм в мкм по образцу; 2) решить новые задачи на эти два действия без опоры и объяснить выбор действия. При подтверждении навыка уточнить уровень ДЗ.

Это стартовая карта знаний, а не прогноз балла ЕНТ.

Проверка уровней примера: химия — 3,5 + 4 + 2,5 + 2 + 3 + 2 = 17; входные блоки не ниже 50 %, условие C не выполнено, до 22,4 балла не хватает → B. Биология — 1,75 + 4,5 + 3,75 + 4,5 + 4,5 + 4,5 = 23,5; математика ниже 2 из 4 → C по первому правилу. Условия проверены в порядке C → A → B, без округления.
