# Таблица распознавания

- I₂ → синее окрашивание: крахмал.
- Cu(OH)₂ без нагревания → ярко-синий раствор: глюкоза, сахароза, глицерин.
- Cu(OH)₂ при нагревании → красный Cu₂O: глюкоза; сахароза — только после гидролиза.
- Ag₂O (NH₃), t → серебряное зеркало: глюкоза; сахароза и крахмал — нет.
- NaOH + CuSO₄ → фиолетовая: белки. Конц. HNO₃ → жёлтая: белки с бензольными кольцами.
- Бромная вода → белый осадок: анилин и фенол. Лакмус синий — предельные амины; анилин — нет.
= Глюкоза — альдегидоспирт; фруктоза — кетоноспирт
! Полисахарид считай по звену C₆H₁₀O₅ = 162; брожение: 1 глюкоза → 2 этанола + 2 CO₂.

# Процессы

- Гидролиз — расщепление водой: сахароза → глюкоза + фруктоза; крахмал → глюкоза; белок → аминокислоты.
- Брожение: спиртовое → этанол + CO₂; молочнокислое → молочная кислота.
- Поликонденсация: глюкоза → крахмал; аминокислоты → пептид + вода.
- Денатурация — разрушение формы белка, первичная структура цела.
- Восстановление: глюкоза → сорбит; нитробензол → анилин (Зинин, 1842).
= CH₄ → C₂H₂ → C₆H₆ → C₆H₅NO₂ → C₆H₅NH₂
! В n-пептиде n − 1 пептидных связей; ClCH₂COOH + 2NH₃ → глицин + NH₄Cl.

# Факты ЕНТ недели

- Моносахариды не гидролизуются; глюкоза и фруктоза C₆H₁₂O₆ — изомеры.
- Сахароза, мальтоза, лактоза — C₁₂H₂₂O₁₁; сахароза зеркала не даёт.
- Крахмал — α-глюкоза, ветвится; целлюлоза — β-глюкоза, линейна.
- Пироксилин — тринитрат целлюлозы, сложный эфир; ацетатный шёлк.
- Анилин слабее аммиака; предельные амины сильнее аммиака.
- Аминокислоты амфотерны; пептидная связь –CO–NH–.
- Белок: первичная — пептидные, вторичная — водородные, третичная — –S–S–, четвертичная — гемоглобин.
- Ферменты — белки; оптимум около 40 °C; пепсин pH 1,5–2; каталаза: 2H₂O₂ → 2H₂O + O₂.
