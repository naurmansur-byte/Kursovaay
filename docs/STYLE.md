# Единый почерк курса «Химия просто»

Правила для всех учебных материалов: их соблюдают Мартин и Макс, чтобы курс выглядел и читался как написанный одним автором. Образец — `course/week-01/`, структура — `course/LESSON_KIT_TEMPLATE.md`. При расхождении действует этот документ.

## Голос

- Обращение к ученику на «ты», к преподавателю — нейтрально («объяснить», «проверить»).
- Коротко и по делу: одна мысль — одно предложение. Без «воды», шуток в учебном тексте и восклицаний.
- Порядок объяснения всегда один: **почему → алгоритм → разные примеры → ловушка → самостоятельно**.
- Не обещаем балл, не называем авторские задачи заданиями НЦТ, не пишем частоту тем на ЕНТ без выборки.

## Чтобы не было видно, что писал ИИ

Образец голоса — `course/week-01/notes-student.md` (переписан Максом 13.10.2026).

- **В ученических материалах нет служебных пометок:** «черновик», «ждёт проверки», «авторский комплект», «страница N из 4», источники, оговорки для проверяющих. Всё это — только в `README.md` недели и в материалах преподавателя.
- **В материалах преподавателя — тоже без кухни разработки:** не упоминать Макса, Мартина, агентов, задания T…, Google Диск, «не создано», «проверено при разработке». Преподавателю нужно: что делать на уроке, ответы, критерии, типичные ошибки. Пакет для преподавателя собирает `tools/teacher_pack.py` (он же вычищает старые пометки в копиях).
- **Без перестраховок.** Не пишем «здесь мы не составляем формулу и не описываем реакцию» — просто объясняем то, что нужно сейчас.
- **Короткие фразы, живые связки:** «Прочитаем 3H₂O», «Что больше: 0,7 г или 650 мг?», «Итого…». Вопрос к ученику лучше длинного пояснения.
- **Абзац — 2–4 строки.** Таблица — только там, где действительно сравнение; не больше одной подряд.
- **Правила, ловушки и разборы — в блоки** (см. ниже), а не внутри длинного текста.

## Разметка для раздаток

Конспект, работа до урока, ДЗ и контроль собираются в оформленный PDF скриптом `tools/handout/handout.py`. Он понимает:

```markdown
---
week: 1
title: Как читать химическую запись
subtitle: Конспект к урокам 1–2 · прочитай до первого урока, это около 25 минут
---

> [!rule] Запомни
> Правило или определение.

> [!trap] Ловушка
> Типичная ошибка и как её избежать.

> [!example] Разберём
> Разобранный пример, строка за строкой.

> [!try] Попробуй
> Задание или самопроверка.
```

Заголовок `#` рисует шапка из `title`, разделы — `##`.

## Обозначения

- Индекс — справа снизу, заряд — справа сверху, коэффициент — перед формулой: `3H₂O`, `Ca²⁺`, `SO₄²⁻`, `2Ca(OH)₂`. В Markdown — Unicode-индексы; в роликах — KaTeX.
- Величины: `n` — количество вещества (моль), `m` — масса (г), `M` — молярная масса (г/моль), `V` — объём (л), `Vₘ` — молярный объём, `ω` — массовая доля, `N` — число частиц, `Nₐ` — постоянная Авогадро.
- Десятичная запятая: `0,5`; единицы через неразрывный пробел: `49 г`, `98 г/моль`.
- Атомные массы — школьные округлённые: H 1, C 12, N 14, O 16, Na 23, Mg 24, Al 27, S 32, Cl 35,5, K 39, Ca 40, Fe 56, Cu 64, Zn 65.
- Условия: «н. у.» только для газов, с явным `Vₘ = 22,4 л/моль`.

## Задания

- ID: `P1…` (до урока), `L1…` (урок), `G1…` (общее ДЗ), `A1/B1/C1…` (варианты ДЗ), `Q1…` (контроль), `R1…` (рубеж), `E1…` (пробник).
- Уровни A/B/C совпадают со смыслом уровней диагностики T02: A — углубление, B — закрепление, C — поддержка.
- У каждого задания: условие с единицами, ответ, полное решение, типичная ошибка. В одиночном выборе ровно один верный вариант; варианты А, Б, В, Г.
- Форматы как в ЕНТ: один ответ, несколько ответов, соответствие, контекст.
- Происхождение: «авторское» или точная ссылка на официальный образец.

## Презентации

- Источник — `slides-outline.md` урока: для каждого слайда блоки «Текст ученику», «Заметки преподавателю», «Раскрытие ответа».
- На слайде не больше 20 строк; одна мысль на слайд.
- PowerPoint собирается **только** скриптом `tools/export_lesson_kit.py` (внутри — `tools/slides/slides.py`): слайды рисуются в браузере и кладутся в PPTX картинками с заметками, поэтому выглядят одинаково в любом PowerPoint, Google Slides и Meet. Обложка недели — автоматически из `README.md`; «Раскрытие ответа» — отдельный тёмный слайд после задания; строки «Ловушка: …», «Задание: …», «Вопрос: …» уходят в блоки внизу слайда. Внешний вид задаёт Макс (стиль 2).
- Правка презентации = правка `slides-outline.md` и повторный экспорт; вручную в PowerPoint не править.
- Готовые файлы — `deliverables/TNN/`.

## Порядок недели — сначала урок (решение Мансура 13.10.2026)

1. **Урок 1** — новая тема с нуля по презентации, практика, короткая проверка. Предварительного чтения не требуем.
2. **После урока 1** — конспект (повторить урок), закрепление (бывшая «работа до урока», файл `pre-work.md`) со своими вопросами, общая часть ДЗ.
3. **Урок 2** — вопросы учеников → повторение → разбор ДЗ → практика в формате ЕНТ → контроль.
4. **После урока 2** — вариант ДЗ A/B/C и исправление ошибок.

В текстах для ученика: «прочитай после урока», «закрепление после урока 1», а не «до урока».

## ДЗ для онлайна (решение Мансура 13.10.2026)

Курс онлайн: ученики ничего не распечатывают. Поэтому в ДЗ **нет таблиц для заполнения, граф и «впиши в клетку»**.

- **Часть 1 — тест в формате ЕНТ**, 8–10 заданий: один ответ (А–Г), несколько ответов, соответствие. Ответ — одной строкой в Telegram: `1В 2Б 3АВ 4: А2 Б1 В3`. Строку-образец давать в начале ДЗ.
- **Часть 2 — 2–3 задачи с решением** в тетради; фото решения — преподавателю в Telegram. Только там, где важен ход решения.
- **«Найди ошибку»** — одно задание: показан неверный ход решения, ученик одной-двумя фразами (или голосовым) объясняет ошибку.
- В каждом задании сказано, **в каком виде прислать ответ**. Условие — коротко, без длинных инструкций.
- Варианты A/B/C сохраняются; у каждого та же структура.
- Файл `homework.md` с `format: phone` в front matter собирается в PDF под экран телефона.

## Памятка недели

Файл `memo.md` → 1–2 вертикальные карточки 1080×1920 (`tools/memo/memo.py`): ученик сохраняет в галерею; годятся и для сторис Instagram. Образец — `course/week-01/memo.md`.

- Карточка — `# Заголовок`; внутри: `= формула или правило крупно`, `- пункт`, `! ловушка`, `> мелкое примечание`.
- Только главное: 6–9 строк на карточку, без объяснений — объяснения в конспекте.

## Нагрузка

- Урок 90 минут; урок II = 20 минут повторения + 70 минут (ДЗ, практика, контроль).
- Самостоятельная работа за неделю — 120–180 минут, посчитать по таблице.
- В каждом ДЗ 20–30 % заданий — повторение прошлых недель (возврат через неделю и через месяц).
