## Результат и граница

Ученик различает n/m/M/N/V, Mr/M, моль молекул/атомов, относительную/обычную плотность. Переводит массу, число частиц и газовый объём при н. у. в моль, составляет коэффициентную пропорцию, вычисляет массу/объём результата. Знает определения, законы, константы и условия их применения.

Разделы 1–5 выжимки — база, объясняются с нуля на уроке 7. Раздел 6 — вариант A с короткой опорой и два необязательных блока в конце урока 7 вместо повторения 84–88 минуты. Доли растворов, примеси, выход, избыток, молярная концентрация — следующие темы; газы только при н. у. Без уравнения состояния.
