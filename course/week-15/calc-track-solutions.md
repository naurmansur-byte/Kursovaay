# Неделя 15. Расчётный трек — решения

Проверить вместе с вариантом A/B/C после урока 30. Задачи авторские тренировочные; баллы трека учебные и не входят в 34 балла ДЗ. 2 балла — верная модель, ход и ответ; 1 — верная модель и одна вычислительная ошибка; 0 — неверная модель или нет решения. Если задачу не решила половина группы, разобрать её на ближайшем уроке в блоке вопросов.

### Задача 1 — 2 балла

**Ответ:** Na₂CO₃ 5,3 г и NaHCO₃ 8,4 г.

**Решение:** n(NaOH) = 0,2 моль, n(CO₂) = 0,15 моль; отношение 0,2 : 0,15 = 1,33 — между 1 и 2, образуются обе соли. x — Na₂CO₃, y — NaHCO₃: по натрию 2x + y = 0,2; по углероду x + y = 0,15 → x = 0,05; y = 0,1. m(Na₂CO₃) = 0,05 × 106 = 5,3 г; m(NaHCO₃) = 0,1 × 84 = 8,4 г.

Типичная ошибка: Выбирать соль по массам веществ. Коррекция: соль определяет отношение количеств.

### Задача 2 — 2 балла

**Ответ:** 1,12 л O₂; 9,8 г H₂SO₄.

**Решение:** n(Cu) = 6,4 : 64 = 0,1 моль. По уравнению n(O₂) = 0,05 моль → 1,12 л; n(H₂SO₄) = 0,1 моль → 9,8 г.

Типичная ошибка: Взять O₂ 1 : 1 с медью — 2,24 л. Коррекция: на 2 Cu — 1 O₂ (4 электрона).
