# Неделя 8. Расчётный трек — решения

Проверить вместе с вариантом A/B/C после урока 16. Задачи авторские тренировочные; баллы трека учебные и не входят в 34 балла ДЗ. 2 балла — верная модель, ход и ответ; 1 — верная модель и одна вычислительная ошибка; 0 — неверная модель или нет решения. Если задачу не решила половина группы, разобрать её на ближайшем уроке в блоке вопросов.

### Задача 1 — 2 балла

**Ответ:** ω(NaCl) = 6,0 %.

**Решение:** m(Na₂CO₃) = 53 × 0,20 = 10,6 г, 0,1 моль; m(HCl) = 146 × 0,05 = 7,3 г, 0,2 моль. Na₂CO₃ + 2HCl → 2NaCl + H₂O + CO₂↑ — вещества взяты точно по уравнению. NaCl 0,2 моль = 11,7 г; CO₂ 0,1 моль = 4,4 г. m(раствора) = 53 + 146 − 4,4 = 194,6 г; ω(NaCl) = 11,7 : 194,6 = 0,060, то есть 6,0 %.

Типичная ошибка: Не вычесть CO₂: 11,7 : 199 = 5,9 %. Коррекция: газ ушёл из раствора — его массу вычитают.

### Задача 2 — 2 балла

**Ответ:** ω(NaCl) = 3,5 %, ω(Na₂SO₄) = 2,1 %.

**Решение:** m(BaCl₂) = 20,8 г, 0,1 моль; m(Na₂SO₄) = 150 × 0,142 = 21,3 г, 0,15 моль. BaCl₂ + Na₂SO₄ → BaSO₄↓ + 2NaCl: BaCl₂ в недостатке, Na₂SO₄ остаётся 0,05 моль = 7,1 г. BaSO₄ 0,1 × 233 = 23,3 г; NaCl 0,2 моль = 11,7 г. m(раствора) = 208 + 150 − 23,3 = 334,7 г. ω(NaCl) = 11,7 : 334,7 = 3,5 %; ω(Na₂SO₄) = 7,1 : 334,7 = 2,1 %.

Типичная ошибка: Забыть Na₂SO₄ в избытке или не вычесть осадок. Коррекция: после реакции перечислить всё, что осталось растворённым.
