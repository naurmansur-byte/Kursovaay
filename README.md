# Химия просто — старт для нового ИИ

Русскоязычная подготовка к ЕНТ по химии и производство образовательных роликов.
Состояние: 12 октября 2026. Репозиторий переиспользован по прямому поручению владельца; прежний проект удалён из текущего дерева, история сохранена.

## Начни здесь

0. **Актуальный план — [дорожная карта запуска к 1 ноября](docs/ROADMAP.md).** Задания — в [prompts/](prompts/README.md), состояние — в [STATUS.md](STATUS.md).
1. Прочитай [актуальную передачу работы](docs/NEXT_AGENT.md).
2. Прочитай [контекст и ответы на 40 вопросов](docs/PROJECT_HANDOFF.md).
3. Для видео используй [техническое задание](docs/VIDEO_PRODUCTION.md), [шаблон ролика](templates/REEL_BRIEF.md) и [проверку качества](docs/QUALITY_CHECKLIST.md).
4. Для учебного направления используй [источники](docs/SOURCES.md) и [исторический черновик программы](archive/CURRICULUM_V0_1.md). Его календарь не утверждён.

## Что уже есть

- Зафиксированные решения о курсе, 40 ответов, роли, ссылки на Google Drive.
- Черновая последовательность тем и карта источников.
- Задание на создание видео и шаблон передачи сценария в производство.

## Чего пока нет

Готовых видео, выбранного видеостека, готового программного генератора, утверждённого дизайна, комплекта пилотной учебной темы и окончательной программы курса. Наличие инструкции не означает наличие работающего рендера.

## Последнее распределение работы

Учебную программу владелец продолжает с другим ИИ. Текущий диалог посвящён контенту Reels.
Другой ИИ в этом репозитории должен подхватить техническое производство видео, опираясь на проверенные сценарии.
YouTube 7–10 минут предусмотрен в общем плане, первая производственная задача — короткий ролик.
Общий контекст курса сохранён, чтобы можно было продолжить и учебное направление по запросу владельца.

## Как начать разговор с другим ИИ

«Прочитай README.md и docs/NEXT_AGENT.md, затем документы по ссылкам внутри репозитория. Продолжи проект “Химия просто”. Начни с производства пробного Reels: одна задача, три варианта подачи, ИИ-озвучка, точные формулы и анимация. Не повторяй опрос из 40 вопросов. Предложи минимальный способ реализации, создай проверяемый результат и запиши, что реально сделано. Если задача про курс — следуй разделу учебного направления в NEXT_AGENT.md».
