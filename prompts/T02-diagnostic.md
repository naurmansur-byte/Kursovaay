# T02. Входная диагностика

## Цель

Короткий тест базы, который проходит каждый записавшийся до начала курса. По нему ученики распределяются по 4 группам, а преподаватель видит пробелы. В Instagram этот же тест предлагается как бесплатная проверка уровня.

## Прочитай

- `docs/ROADMAP.md`
- `docs/PROJECT_HANDOFF.md` — раздел 2
- `archive/CURRICULUM_V0_1.md` — модуль М1 и раздел 7 «Контроль» (входная работа)
- `course/PROGRAM.md`, если T01 уже готово

## Что сделать

1. 25–30 заданий на 40 минут по основам:
   - математика для химии: проценты, пропорции, единицы;
   - атом, молекула, ион; символы, индексы, коэффициенты, заряды;
   - составление формул по валентности;
   - уравнивание реакций;
   - классы неорганических веществ;
   - простой расчёт: молярная масса и количество вещества.
2. Форматы как в ЕНТ: с одним ответом, с несколькими ответами, на соответствие. Задания от лёгких к средним, без сложного уровня.
3. Каждое задание — авторское, так и помечено. Укажи, какой навык проверяет каждое задание.
4. Ключ и краткое решение к каждому заданию. Атомные массы — школьные округлённые значения (например, Cl = 35,5); список значений дай в начале теста.
5. Подсчёт баллов и правило: баллы по блокам → уровень A / B / C → рекомендация по группе и по стартовым пробелам.

## Результат

- `course/diagnostic/student.md` — версия для ученика (без ответов).
- `course/diagnostic/teacher.md` — ключи, решения, подсчёт баллов, правило распределения.
- На Диске: Google Form с автопроверкой. Если создать форму нельзя — Google Doc с вопросами и пометкой, что их надо перенести в форму вручную.

## Критерии приёмки

- Каждый ответ пересчитан независимо; в заданиях с одним ответом верный вариант ровно один.
- Нет двусмысленных формулировок и заданий на темы, которых нет в основах 7–9 классов.
- Форма собирает только имя, класс и контакт (без лишних персональных данных).

## Чего не делать

- Не выдавать задания за официальные задания НЦТ и не копировать их из чужих пробников.
- Не пересчитывать результат в «прогноз балла ЕНТ».
