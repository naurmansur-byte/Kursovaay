Тест 1–8 — строкой, например `G: 1Б 2: А3 Б1; 3БГЕ …` (образец записи, не ответы); 9–10 — фото, 11 — текст или голосовое. Все добавленные вещества растворяются полностью; упаривается только вода, вещество не улетучивается; в задачах смешивания для вычисления ω реакции/осадка нет; если дано уравнение, реакция протекает по нему.

## G: Общее

Тест 12 минут.

**G1. Один ответ · строка теста.** M(H₂SO₄) при Ar(H) = 1, Ar(S) = 32, Ar(O) = 16:

- А) 98 г/моль.
- Б) 49 г/моль.
- В) 96 г/моль.
- Г) 98 г.

- 1 — Соль.
- 2 — Оксид.

- Г) Mr измеряется в граммах.
- Д) N=nNₐ.
- Е) 1 моль H₂ содержит 1 моль атомов H.

**G4. Один ответ · строка теста.** Растворимость при данной температуре задаётся массой вещества на:

**G5. Один ответ · строка теста.** Молярная концентрация относится к:

**G6. Несколько ответов · строка теста.** Выбери верные факты.

## A: Углубление

Тест 12 минут.

Опора A входит в 30 минут: c = ωρ/M при ρ в г/л; эмпирическая формула — отношение атомов, молекулярная — реальное число; множитель=M истинная/M простейшая. В смеси газ образует указанный компонент.

**A1. Один ответ · строка теста.** M(CO₂)=44, M(H₂)=2 г/моль. D_H₂(CO₂) равна:

- А) 44 г/л.
- Б) 2.
- В) 22.
- Г) 88.

**A2. Соответствие · строка теста.** Сопоставь А — количество вещества n; Б — масса m с единицей.

- 1 — Моль.
- 2 — Литр.
- 3 — Грамм.
- 4 — Моль⁻¹.

**A3. Несколько ответов · строка теста.** Выбери верные утверждения о 1 моль молекул CH₄.

- А) Атомов C — 1 моль.
- Б) Атомов H — 1 моль.
- В) Атомов H — 4 моль.
- Г) Общее количество атомов 5 моль.
- Д) Молекула всего одна.
- Е) Mr всегда измеряют в г/моль.

**A4. Один ответ · строка теста.** Малорастворимое вещество достигло предельной растворимости при данной t. Раствор с небольшим содержанием вещества может быть:

- А) Только перенасыщенным.
- Б) Насыщенным и разбавленным.
- В) Только концентрированным.
- Г) Неоднородным по определению раствором.

**A5. Один ответ · строка теста.** Учебная граница «практически нерастворимые» на 100 г воды:

- А) Меньше 0,01 г.
- Б) Больше 10 г.
- В) Ровно 100 г.
- Г) Больше 1 г.

**A6. Несколько ответов · строка теста.** Выбери верные определения.

- А) Растворимость относится к 100 г раствора.
- Б) c измеряют в моль/л раствора.
- В) Насыщение не зависит от температуры.
- Г) ω считают по массе раствора.
- Д) При доливании чистой воды масса растворённого вещества увеличивается.
- Е) Растворимость относится к данной температуре.

**A7. Один ответ · строка теста.** Дано ω = 0,04, ρ = 1030 г/л, M(NaBr)=103 г/моль. c=ωρ/M. Найди c.

- А) 0,04.
- Б) 0,4.
- В) 4.
- Г) 40.

**A8. Один ответ · строка теста.** Простейшая формула CH, заданная M=78 г/моль. M(CH)=13 г/моль. Истинная формула:

- А) CH.
- Б) C₂H₂.
- В) C₆H₆.
- Г) C₈H₈.

### Фото — 14 минут

**A9. Фото решения.** Смесь CaO/CaCO₃ имеет массу 15,6 г; при прокаливании выделилось 2,24 л CO₂ при н. у. CaCO₃ → CaO + CO₂; M(CaCO₃)=100, Vₘ=22,4 л/моль. Найди исходные массы и долю CaO.

**A10. Фото решения.** 100 г технического CaCO₃ с 20 % инертных примесей прокалили. Выход CO₂ 75 %. CaCO₃ → CaO + CO₂; M=100 г/моль, Vₘ=22,4 л/моль при н. у. Найди чистую массу, теоретический/практический объём CO₂.

## B: Закрепление

**B2. Соответствие · строка теста.** Сопоставь А — Fe; Б — S с молярной массой.

- Д) Коэффициенты означают одинаковые массы.

**B4. Один ответ · строка теста.** При нагревании растворимость большинства твёрдых веществ обычно:

**B7. Один ответ · строка теста.** Приготовили 200 г 5 % раствора. Масса вещества:

## C: Поддержка

Тест 12 минут.

**C1. Один ответ · строка теста.** Mr(NaOH) при Ar(Na) = 23, Ar(O) = 16, Ar(H) = 1:

- А) 23.
- Б) 39.
- В) 40.
- Г) 56.

**C2. Соответствие · строка теста.** Сопоставь А — Nₐ; Б — Vₘ газа при н. у. со значением.

- 1 — 22,4 л/моль.
- 2 — 6,02·10²³ моль⁻¹.
- 3 — 29 г/моль.
- 4 — 273 °C.

**C3. Несколько ответов · строка теста.** Выбери верные формулы недели 4.

- А) m=nM.
- Б) n=m/M.
- В) V=nVₘ при н. у. для газа.
- Г) Mr имеет единицу г.
- Д) Коэффициенты всегда равны массам.
- Е) n=N×Nₐ.

**C4. Один ответ · строка теста.** Раствор — это система:

- А) Обязательно неоднородная.
- Б) Только твёрдая.
- В) Однородная из растворителя и вещества.
- Г) Только вода без примеси вещества.

**C5. Один ответ · строка теста.** «Хорошо растворимые» по учебному описанию на 100 г воды:

- А) Больше 10 г.
- Б) Меньше 0,01 г.
- В) Ровно 0 г.
- Г) Любая масса при любой температуре.

**C6. Несколько ответов · строка теста.** Выбери верные опоры.

- А) c считают на литр воды, не раствора.
- Б) Масса раствора = масса вещества + масса растворителя.
- В) Насыщенный всегда концентрированный.
- Г) При упаривании только воды масса вещества сохраняется.
- Д) Добавление вещества не меняет массу раствора.
- Е) Растворимость газов обычно растёт при нагревании.

**C7. Один ответ · строка теста.** 5 г вещества + 45 г воды. По формуле ω=m вещества/m раствора найди долю.

- А) 5 %.
- Б) 10 %.
- В) 45 %.
- Г) 50 %.

**C8. Один ответ · строка теста.** Дано n=0,1 моль, V=1 л раствора. c=n/V равно:

- А) 1.
- Б) 10.
- В) 0,01.
- Г) 0,1.

### Фото — 14 минут

**C9. Фото решения.** 125 г технического CaCO₃ с 20 % инертных примесей. CaCO₃ → CaO + CO₂; M=100 г/моль, Vₘ=22,4 л/моль при н. у.; выход 100 %. Найди чистую массу и объём CO₂.

**C10. Фото решения.** Из 4 г H₂ и 16 г O₂ по 2H₂ + O₂ → 2H₂O найди недостаток и массу воды. M(H₂)=2, M(O₂)=32, M(H₂O)=18 г/моль.
