# Неделя 22. Расчётный трек — решения

Проверить вместе с вариантом A/B/C после урока 44. Задачи авторские тренировочные; баллы трека учебные и не входят в 34 балла ДЗ. 2 балла — верная модель, ход и ответ; 1 — верная модель и одна вычислительная ошибка; 0 — неверная модель или нет решения. Если задачу не решила половина группы, разобрать её на ближайшем уроке в блоке вопросов.

### Задача 1 — 2 балла

**Ответ:** ω(Al) = 39,1 %.

**Решение:** n(H₂) = 10,08 : 22,4 = 0,45 моль. x — Al, y — Fe: 1,5x + y = 0,45; 27x + 56y = 13,8. y = 0,45 − 1,5x; 27x + 25,2 − 84x = 13,8; 57x = 11,4; x = 0,2; y = 0,15. m(Al) = 5,4 г, m(Fe) = 8,4 г; ω(Al) = 5,4 : 13,8 = 39,1 %.

Типичная ошибка: Для алюминия 1 моль H₂ на 1 моль металла. Коррекция: 2Al → 3H₂.

### Задача 2 — 2 балла

**Ответ:** 4,48 л; 8,96 л; при 5,6 л — 15,9 г Na₂CO₃ и 8,4 г NaHCO₃.

**Решение:** 2NaOH + CO₂ → Na₂CO₃ + H₂O: n(CO₂) = 0,2 моль, 4,48 л. NaOH + CO₂ → NaHCO₃: 0,4 моль, 8,96 л. 5,6 л = 0,25 моль, отношение 0,4 : 0,25 = 1,6 — обе соли: 2x + y = 0,4; x + y = 0,25 → x = 0,15, y = 0,1; Na₂CO₃ 15,9 г, NaHCO₃ 8,4 г.

Типичная ошибка: Перепутать, какой соли нужен избыток CO₂. Коррекция: кислая соль — больше кислотного оксида, отношение 1 : 1.
