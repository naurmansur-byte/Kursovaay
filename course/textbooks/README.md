# Учебная база: учебники из перечня НЦТ

Макс, начато 13.10.2026 (решение Мансура: «ничего от себя, всё по учебникам»). НЦТ составляет задания по стандарту и учебникам из своего перечня, поэтому наши уроки, карточки и пробники опираются на те же книги.

## Что здесь лежит

- `INDEX.md` — карта «неделя курса → параграфы и страницы учебников» для обоих предметов.
- `chem-NN-*.md`, `bio-NN-*.md` — **выжимки параграфов** к неделям курса: термины и определения (как в учебнике, коротко), законы и формулировки, учёные, даты, тривиальные названия, числа, что из этого спрашивают на ЕНТ, страницы для сверки. Делаются заранее, с запасом в 1–2 недели до задачи Мартину.
- `ERRATA.md` — ошибки учебников и как правильно.

## Как получен текст

Учебники — сканы. Страницы склеиваются из полос (`pypdf` + Pillow, ×2), распознаются Windows OCR (русский). Распознавание даёт около 90 % точности: для поиска и выжимок хватает, а формулы, числа и спорные формулировки Макс сверяет по картинке страницы. Скрипты и команды — `tools/textbooks/README.md`.

## Как этим пользоваться

1. Перед задачей недели Макс кладёт выжимку нужных параграфов и указывает её в задании.
2. Мартин пишет комплект **только по выжимке** (и справочнику фактов `course/ent-base/`). Чего нет в выжимке — не добавляет; если нужно — помечает `[НУЖНО РЕШЕНИЕ: …]`.
3. В `README.md` недели — таблица «Источник»: раздел комплекта → учебник, §, страницы.
4. Ошибка в учебнике → `ERRATA.md` и строка в заметках преподавателю.
