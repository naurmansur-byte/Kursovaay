# Полимеры

- Мономер → звено → макромолекула; n = M(полимера) : M(звена).
- Полимеризация: мономер с C=C, без побочных продуктов, масса сохраняется.
- Поликонденсация: две функциональные группы, выделяется вода (HCl, NH₃).
- Полимеризация: полиэтилен, полипропилен, ПВХ, полистирол, тефлон, каучуки.
- Поликонденсация: капрон, кевлар, лавсан, фенолформальдегидная смола, крахмал, белки.
= Термопласт — многократно размягчается; реактопласт — твердеет необратимо
! Резина = каучук + сера (сетка) + сажа; эбонит — больше 30 % серы.

# Качественные реакции

- Бромная вода: обесцвечивание — C=C, C≡C; белый осадок — фенол, анилин; бензол — нет.
- KMnO₄ — обесцвечивание (бурый осадок): алкены, алкины.
- FeCl₃ — фиолетовое: фенол. I₂ — синее: крахмал.
- Cu(OH)₂: синий раствор — многоатомные спирты, глюкоза; при нагревании красный Cu₂O — альдегиды, глюкоза.
- Ag₂O (NH₃), t — зеркало: альдегиды, глюкоза, HCOOH.
- Белки: NaOH + CuSO₄ — фиолетовое; конц. HNO₃ — жёлтое. Лакмус: кислоты — красный, амины — синий.
= Горение: ПЭ — как парафин; ПВХ — коптит, HCl; шерсть — жжёное перо; хлопок — жжёная бумага
! Медная проволока снова красная — спирт.

# Вывод формулы и факты

- ω → n(C) : n(H) : n(O) = ω/12 : ω/1 : ω/16 → простейшая формула.
- Горение: n(C) = n(CO₂); n(H) = 2n(H₂O); m(O) = m − m(C) − m(H).
- M = D · M(газа): D(H₂) × 2, D(He) × 4, D(воздух) × 29.
- Класс по свойствам: NaHCO₃ — кислота; зеркало — альдегид; бромная вода — C=C.
- Ряд: алкан → галогеналкан → спирт → альдегид → кислота.
- Олигомеры — Mr 500–5000; ПЭ высокого давления — разветвлённый.
- Вискоза, ацетат — искусственные; капрон, кевлар — полиамиды; лавсан — полиэфир.
- Лебедев: бутадиен из этанола; пластик — 100–500 лет; при сжигании — диоксины.
