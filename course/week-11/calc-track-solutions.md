# Неделя 11. Расчётный трек — решения

Проверить вместе с вариантом A/B/C после урока 22. Задачи авторские тренировочные; баллы трека учебные и не входят в 34 балла ДЗ. 2 балла — верная модель, ход и ответ; 1 — верная модель и одна вычислительная ошибка; 0 — неверная модель или нет решения. Если задачу не решила половина группы, разобрать её на ближайшем уроке в блоке вопросов.

### Задача 1 — 2 балла

**Ответ:** 427,5 кг CaCO₃.

**Решение:** m(C) = 60 × 0,90 = 54 кг, n = 54 : 12 = 4,5 кмоль. По углероду C → CaCO₃ (1 : 1): теоретически 4,5 × 100 = 450 кг; с выходом 450 × 0,95 = 427,5 кг.

Типичная ошибка: Считать по всей массе угля: 5 кмоль, 475 кг. Коррекция: сначала масса чистого вещества.

### Задача 2 — 2 балла

**Ответ:** 4,48 л теоретически; выход 89,3 %.

**Решение:** Катод: Cu²⁺ + 2e⁻ → Cu; анод: 2Cl⁻ → Cl₂ + 2e⁻; по электронам n(Cl₂) = n(Cu). n(Cu) = 12,8 : 64 = 0,2 моль → V(Cl₂) = 0,2 × 22,4 = 4,48 л. η = 4,0 : 4,48 = 0,893, то есть 89,3 %.

Типичная ошибка: Считать хлор по атомам: 0,4 моль, 8,96 л. Коррекция: на одну молекулу Cl₂ — два электрона, как на один атом Cu.
