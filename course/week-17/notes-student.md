## 1. Что изучает органическая химия

Почему у углерода больше 20 млн соединений, а у всех остальных элементов вместе — около 1,5 млн? Атомы углерода соединяются друг с другом в длинные цепи и кольца.

**Органическая химия** изучает соединения углерода и законы их превращений. Термин ввёл Й. Я. Берцелиус в 1807 году — сначала только для веществ живых организмов.

**Органогены** — элементы органических веществ: кроме C чаще всего H, O, N; реже S, P, галогены. **Углеводороды** состоят только из C и H. В **производных углеводородов** атом H замещён другим атомом или группой: CH₃Cl, CH₃OH, CH₃NH₂.

> [!rule] Особенности органических веществ
> Цепи и кольца из атомов C с одинарными, двойными и тройными связями.
> Широко распространена изомерия.
> Связи ковалентные, малополярные; большинство веществ — неэлектролиты.
> Низкие температуры плавления; при нагревании обугливаются, в кислороде сгорают.

CO, CO₂, H₂CO₃ и CaCO₃ содержат углерод, но по свойствам близки к неорганическим и изучаются с ними. Резкой границы между органическими и неорганическими веществами нет.

## 2. Формулы и строение

| Формула | Что показывает | Пример |
|---|---|---|
| Молекулярная | состав молекулы | C₆H₁₄ |
| Простейшая | только соотношение атомов | C₃H₇ для гексана |
| Структурная развёрнутая | все связи чёрточками | — |
| Сокращённая | чёрточками только связи C–C | CH₃–CH₂–CH₃ |
| Скелетная | только углеродная цепь зигзагом | — |

![Пропан пятью способами: молекулярная C₃H₈, простейшая C₃H₈, развёрнутая со всеми связями, сокращённая CH₃–CH₂–CH₃ и скелетная — зигзаг из двух отрезков](pics/propane-formulas.png)

> [!rule] Углерод четырёхвалентен
> В органических веществах C всегда образует четыре связи.
> В алканах атом C в состоянии sp³: четыре связи направлены к вершинам тетраэдра, угол 109°28′.
> Поэтому цепь — зигзаг, а не прямая; расстояние C–C 0,154 нм.

![Тетраэдр метана: атом C в центре, четыре атома H в вершинах, угол 109°28′; рядом цепь из пяти атомов C зигзагом](pics/methane-tetrahedron.png)

Молекула метана объёмная, а не плоская, как на бумаге. Связь C–H слабо полярна: C электроотрицательнее H. Вокруг связи C–C возможно вращение, поэтому цепь принимает разные формы.

> [!trap] Простейшая формула — не молекулярная
> У гексана C₆H₁₄ простейшая формула C₃H₇, у этана C₂H₆ — CH₃. Простейшая формула показывает только отношение атомов.

## 3. Классификация

Органические вещества делят по двум признакам: **углеродный скелет** и **функциональная группа**.

- По скелету: **ациклические** (цепь неразветвлённая или разветвлённая) и **циклические**; циклические — **карбоциклические** (кольцо только из C) и **гетероциклические** (в кольце есть N, O, S).
- По связям C–C: **предельные** (только одинарные) и **непредельные** (есть двойные или тройные).
- Классы углеводородов: алканы (метан), алкены (этен), алкадиены (пропадиен), алкины (этин), арены (бензол), циклоалканы (циклопропан).

![Схема классификации: органические вещества → углеводороды и производные; углеводороды → ациклические (алканы, алкены, алкадиены, алкины) и циклические (циклоалканы, арены); рядом функциональные группы и классы](pics/organic-classification.png)

**Функциональная группа** — атом или группа атомов, которая определяет свойства и класс вещества; общая запись R–X. На этой неделе класс нужно только узнать по группе:

| Группа | Класс |
|---|---|
| –OH | спирты (и фенолы) |
| –CHO | альдегиды |
| >C=O | кетоны |
| –COOH | карбоновые кислоты |
| –COO– | сложные эфиры |
| –NH₂ | амины |
| –NO₂ | нитросоединения |
| –NH₂ и –COOH | аминокислоты |

## 4. Гомологи и ряд алканов

**Гомологи** — вещества, сходные по строению и свойствам, которые отличаются на группу **CH₂** (гомологическая разность). Вместе они образуют **гомологический ряд** с одной общей формулой. Ближайшие гомологи пропана — этан и бутан.

**Алканы** (парафины, предельные углеводороды) — **CₙH₂ₙ₊₂**: каждый атом C тратит на соседний одну валентность, остальные заняты водородом. «Парафин» значит «малоактивный».

> [!rule] Первые десять алканов
> метан CH₄ · этан C₂H₆ · пропан C₃H₈ · бутан C₄H₁₀ · пентан C₅H₁₂
> гексан C₆H₁₄ · гептан C₇H₁₆ · октан C₈H₁₈ · нонан C₉H₂₀ · декан C₁₀H₂₂
> Радикалы: -ан → -ил: метил –CH₃, этил –C₂H₅, пропил –C₃H₇, бутил –C₄H₉.
> M(CₙH₂ₙ₊₂) = 14n + 2: при M = 100 n = 7, C₇H₁₆.

Физические свойства: **C₁–C₄ — газы, C₅–C₁₅ — жидкости, с C₁₆ — твёрдые**. Температура кипения растёт с длиной цепи. Алканы неполярны, в воде практически нерастворимы, легче воды; жидкие алканы — хорошие растворители. Метан, этан и высшие алканы запаха не имеют.

## 5. Названия по IUPAC

Номенклатура бывает **тривиальной** (исторические названия: винный спирт, уксусная кислота), **рациональной** («триметилметан») и **систематической** — IUPAC. **Локант** — номер атома с заместителем; **ди-, три-, тетра-** — число одинаковых заместителей.

Атом C называют по числу соседних атомов **углерода**: **первичный** — один сосед C, **вторичный** — два, **третичный** — три, **четвертичный** — четыре.

![Молекула 2,2,3-триметилпентана: первичные атомы C отмечены одним цветом, вторичный — другим, третичный и четвертичный — своими; рядом подпись «считаем соседние C, а не H»](pics/carbon-atom-types.png)

> [!rule] Алгоритм названия алкана
> 1) Найди самую длинную цепь — главную.
> 2) Пронумеруй её с конца, ближе к которому разветвление.
> 3) Назови заместители с номерами; одинаковые — ди-, три-, у каждого свой номер.
> 4) Разные заместители — по алфавиту; сумма номеров — наименьшая.
> 5) В конце — название алкана главной цепи.

![Алгоритм на примере: цепь с заместителями, главная цепь выделена цветом, нумерация от ближнего к разветвлению конца, итог — 2,3-диметилпентан](pics/naming-algorithm.png)

> [!example] Разберём
> ```
> CH₃–CH–CH₂–CH–CH₃
>     |      |
>     CH₃    C₂H₅
> ```
> Самая длинная цепь — 6 атомов C: она продолжается через этильную группу.
> Нумеруем с левого конца, к нему ближе разветвление: метил у C-2 и метил у C-4 (это правый CH₃ исходной записи).
> С правого конца номера были бы 3 и 5 — сумма больше.
> Название: **2,4-диметилгексан**.

Ещё примеры: 3-метилгексан, 3,3-диметилпентан, 2,3,5-триметилгексан, 2,2-диметил-3-этилпентан.

> [!trap] Главная цепь — самая длинная
> «2-этилбутан» — ошибка: через этил цепь длиннее, это **3-метилпентан**.
> «3-метилбутан» — ошибка нумерации: считаем с ближнего к разветвлению конца, это **2-метилбутан**.

## 6. Изомерия

**Изомеры** — вещества с одинаковым составом (одной молекулярной формулой), но разным строением, а значит, разными свойствами.

![Изомеры бутана и пентана: н-бутан (t кип −0,5 °C) и 2-метилпропан (−11,4 °C); н-пентан, 2-метилбутан, 2,2-диметилпропан — разветвлённый изомер кипит ниже](pics/isomers-bp.png)

- Бутан C₄H₁₀ — 2 изомера: н-бутан (t кип −0,5 °C) и изобутан, 2-метилпропан (−11,4 °C).
- Пентан C₅H₁₂ — 3 изомера: н-пентан, изопентан (2-метилбутан), неопентан (2,2-диметилпропан).
- Число изомеров: C₄ — 2, C₅ — 3, C₆ — 5, C₇ — 9, C₈ — 18, C₉ — 35, C₁₀ — 75. У метана, этана и пропана изомеров нет.

> [!rule] Виды изомерии
> **Структурная** — разный порядок соединения атомов: углеродного скелета (н-пентан и 2-метилбутан); положения кратной связи или функциональной группы (бутен-1 и бутен-2); межклассовая (этанол и диметиловый эфир).
> **Пространственная** — строение одно, расположение в пространстве разное: цис-транс и оптическая.
> У алканов — только изомерия скелета.

| Общая формула | Классы-изомеры | Пример |
|---|---|---|
| CₙH₂ₙ | алкены и циклоалканы | гексен-1 и циклогексан |
| CₙH₂ₙ₋₂ | алкины и алкадиены | пропин и пропадиен |
| CₙH₂ₙ₊₂O | спирты и простые эфиры | этанол и диметиловый эфир |
| CₙH₂ₙO | альдегиды и кетоны | пропаналь и пропанон |
| CₙH₂ₙO₂ | кислоты и сложные эфиры | бутановая кислота и метиловый эфир пропановой кислоты |

> [!trap] Гомолог или изомер
> Гомологи — **разные** формулы с разницей CH₂: этан и пропан.
> Изомеры — **одна** формула, разное строение: бутан и 2-метилпропан.
> Разветвлённый изомер кипит **ниже** неразветвлённого.

## 7. Алканы: свойства и применение

**Метан CH₄** — бесцветный газ без запаха, почти нерастворим в воде, легче воздуха; t кип −161,5 °C. Главная часть **природного газа**; «болотный газ» образуется при гниении растений без воздуха, «рудничный газ» скапливается в шахтах. Алканы есть в природном и попутном газе, нефти, угле, горючих сланцах, газовых гидратах, биогазе.

Связи C–C и C–H прочные и малополярные, поэтому алканы малоактивны. Типичные реакции — замещение, разложение, окисление, изомеризация.

> [!rule] Хлорирование метана на свету
> CH₄ + Cl₂ → CH₃Cl + HCl (хлорметан)
> CH₃Cl + Cl₂ → CH₂Cl₂ + HCl (дихлорметан)
> CH₂Cl₂ + Cl₂ → CHCl₃ + HCl (трихлорметан, хлороформ)
> CHCl₃ + Cl₂ → CCl₄ + HCl (тетрахлорметан)
> Механизм радикально-цепной; на каждой ступени выделяется HCl.

![Хлорирование метана по четырём ступеням: на каждой стрелке Cl₂ и hν, после каждой — HCl; молекулы CH₃Cl, CH₂Cl₂, CHCl₃, CCl₄ с подписями](pics/methane-chlorination.png)

На рассеянном свету окраска хлора постепенно исчезает; на прямом солнечном свету смесь может взорваться. Хлороформ используют в медицине, CCl₄ — для тушения пожаров; оба токсичны. **Фреоны** — фтор- и хлорпроизводные, хладагенты; они разрушают озоновый слой.

- **Разложение:** при ~1000 °C CH₄ → C + 2H₂; при 1500 °C 2CH₄ → C₂H₂ + 3H₂ (ацетилен).
- **Горение:** CH₄ + 2O₂ → CO₂ + 2H₂O + Q; 2C₂H₆ + 7O₂ → 4CO₂ + 6H₂O + Q. Общий вид: CₙH₂ₙ₊₂ + (3n + 1)/2 O₂ → nCO₂ + (n + 1)H₂O.
- **Синтез-газ:** 2CH₄ + O₂ → 2CO + 4H₂ (~850 °C) — сырьё для метанола и высших алканов, водород — для аммиака.
- **Изомеризация:** н-пентан → 2-метилбутан (катализатор AlCl₃).
- **Неполное сгорание** даёт CO и сажу.

> [!trap] Взрыв и запах
> Смеси алканов с воздухом взрывоопасны. Метан в воздухе взрывается при 5–15 %, сильнее всего — при 9,5 %; смесь CH₄ : O₂ = 1 : 2 даёт очень сильный взрыв.
> Сам метан запаха не имеет — пахнут добавленные **одоранты** (меркаптаны). Газовая служба — 104.

Применение: топливо (газ, бензин, керосин, дизельное топливо, мазут), вазелин и парафин, растворители, хладагенты; сырьё для пластмасс, каучуков, волокон, моющих средств. Если сжечь парафин под стаканом, на стенках появятся капли воды (есть H), а известковая вода помутнеет (есть C).

## 8. Циклоалканы

**Циклоалканы** — насыщенные углеводороды с циклом из трёх и более атомов C. Общая формула **CₙH₂ₙ (n ≥ 3)** — та же, что у алкенов. Названия — приставка **цикло-**: циклопропан C₃H₆, циклобутан C₄H₈, циклопентан C₅H₁₀, циклогексан C₆H₁₂. C₅ и C₆ есть в нефти, поэтому их называют **нафтенами**; из нефти их впервые выделил В. В. Марковников.

![Циклопропан, циклобутан, циклопентан и циклогексан: малые циклы с напряжёнными углами раскрываются, C₅ и C₆ — почти тетраэдрические углы; ниже цис- и транс-1,2-диметилциклопропан](pics/cycloalkanes.png)

- Изомерия: размер цикла, строение и положение заместителей; межклассовая с алкенами. У 1,2-диметилциклопропана есть цис- и транс-изомеры: метилы по одну или по разные стороны плоскости цикла.
- Циклопропан и циклобутан — газы; циклопентан и циклогексан — жидкости.
- В C₃ и C₄ углы сильно отличаются от 109°28′ — **напряжение**, поэтому малые циклы **раскрываются** (присоединение).
- С C₅ углы почти тетраэдрические — идёт **замещение**, как у алканов: C₆H₁₂ + Cl₂ → C₆H₁₁Cl + HCl (на свету).
- Горение: C₆H₁₂ + 9O₂ → 6CO₂ + 6H₂O + Q.
- Дегидрирование: циклогексан → бензол + 3H₂; метилциклогексан → толуол + 3H₂.
- Циклопропан — средство для наркоза (сейчас редко: очень огнеопасен).

> [!trap] CₙH₂ₙ — два класса
> CₙH₂ₙ — и алкены, и циклоалканы; CₙH₂ₙ₊₂ — только алканы. Цис-транс у алканов нет, у 1,2-диметилциклопропана есть. Циклогексан при дегидрировании даёт бензол, а не гексен.

## 9. Вывод молекулярной формулы

![Схема: ω элементов → отношение ω/Aᵣ → простейшая формула; плотность газа → M; n = M(истинная) / M(простейшая) → молекулярная формула; отдельная ветка — продукты сгорания](pics/formula-derivation.png)

> [!rule] Правила
> M = 2 · D(H₂) = 29 · D(возд) = 4 · D(He) = 22,4 · ρ (для газа при н. у.).
> Простейшая формула: ω/Aᵣ для каждого элемента, делим на меньшее.
> Множитель: M(истинная) / M(простейшая).
> По продуктам сгорания: n(C) = n(CO₂), n(H) = 2n(H₂O); проверь кислород: m(C) + m(H) = m(вещества)?
> Для алкана: 14n + 2 = M.

> [!example] Разберём: по массовой доле и плотности
> ω(C) = 81,8 %, D(H₂) = 22. M = 44.
> C : H = 81,8/12 : 18,2/1 = 6,82 : 18,2 = 3 : 8 → C₃H₈ (M = 44, множитель 1).

> [!example] Разберём: по продуктам сгорания
> 4,3 г углеводорода → 13,2 г CO₂ и 6,3 г H₂O; D(H₂) = 43.
> n(C) = 0,30 моль (3,6 г), n(H) = 0,70 моль (0,7 г); 3,6 + 0,7 = 4,3 г — кислорода нет.
> C : H = 3 : 7, простейшая C₃H₇ (43); M = 86 → C₆H₁₄.

> [!trap] 85,7 % у всех CₙH₂ₙ
> ω(C) = 85,7 % у любого алкена и циклоалкана. По одной массовой доле формулу не найти — нужна молярная масса.

> [!rule] Факты ЕНТ недели
> - Органическая химия — химия соединений углерода; термин ввёл Берцелиус в 1807 году; органогены C, H, O, N.
> - C всегда четырёхвалентен; в алканах sp³, угол 109°28′, цепь — зигзаг.
> - Алканы CₙH₂ₙ₊₂: метан, этан, пропан, бутан, пентан, гексан, гептан, октан, нонан, декан; радикалы -ил.
> - Изомеров: C₄ — 2, C₅ — 3, C₆ — 5, C₇ — 9; н-бутан кипит при −0,5 °C, изобутан — при −11,4 °C.
> - C₁–C₄ — газы, C₅–C₁₅ — жидкости; метан — болотный и рудничный газ, без запаха, пахнут одоранты.
> - Хлорирование на свету: CH₃Cl → CH₂Cl₂ → CHCl₃ (хлороформ) → CCl₄; механизм радикальный.
> - CH₄ → C + 2H₂ (1000 °C), 2CH₄ → C₂H₂ + 3H₂ (1500 °C); CH₄ : O₂ = 1 : 2 — сильный взрыв; синтез-газ — CO + H₂.
> - Циклопропан и циклобутан — газы, малые циклы раскрываются; циклогексан → бензол + 3H₂; нафтены — Марковников; циклопропан — наркоз.
