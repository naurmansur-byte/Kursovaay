## Готовое объяснение для доски

**L1. Валентность и бинарная формула, 10–27 минут.** Валентность описывает способность атома образовывать определённое число связей; в выбранных простых бинарных формулах используем правило равенства суммарных валентностей двух элементов. Валентности даны условием римскими цифрами, мы не определяем их по таблице и не обсуждаем причины. Бинарное соединение содержит два элемента. Значение валентности одного элемента не объявляем постоянным для любых веществ.

Алгоритм: **записать два символа в заданном порядке → найти наименьшее общее кратное двух валентностей → разделить его на каждую валентность → записать частные индексами → проверить равенство**. Индекс 1 не пишем. При равных валентностях индексы 1 : 1; излишний общий множитель сокращаем.

- Mg(II) и Cl(I): НОК(2, 1) = 2; индексы Mg: 2/2 = 1, Cl: 2/1 = 2. **MgCl₂**; проверка 1·II = 2·I = 2.
- Al(III) и O(II): НОК(3, 2) = 6; индексы Al: 6/3 = 2, O: 6/2 = 3. **Al₂O₃**; проверка 2·III = 3·II = 6.
- Ca(II) и O(II): НОК = 2, индексы 1 : 1. **CaO**, проверка 1·II = 1·II. Механический перенос чисел дал бы Ca₂O₂, но общие индексы 2 : 2 нужно сократить до 1 : 1. Мы составляем простую формульную запись по условию, а не изменяем уже заданную формулу реального вещества.

После объяснения устно: «Каковы индексы Mg(II) и O(II)?». **Ключ:** 1 : 1, MgO. Не требовать на этом шаге самостоятельных электронных объяснений.

**L2. Относительные массы, 27–41 минут.** Aᵣ — относительная атомная масса: отношение средней массы атомов элемента к принятой единице сравнения — 1/12 массы атома углерода-12. В этой неделе используем только данные справки, без строения атома и изотопных расчётов. Это относительная величина, единиц у Aᵣ нет. Она не является массой образца в граммах.

Mᵣ молекулы — сумма Aᵣ с учётом всех индексов. У немолекулярного вещества точно так же рассчитываем **относительную формульную массу**, используя состав формульной единицы. В вычислениях недели эту сумму также обозначаем Mᵣ, предварительно называя её правильно. MgO, CaO, MgCl₂, Al₂O₃ и Na₂O не называем отдельными молекулами.

- H₂O: Mᵣ = 2·1 + 1·16 = **18** — относительная молекулярная масса.
- MgO: Mᵣ = 1·24 + 1·16 = **40** — относительная формульная масса.

Правило: **состав одной единицы → Aᵣ каждого элемента → число атомов × Aᵣ → сумма**. Коэффициент из записи 3H₂O не включаем в Mᵣ одной молекулы воды: она по-прежнему равна 18. Относительная масса записывается без единиц; число 40 не означает, что любой образец MgO имеет массу 40 г.

**L3. Массовая доля элемента, 41–55 минут.** Массовая доля ω показывает, какая часть массы чистого вещества приходится на выбранный элемент. Сначала берём относительный вклад этого элемента в одной формульной записи; затем делим на относительную массу всей записи. N здесь — **число атомов выбранного элемента в формуле**, прочитанное по индексу.

**ω(E) = N·Aᵣ(E)/Mᵣ; ω(E) в процентах = N·Aᵣ(E)/Mᵣ · 100%.** Доля безразмерна и лежит от 0 до 1, процент от 0 до 100%. Для одного и того же ответа 0,4 и 40% — две допустимые формы записи; 0,4% — другой результат.

- H₂O: Mᵣ = 18; вклад O = 1·16 = 16; ω(O) = 16/18 ≈ 0,8889, или **88,9%**. Вклад H = 2·1 = 2, ω(H) ≈ 11,1%; проценты вместе дают 100% с учётом округления.
- MgO: Mᵣ = 40; ω(O) = 16/40 = 0,4 = **40%**, ω(Mg) = 24/40 = 0,6 = 60%. Это доля кислорода в MgO; не масса кислорода в произвольном образце, пока масса образца не дана.

Один вопрос после объяснения: «В числителе для H в H₂O должно быть 1 или 2?». **Ключ:** 2·1 = 2, потому что индекс H равен 2. Знаменатель — масса всей формулы 18, а не только O.

**L4. Замкнутая система, 55–64 минуты.** При химической реакции атомы перестраиваются в новые вещества; в рассматриваемых химических превращениях число атомов каждого элемента сохраняется. Поэтому **суммарная масса веществ в замкнутой системе до реакции равна суммарной массе веществ после**. Замкнутая система не обменивается веществом с окружающей средой; нагрев сам по себе не означает, что вещество вышло из системы.

Пример для расчёта на бумаге: в замкнутой системе 12 г Mg и 8 г O₂ полностью превратились только в MgO. Найти массу продукта. **12 + 8 = 20 г MgO**. Дано, что оба вещества полностью израсходованы и других продуктов нет: именно поэтому здесь вся начальная масса относится к одному продукту.

Контрпример: газ ушёл из открытого сосуда. Масса оставшегося содержимого может уменьшиться, но газ входит в общий материальный баланс; закон не нарушен. Не подменять «массу всей системы» массой одного оставшегося продукта. Количественный расчёт массы по коэффициентам здесь не вводим.

**L5. Уравнивание и два типа, 64–80 минут.** В схеме уже даны формулы исходных веществ слева и продуктов справа. Стрелка означает превращение, плюс разделяет вещества. Схема становится уравнением, когда подобраны наименьшие положительные целые коэффициенты и число атомов **каждого** элемента совпало. Коэффициент 1 обычно не пишется. Меняем только коэффициенты перед формулами, индексы продуктов сохраняем.

Алгоритм: **посчитать атомы слева/справа → выбрать элемент с несовпадением → поставить коэффициент перед целой формулой → пересчитать все элементы → убрать общий множитель, если есть → проверить каждый элемент**.

1. Дана схема Mg + O₂ → MgO (условие реакции — нагрев). Слева O — 2, справа O — 1. Ставим 2 перед MgO; справа Mg — 2, значит ставим 2 перед Mg. **2Mg + O₂ → 2MgO**. Проверка: Mg 2 = 2, O 2 = 2. Из двух исходных веществ получается одно вещество — **соединение**. Это тип по числу исходных веществ и продуктов, а не по числу атомов или величине коэффициентов.
2. Дана схема CaCO₃ → CaO + CO₂ (нагрев). Слева Ca — 1, C — 1, O — 3; справа Ca — 1, C — 1, O — 1 + 2 = 3. Все коэффициенты уже равны 1. **CaCO₃ → CaO + CO₂** — **разложение**: одно исходное вещество образует несколько веществ. Условие нагрева пишем над стрелкой или словами; оно не является коэффициентом.

Ловушка: Mg + O₂ → MgO₂ меняет заданный продукт MgO на другое вещество. Совпадение счёта после такой подмены не уравнивает исходную схему. Верный ответ — 2Mg + O₂ → 2MgO.

Все схемы предназначены для работы на бумаге. Горение металлов, нагрев веществ и смешивание газов не назначаются как домашний опыт.
