15 минут после урока 16. Задание в формате ЕНТ 26–30: прочитай контекст — первичная и конечная моча — и ответь на четыре вопроса, в каждом один верный ответ. Ответы пришли строкой в Telegram вместе с вариантом A/B/C: `К: 1… 2… 3… 4…`. Решения открывай после попытки.

**Как читать опыт:** что меняли → что было одинаковым → контроль → что показали данные → вывод только в пределах данных.

### Контекст

Есть ли вещество в плазме крови, первичной и конечной моче — по таблице недели 8.

| Вещество | Плазма | Первичная моча | Конечная моча |
|---|---|---|---|
| глюкоза | есть | есть | нет |
| крупные белки | есть | нет | нет |
| мочевина | есть | есть | есть |

**1. Один ответ.** Почему в первичной моче нет крупных белков?

- А) Их разрушает почка.
- Б) Они не проходят фильтр и остаются в крови.
- В) Они реабсорбируются.
- Г) Их нет в плазме.

**2. Один ответ.** Почему в конечной моче нет глюкозы?

- А) Её возвращает в кровь реабсорбция в канальце.
- Б) Она не фильтруется.
- В) Её разрушает мочевина.
- Г) Она превращается в белок.

**3. Один ответ.** Скорость фильтрации 125 мл/мин. Сколько первичной мочи образуется за сутки?

- А) 1,5 л.
- Б) 18 л.
- В) 180 л.
- Г) 1800 л.

**4. Один ответ.** Конечной мочи около 1,5 л в сутки. Какая доля первичной мочи (180 л) возвращается в кровь?

- А) Около 1 %.
- Б) Около 50 %.
- В) Около 90 %.
- Г) Больше 99 %.
