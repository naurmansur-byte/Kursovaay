## 1. Условный заряд

Степень окисления — условный заряд атома при отнесении электронных пар к более электроотрицательному элементу. Она помогает следить за перераспределением электронов, но не означает, что любая молекула действительно состоит из свободных ионов. Заряд иона Al³⁺ записывают цифрой перед знаком; степень окисления Al⁺³ — знаком перед цифрой. В расчётах удобно писать Al: +3.

В простом веществе степень окисления 0: H₂, O₂, Fe, S. Сумма для нейтральной формулы 0, для многоатомного иона равна его заряду. Не путай степень атома с зарядом всего иона.

| Правило | Пример |
|---|---|
| F в соединении −1 | OF₂: O +2 |
| H обычно +1; в гидриде металла −1 | HCl / NaH, CaH₂ |
| O обычно −2; в пероксиде −1 | H₂O / H₂O₂, Na₂O₂, BaO₂ |
| Типичные металлы в соединениях положительны | Na +1, Ca +2, Al +3 |
| Более электроотрицательный элемент бинарного соединения отрицателен | Cl −1 в AlCl₃ |

Для изученных элементов главных подгрупп высшая степень часто совпадает с номером группы в короткой таблице: S группы VIA даёт +6; низшая неметалла — N − 8, у S −2. Это учебная закономерность с исключениями, не формула по современному номеру 16 или 17; на O и F высшую по номеру группы не переносим.

> [!example] Сумма с индексами
> P₂O₅: 2x + 5(−2) = 0, x = +5.
> H₂SO₄: 2(+1) + x + 4(−2) = 0, x = +6.
> SO₄²⁻: x + 4(−2) = −2, x = +6. Степень S +6, заряд иона −2.

## 2. Процесс и роль

ОВР сопровождается изменением степеней окисления. Окисление — отдача электронов и рост степени; восстановление — приём электронов и её снижение. В реальном уравнении эти процессы сопряжены.

![Шкала от отрицательных степеней к положительным: вправо рост/окисление, влево снижение/восстановление](pics/oxidation-scale.png)

> [!rule] Название роли
> Восстановитель отдаёт e⁻ и сам окисляется. Окислитель принимает e⁻ и сам восстанавливается.

![Восстановитель отдаёт электроны окислителю; его степень растёт, у получателя падает](pics/electron-transfer.png)

2Mg + O₂ → 2MgO: Mg 0 → +2 — восстановитель; O 0 → −2 — окислитель. CuO + H₂ → Cu + H₂O: Cu +2 → 0, H 0 → +1; CuO окислитель, H₂ восстановитель. Чёрный оксид превращается в красную медь.

Запись баланса Mg⁰ − 2e⁻ → Mg⁺² показывает электронный счёт. Для реально существующих ионов можно записать Mg → Mg²⁺ + 2e⁻. Молекулярный индекс учитывай: Cl₂ + 2e⁻ → 2Cl⁻; O₂⁰ + 4e⁻ → 2O⁻² — формальная запись изменения степеней, не свободные O²⁻ в воде.

В обычном обмене NaOH + HCl → NaCl + H₂O степени не меняются. При замещении Zn + 2HCl → ZnCl₂ + H₂ меняются Zn и H. Соединение/разложение могут быть и ОВР, и не ОВР: решает проверка степеней, не число веществ.

## 3. Электронный баланс

1. Запиши заданные продукты и степени атомов.
2. Найди, кто меняется; посчитай электронный переход на атом или указанную группу атомов.
3. Найди НОК отданных и принятых электронов, затем множители.
4. Поставь коэффициенты при веществах с этими атомами; остальные подбери по составу.
5. H и O проверь последними, затем пересчитай все атомы и электронный итог.

![Пять шагов баланса: степени → изменения → НОК → коэффициенты → атомы и электроны](pics/balance-steps.png)

> [!example] Два электронных перехода
> Ca: 0 → +2, отдаёт 2e⁻; P: 0 → −3, принимает 3e⁻.
> НОК 6: Ca × 3, P × 2. 3Ca + 2P → Ca₃P₂.
> Al: 0 → +3; 2H⁺ + 2e⁻ → H₂. Множители 2 и 3.
> 2Al + 3H₂SO₄(разб.) → Al₂(SO₄)₃ + 3H₂↑.

Ещё пример: 6P + 5KClO₃ → 3P₂O₅ + 5KCl. P 0 → +5 отдаёт 5, Cl +5 → −1 принимает 6; общий счёт 30e⁻. Коэффициент вещества не всегда равен множителю одного атома: учитывай индекс в формуле.

> [!trap] Что легко перепутать
> Восстановитель окисляется. Рост степени — окисление. Заряд SO₄²⁻ не равен степени S. Нельзя менять индексы вместо коэффициентов, терять двойку у H₂/O₂/Cl₂ или ставить множители без НОК.

## 4. Возможные роли и тип реакции

Для выбранного атома высшая степень допускает только снижение, низшая — только рост, промежуточная — оба направления. Роль целого вещества определяется конкретным уравнением и всеми участвующими атомами.

| Сера | Направление и возможная роль по S |
|---|---|
| H₂S, S −2 | Степень может расти: восстановитель |
| S, степень 0 | Может расти или снижаться |
| SO₂, S +4 | Может расти или снижаться |
| H₂SO₄, S +6 | По S только снижение: окислитель |

![S −2, 0, +4, +6: стрелки возможного изменения; у промежуточных обе стороны](pics/sulfur-roles.png)

По N: HNO₃ с N +5 — окислитель, NH₃ с N −3 — восстановитель. Важные окислители: O₂, O₃, галогены, HNO₃, концентрированная H₂SO₄, H₂O₂. Восстановители: H₂, металлы, C, CO. Список не означает, что каждое вещество играет только одну роль во всех реакциях: H₂O₂ тоже может восстанавливаться и окисляться. Нужны партнёр и условия.

| Тип | Признак и пример |
|---|---|
| Межмолекулярная | Разные исходные вещества: Fe₂O₃ + 3CO → 2Fe + 3CO₂ |
| Внутримолекулярная | Разные элементы одного исходного вещества меняются; для заданных продуктов 4FeSO₄ → 2Fe₂O₃ + 4SO₂ + O₂ |
| Самоокисление-самовосстановление | Один элемент меняется в двух направлениях |

Диспропорционирование: Cl₂ + H₂O ⇄ HClO + HCl, Cl 0 → +1 и −1. Конпропорционирование: SO₂ + 2H₂S → 3S + 2H₂O, S +4 и −2 → 0. Это два направления третьего семейства: одна степень → две или две → одна промежуточная.

![Три семейства ОВР; третье разветвляется на диспропорционирование и конпропорционирование](pics/redox-types.png)

## 5. Полуреакции и среда

Электронный баланс сравнивает степени атомов. Метод полуреакций записывает реальные частицы: сильные растворимые электролиты ионами, слабые электролиты, газы и осадки целыми формулами. Сначала уравняй атомы, затем заряд электронами. HNO₃ в водном ионном уравнении даёт H⁺ и NO₃⁻.

Кислая среда: добавляй H₂O для O, H⁺ для H, затем e⁻ для заряда. MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H₂O. Fe²⁺ → Fe³⁺ + e⁻. Умножь вторую на 5, сложи и сократи электроны: MnO₄⁻ + 8H⁺ + 5Fe²⁺ → Mn²⁺ + 4H₂O + 5Fe³⁺.

Молекулярно: 2KMnO₄ + 10FeSO₄ + 8H₂SO₄ → 2MnSO₄ + 5Fe₂(SO₄)₃ + K₂SO₄ + 8H₂O. Кислота не только среда: её H и O участвуют в балансе.

Нейтральная исходная среда: MnO₄⁻ + 2H₂O + 3e⁻ → MnO₂↓ + 4OH⁻. Сульфит: SO₃²⁻ + H₂O → SO₄²⁻ + 2H⁺ + 2e⁻. После умножения на 2/3 сложи H⁺ и OH⁻ в воду и сократи: 2MnO₄⁻ + 3SO₃²⁻ + H₂O → 2MnO₂↓ + 3SO₄²⁻ + 2OH⁻. Раствор становится щелочным: «нейтральная» описывает начальные условия, а не неизменный pH.

![В изученных реакциях: MnO₄⁻ + H⁺ → Mn²⁺, в нейтральных исходных условиях → MnO₂](pics/permanganate-medium.png)

> [!trap] Два метода записи
> Формальный P⁺³ в электронном балансе не означает свободный ион P³⁺ в растворе. В полуреакции используй реальную формулу вещества; электроны уравнивают суммарный заряд.

## 6. Расчёт по уравнению

Сначала уравнение, затем количество известного вещества, молярное отношение и искомая величина. Для газа при н. у. используй Vₘ = 22,4 л/моль.

> [!example] Металл и вода
> 0,92 г одновалентного металла с водой дают 0,448 л H₂ при н. у.
> 2Me + 2H₂O → 2MeOH + H₂; n(H₂) = 0,448/22,4 = 0,020 моль.
> n(Me) = 0,040 моль; M = 0,92/0,040 = 23 г/моль: натрий.

В сплаве Al/Cu с разбавленной H₂SO₄ в заданных условиях реагирует Al. Из 2 г сплава получено 1,12 л H₂: n(H₂) = 0,05 моль; n(Al) = 2/3 × 0,05; m(Al) = 0,9 г; m(Cu) = 1,1 г, ω(Cu) = 55 %. С концентрированной кислотой это условие уже другое.

> [!rule] Факты ЕНТ недели
> - F в соединениях имеет степень окисления −1.
> - H обычно +1, в гидридах металлов NaH и CaH₂ имеет −1.
> - O обычно −2, в пероксидах −1, в OF₂ имеет +2.
> - Восстановитель отдаёт электроны и окисляется; окислитель принимает и восстанавливается.
> - Число отданных электронов равно числу принятых.
> - По атому серы: S⁻² — восстановитель, S⁺⁶ — окислитель, S⁺⁴ может играть обе роли.
> - Обычный ионный обмен не меняет степеней окисления; замещение металлом другого элемента — ОВР.
> - В изученных условиях MnO₄⁻ в кислой среде даёт Mn²⁺, в нейтральной — MnO₂.

> [!try] Перед вариантом
> По степени S объясни две роли SO₂; затем сравни продукт восстановления MnO₄⁻ в двух объяснённых средах.
