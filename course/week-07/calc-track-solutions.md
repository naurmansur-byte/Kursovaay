# Неделя 7. Расчётный трек — решения

Проверить вместе с вариантом A/B/C после урока 14. Задачи авторские тренировочные; баллы трека учебные и не входят в 34 балла ДЗ. 2 балла — верная модель, ход и ответ; 1 — верная модель и одна вычислительная ошибка; 0 — неверная модель или нет решения. Если задачу не решила половина группы, разобрать её на ближайшем уроке в блоке вопросов.

### Задача 1 — 2 балла

**Ответ:** HCl в избытке, осталось 3,65 г; собрали 3,02 л H₂.

**Решение:** Mg + 2HCl → MgCl₂ + H₂↑. n(HCl) = 14,6 : 36,5 = 0,4 моль; n(Mg) = 3,6 : 24 = 0,15 моль. На 0,15 моль Mg нужно 0,3 моль HCl — кислота в избытке, осталось 0,1 моль = 3,65 г. Считаем по магнию: n(H₂) = 0,15 моль, V = 0,15 × 22,4 = 3,36 л теоретически; 90 % — 3,36 × 0,9 = 3,02 л.

Типичная ошибка: Считать водород по HCl: 0,2 моль, 4,48 л. Коррекция: продукт — по веществу в недостатке.

### Задача 2 — 2 балла

**Ответ:** m(Mg) = 2,4 г, m(Al) = 5,4 г.

**Решение:** n(H₂) = 8,96 : 22,4 = 0,4 моль. Пусть n(Mg) = x, n(Al) = y. Mg даёт x моль H₂, Al — 1,5y моль. Система: x + 1,5y = 0,4; 24x + 27y = 7,8. Из первого x = 0,4 − 1,5y; 24(0,4 − 1,5y) + 27y = 7,8; 9,6 − 9y = 7,8; y = 0,2; x = 0,1. m(Mg) = 2,4 г, m(Al) = 5,4 г; проверка: 7,8 г.

Типичная ошибка: Взять для алюминия 1 моль H₂ на 1 моль металла. Коррекция: коэффициенты по водороду брать из уравнения: 2Al → 3H₂.
