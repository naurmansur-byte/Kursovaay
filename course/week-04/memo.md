# Переходы через моль
= n=m/M; m=nM; M=m/n
= N=nNₐ; n=N/Nₐ
= V=nVₘ; n=V/Vₘ
- Уравнение → данные → пропорция → искомая масса/объём
- По коэффициентам: n₂=n₁×ν₂/ν₁
! Mr без единицы; M — г/моль
! 1 моль H₂O: 2 моль H,1 моль O
! Коэффициенты — моль, а не массы
