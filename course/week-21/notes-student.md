## 1. Углеводы: классификация

Сахар, крахмал картофеля и хлопок — родственники. Что у них общего и почему хлопок не сладкий?

Общая формула углеводов **Cₙ(H₂O)ₘ** — отсюда историческое название «углерод + вода». Есть исключения: дезоксирибоза C₅H₁₀O₄ под формулу не подходит, а формальдегид CH₂O и уксусная кислота подходят, но углеводами не являются.

| Группа | Гидролиз | Примеры | Формула |
|---|---|---|---|
| Моносахариды | не гидролизуются | глюкоза, фруктоза (C₆); рибоза, дезоксирибоза (C₅) | C₆H₁₂O₆; C₅H₁₀O₅; C₅H₁₀O₄ |
| Дисахариды | → 2 моносахарида | сахароза (глюкоза + фруктоза), мальтоза (2 глюкозы), лактоза (глюкоза + галактоза) | C₁₂H₂₂O₁₁ |
| Полисахариды | → много моносахаридов | крахмал, целлюлоза | (C₆H₁₀O₅)ₙ |

![Классификация углеводов: моносахариды (глюкоза, фруктоза, рибоза) — дисахариды (сахароза, мальтоза, лактоза) — полисахариды (крахмал, целлюлоза); стрелки гидролиза справа налево](pics/carb-classes.png)

## 2. Глюкоза и фруктоза

**Глюкоза** — **альдегидоспирт**: одна альдегидная группа –CHO и пять групп –OH; открытая цепь CH₂OH–(CHOH)₄–CHO. Существует и в циклических формах — α и β. **Фруктоза** — изомер глюкозы, **кетоноспирт**: вместо –CHO группа C=O; слаще глюкозы, есть во фруктах и мёде.

![Открытые цепи: глюкоза — шесть атомов C, наверху –CHO, у остальных –OH; фруктоза — C=O у второго атома C](pics/glucose.png)

Глюкоза — белое кристаллическое сладкое вещество, хорошо растворимое в воде, «виноградный сахар»; в крови около 0,1 %. Образуется при **фотосинтезе**: 6CO₂ + 6H₂O → C₆H₁₂O₆ + 6O₂ (свет, хлорофилл); в промышленности — гидролизом крахмала. Сахаристые вещества из формальдегида впервые получил А. М. Бутлеров (1861).

> [!rule] Свойства глюкозы
> Как многоатомный спирт: + свежий Cu(OH)₂ **без нагревания** → ярко-синий раствор.
> Как альдегид: + Ag₂O (аммиачный раствор), t → **серебряное зеркало**; + Cu(OH)₂ **при нагревании** → **красный Cu₂O**; + H₂ → сорбит.
> Спиртовое брожение (дрожжи): C₆H₁₂O₆ → 2C₂H₅OH + 2CO₂↑.
> Молочнокислое брожение: C₆H₁₂O₆ → 2CH₃–CH(OH)–COOH — молочная кислота, без газа.
> В организме: C₆H₁₂O₆ + 6O₂ → 6CO₂ + 6H₂O + энергия.

![Три пробирки с глюкозой: Cu(OH)₂ без нагревания — ярко-синий раствор; Cu(OH)₂ при нагревании — красный осадок Cu₂O; аммиачный Ag₂O — серебряное зеркало](pics/glucose-tests.png)

Применение: питательное и лечебное средство, кондитерское дело, зеркала и ёлочные украшения, получение спирта и молочной кислоты.

> [!trap] Две реакции с Cu(OH)₂
> Без нагревания, синий раствор — несколько –OH рядом (глюкоза, сахароза, глицерин). При нагревании, красный осадок — группа –CHO (глюкоза).

## 3. Сахароза и другие дисахариды

**Сахароза** C₁₂H₂₂O₁₁ — обычный сахар из сахарной свёклы и тростника. С Cu(OH)₂ даёт ярко-синий раствор, но **серебряного зеркала не даёт — она не альдегид**. После кипячения с кислотой раствор даёт красный осадок с Cu(OH)₂ при нагревании: появилась глюкоза.

> [!rule] Гидролиз сахарозы
> C₁₂H₂₂O₁₁ + H₂O → C₆H₁₂O₆ (глюкоза) + C₆H₁₂O₆ (фруктоза) — H⁺ или ферменты.

Из свёклы сахарозу выделяют так: сок + Ca(OH)₂ → сахарат кальция → + CO₂ → CaCO₃↓ и раствор сахарозы. **Мальтоза** (солодовый сахар) — из двух остатков глюкозы; **лактоза** (молочный сахар) — из глюкозы и галактозы.

## 4. Крахмал и целлюлоза

| | Крахмал | Целлюлоза (клетчатка) |
|---|---|---|
| Формула | (C₆H₁₀O₅)ₙ | (C₆H₁₀O₅)ₙ, M — несколько миллионов |
| Звено | остаток α-глюкозы | остаток β-глюкозы |
| Строение | линейное (амилоза) и разветвлённое (амилопектин) | только линейное → волокна |
| Где | запасное вещество растений: зёрна, клубни | оболочки клеток: хлопок, древесина |
| Свойства | белый порошок; в горячей воде — клейстер | волокнистая, не растворяется в воде |
| С йодом | **синее окрашивание** | нет |

![Крахмал: цепочки амилозы и ветвистый амилопектин из шестиугольников-звеньев; целлюлоза: длинные параллельные линейные цепи-волокна; пробирка с крахмалом и йодом — синяя](pics/starch-cellulose.png)

> [!rule] Гидролиз полисахаридов
> Крахмал (H⁺, t или ферменты) → декстрины → мальтоза → глюкоза: (C₆H₁₀O₅)ₙ + nH₂O → nC₆H₁₂O₆.
> Цепочка: крахмал → глюкоза → этанол. В организме гидролиз крахмала начинается во рту.

![Ступенчатый гидролиз крахмала: крахмал → декстрины → мальтоза → глюкоза → брожение → этанол + CO₂](pics/starch-hydrolysis.png)

Образование крахмала из глюкозы сопровождается выделением воды — это **поликонденсация** (подробно — на следующей неделе).

**Эфиры целлюлозы:** с HNO₃ (в присутствии H₂SO₄) — **тринитрат целлюлозы (пироксилин)**, бездымный порох: [C₆H₇O₂(OH)₃]ₙ + 3nHNO₃ → [C₆H₇O₂(ONO₂)₃]ₙ + 3nH₂O; **ацетаты** → ацетатный шёлк. Целлюлоза идёт на бумагу, ткани, спирт, искусственные волокна.

> [!trap] Считай по звену
> Для полисахарида бери звено C₆H₁₀O₅, M = 162 (не глюкозу, 180): n звеньев → n глюкоз. При гидролизе масса растёт — присоединяется вода.

> [!example] Спирт из крахмала
> 81 г крахмала = 0,50 моль звеньев → глюкоза 0,50 моль → этанол 1,0 моль = 46 г и CO₂ 1,0 моль = 22,4 л.

## 5. Амины и анилин

**Амины** — производные аммиака, в которых атомы H замещены радикалами: **первичные** R–NH₂ (метиламин), **вторичные** R₂NH (диэтиламин), **третичные** R₃N (триметиламин). Названия: радикал + **-амин**. Изомерны, например, пропиламин, метилэтиламин и триметиламин.

![Амины: первичный CH₃–NH₂, вторичный (C₂H₅)₂NH, третичный (CH₃)₃N; неподелённая пара электронов у атома азота](pics/amines.png)

Простейшие амины — газы с запахом аммиака, затем жидкости с запахом испорченной рыбы; образуются при гниении белков.

> [!rule] Амины — основания
> Неподелённая пара электронов азота присоединяет H⁺:
> CH₃NH₂ + H₂O ⇄ [CH₃NH₃]⁺ + OH⁻ — лакмус синий;
> CH₃NH₂ + HCl → [CH₃NH₃]Cl — хлорид метиламмония.
> Предельные амины — более сильные основания, чем аммиак. Горение: 4CH₃NH₂ + 9O₂ → 4CO₂ + 10H₂O + 2N₂.

**Анилин C₆H₅NH₂** — бесцветная маслянистая ядовитая жидкость, мало растворим в воде.

- **Реакция Зинина (Н. Н. Зинин, 1842):** C₆H₅NO₂ + 6[H] → C₆H₅NH₂ + 2H₂O — восстановление нитробензола.
- Основание **слабее аммиака**: кольцо оттягивает электронную пару азота; лакмус не окрашивает; с кислотами даёт соли: C₆H₅NH₂ + HCl → [C₆H₅NH₃]Cl.
- С **бромной водой** — **белый осадок** 2,4,6-триброманилина: C₆H₅NH₂ + 3Br₂ → C₆H₂Br₃NH₂↓ + 3HBr.
- Применение: красители, лекарства.

> [!trap] Бромная вода и белый осадок
> Белый осадок с бромной водой дают и фенол, и анилин: группы –OH и –NH₂ облегчают замещение в кольце. Нитробензол — нитросоединение, а пироксилин и нитроглицерин — сложные эфиры.

## 6. Аминокислоты

**Аминокислоты** содержат **аминогруппу –NH₂ и карбоксильную группу –COOH**. **Глицин** (аминоуксусная) H₂N–CH₂–COOH; **аланин** (2-аминопропановая) CH₃–CH(NH₂)–COOH. В белках — остатки 20 α-аминокислот: группа –NH₂ у атома C рядом с COOH. Получают гидролизом белков или из хлоруксусной кислоты: ClCH₂COOH + 2NH₃ → H₂NCH₂COOH + NH₄Cl. Бесцветные кристаллические вещества, хорошо растворимы, многие сладкие.

> [!rule] Амфотерность и пептидная связь
> Как кислота: H₂NCH₂COOH + NaOH → H₂NCH₂COONa + H₂O.
> Как основание: H₂NCH₂COOH + HCl → [H₃NCH₂COOH]Cl.
> COOH одной аминокислоты + NH₂ другой → **пептидная связь –CO–NH–** + H₂O; глицин + аланин → дипептид + H₂O.

![Аминокислота: слева –NH₂ (основная), справа –COOH (кислотная); две аминокислоты соединяются пептидной связью –CO–NH–, выделяется вода](pics/amino-acid.png)

> [!trap] Сколько связей
> В пептиде из n остатков n − 1 пептидных связей. M дипептида = сумма M аминокислот − 18.

## 7. Белки

**Белки** — биополимеры из остатков α-аминокислот, соединённых пептидными связями; M — от 10 000 до нескольких миллионов. Состав: C, H, O, N, обычно S. Гипотезу о пептидной связи высказал А. Я. Данилевский (1888), подтвердил синтезом Э. Фишер. **Простые** белки — только аминокислоты; **сложные** — с небелковой частью (гемоглобин).

| Структура | Что это | Чем удерживается |
|---|---|---|
| Первичная | последовательность аминокислот | пептидные связи |
| Вторичная | спираль | водородные связи |
| Третичная | клубок (глобула) — определяет активность | дисульфидные мостики –S–S–, солевые и водородные связи |
| Четвертичная | несколько цепей вместе | гемоглобин — 4 цепи |

![Четыре структуры белка: цепочка бусин, спираль, клубок, четыре клубка вместе](pics/protein-structure.png)

- Глобулярные белки растворимы (альбумин яичного белка), фибриллярные — нет (кератин волос).
- **Гидролиз** (кислоты, щёлочи, ферменты) → аминокислоты.
- **Денатурация** — разрушение вторичной, третичной и четвертичной структуры **при сохранении первичной**: нагревание, соли тяжёлых металлов, концентрированные кислоты и щёлочи, излучение. Варка яйца — денатурация.

| Цветная реакция | Реактив | Признак | Что обнаруживает |
|---|---|---|---|
| Биуретовая | NaOH + CuSO₄ | фиолетовая окраска | пептидные связи — любой белок |
| Ксантопротеиновая | конц. HNO₃ | жёлтая окраска | аминокислоты с бензольным кольцом |
| Горение | — | запах жжёной шерсти | шерсть, шёлк |

![Пробирки с белком: NaOH + CuSO₄ — фиолетовая; конц. HNO₃ — жёлтая; нагревание — хлопья свернувшегося белка](pics/protein-tests.png)

> [!trap] Гидролиз и денатурация
> Денатурация меняет форму белка, пептидные связи целы. Гидролиз разрывает пептидные связи — до аминокислот.

## 8. Ферменты

**Ферменты** — белковые катализаторы живых организмов. Простые — только белок; сложные — белок + кофермент (витамины группы B, витамин C, микроэлементы).

- **Избирательность:** каждый фермент ускоряет одну реакцию или группу однотипных. **Активный центр** подходит к веществу, как ключ к замку (Э. Фишер).
- **Оптимум температуры** около 40 °C, при 70 °C активность теряется; **оптимум pH**: пепсин — 1,5–2, каталаза крови — около 7.
- Каталаза разлагает пероксид водорода: 2H₂O₂ → 2H₂O + O₂ — «вскипание» раны.
- Применение: сыроварение, хлебопечение, кисломолочные продукты, стиральные порошки, медицина.

## 9. Распознавание и процессы

| Реактив, условие | Признак | Кто даёт |
|---|---|---|
| I₂ | синее окрашивание | крахмал |
| Cu(OH)₂ без нагревания | ярко-синий раствор | глюкоза, сахароза, глицерин |
| Cu(OH)₂ при нагревании | красный осадок Cu₂O | глюкоза; сахароза — только после гидролиза |
| Ag₂O (NH₃), t | серебряное зеркало | глюкоза; сахароза и крахмал — нет |
| NaOH + CuSO₄ | фиолетовая окраска | белки |
| Конц. HNO₃ | жёлтая окраска | белки с ароматическими аминокислотами |
| Бромная вода | белый осадок | анилин (и фенол) |
| Лакмус | синий | растворы предельных аминов; анилин — не меняет |

| Процесс | Что происходит | Пример |
|---|---|---|
| Гидролиз | расщепление водой | сахароза → глюкоза + фруктоза; крахмал → глюкоза; белок → аминокислоты |
| Брожение | расщепление глюкозы микроорганизмами | спиртовое → этанол + CO₂; молочнокислое → молочная кислота |
| Поликонденсация | мономеры → полимер + вода | глюкоза → крахмал; аминокислоты → пептид |
| Денатурация | разрушение пространственной структуры белка | варка яйца |
| Восстановление | присоединение водорода | глюкоза → сорбит; нитробензол → анилин |

Цепочки: CH₄ → C₂H₂ → C₆H₆ → C₆H₅NO₂ → C₆H₅NH₂; крахмал → глюкоза → этанол; CH₃COOH → ClCH₂COOH → глицин → дипептид; CO₂ + H₂O → глюкоза → крахмал.

![Таблица распознавания и цепочка «метан → ацетилен → бензол → нитробензол → анилин» с условиями над стрелками](pics/recognition.png)

> [!rule] Факты ЕНТ недели
> - Моносахариды не гидролизуются; глюкоза и фруктоза C₆H₁₂O₆ — изомеры; глюкоза — альдегидоспирт, фруктоза — кетоноспирт.
> - Сахароза, мальтоза, лактоза — C₁₂H₂₂O₁₁; сахароза → глюкоза + фруктоза, зеркала не даёт.
> - Крахмал и целлюлоза (C₆H₁₀O₅)ₙ: α- и β-глюкоза; крахмал ветвится, целлюлоза линейна; йод → синий — крахмал.
> - Глюкоза: Cu(OH)₂ — синий раствор, при нагревании — красный Cu₂O; серебряное зеркало; H₂ → сорбит; брожение спиртовое и молочнокислое.
> - Пироксилин — тринитрат целлюлозы; ацетатный шёлк.
> - Амины — производные аммиака, основания; анилин — реакция Зинина (1842), слабее аммиака, с бромной водой — белый осадок.
> - Аминокислоты амфотерны; глицин, аланин; пептидная связь –CO–NH–; белки: первичная — пептидные, вторичная — водородные, третичная — –S–S–, четвертичная — гемоглобин; денатурация сохраняет первичную.
> - Биуретовая — фиолетовая, ксантопротеиновая — жёлтая; ферменты — белки, избирательны, оптимум около 40 °C, пепсин pH 1,5–2.
