## Повторение: готовые условия и ключи

**0–5 минут.** Сначала собрать вопросы учеников после конспекта, P1–P6 и общей части ДЗ. В те же пять минут показать MgCl₂ и схему Mg + O₂ → MgO. В MgCl₂ индекс 2 относится к Cl; заданная валентность Mg — II — характеристика для составления формулы, не число атомов. Коэффициент ставится перед целой формулой. Aᵣ берём из справки, Mᵣ вычисляем по одной формуле, оба без единиц; ω = вклад элемента/вся относительная масса. Для уравнивания меняем коэффициенты и проверяем каждый элемент. Соединение — несколько веществ → одно, разложение — одно → несколько. Устный вопрос: «Если газ вышел из открытого сосуда, масса оставшегося содержимого обязана остаться прежней?». **Нет:** система открыта; в общем балансе нужно учесть ушедший газ.

**L9, 5–12 минут.** По заданным Ca(II) и O(II) составьте формулу и найдите её относительную формульную массу. **Ключ:** НОК = 2, индексы 1 : 1, **CaO**, 1·II = 1·II; Mᵣ = 40 + 16 = **56** без единиц. Не оставлять Ca₂O₂: индексы простого соотношения должны быть минимальны.

**L10, 12–20 минут.** а) Для MgO найдите массовую долю O в процентах. б) Дана схема CaCO₃ → CaO + CO₂ при нагревании. Нужны ли коэффициенты, отличные от 1? Назовите тип, подтвердите счёт O. **Ключ:** а) Mᵣ = 24 + 16 = 40, ω(O) = 16/40 · 100% = **40%**. б) коэффициенты 1 : 1 : 1; Ca 1 = 1, C 1 = 1, O 3 = 1 + 2; **разложение**. Заданную формулу CaCO₃ не выводим по валентностям; правило L1 касается только бинарных формул.

## Как разобрать G1 и G4, 20–35 минут

Условия совпадают с [homework](homework.md). Полные критерии — в [решениях](homework-solutions.md). Сначала каждый смотрит свой исходный ход, затем общий ключ.

| ID | Условие для разбора | Ответ и ход |
|---|---|---|
| G1 | Сколько атомов H и O во всей записи 3H₂O? А) H — 3, O — 2; Б) H — 2, O — 1; В) H — 6, O — 3; Г) H — 3, O — 6. При разборе показать подсчёт в одной молекуле и во всех трёх. | **В**. В одной H₂O: H — 2, O — 1; во всей записи H = 3·2 = **6**, O = 3·1 = **3**. Коэффициент умножает число атомов каждого элемента. |
| G4 | Сопоставить: А) Mg(II), Cl(I); Б) Al(III), O(II); В) Ca(II), O(II). Формулы: 1 — Al₂O₃; 2 — CaO; 3 — MgCl₂. Каждую использовать один раз. При разборе объяснить индексы одной из своих формул. | **А3 Б1 В2**. MgCl₂: 1·II = 2·I = **2**; Al₂O₃: 2·III = 3·II = **6**; CaO: 1·II = 1·II = **2**, индексы 1 : 1. НОК 2, 6 и 2 соответственно. |

В 20–23 каждый сравнивает свои попытки, в 23–27 разбираем G1, в 27–31 — G4; в 31–35 каждый повторяет только тот шаг, где ошибся. Разбирать не больше двух общих причин: пропуск коэффициента и перенос валентности без проверки. Ошибку в единицах из G2 оставить для индивидуальной коррекции при необходимости. За один неверный исходный индекс не начислять несколько независимых предметных ошибок в последующих вычислениях; отдельно проверить дальнейший алгоритм. Если ДЗ не выполнено, ученик решает тот же пример с доски и отмечает вопрос, не получает дополнительный полный список.

## Совместная практика: условия и решения

**L11, 6 минут (35–41).** По заданным Mg(II), Na(I) и O(II) составьте Mg/O и Na/O формулы с наименьшими индексами; докажите проверкой. **Решение:** MgO, индексы 1 : 1, 1·II = 1·II = 2; Na₂O, индексы 2 : 1, 2·I = 1·II = 2. Одинаковые индексы не нужны во всех соединениях; они следуют из конкретных данных.

**L12, 9 минут (41–50).** Формула Al₂O₃ дана. Найдите относительную формульную массу и массовую долю O в процентах; проверьте её по доле Al. **Решение:** Mᵣ = 2·27 + 3·16 = 54 + 48 = **102**; ω(O) = 48/102 · 100% ≈ **47,1%**; ω(Al) = 54/102 · 100% ≈ **52,9%**, сумма ≈ 100%. Критерии: учтены оба индекса, Mᵣ без единиц, выделен весь вклад кислорода 48, процент округлён в конце. Ответ 16/102 пропускает индекс 3.

**L13, 8 минут (50–58).** Дана схема Al + O₂ → Al₂O₃ (нагрев). Подберите наименьшие целые коэффициенты, проверьте атомы Al и O, назовите тип. **Решение:** для O ищем общее число 6: слева 3O₂, справа 2Al₂O₃; справа Al — 4, ставим 4Al. **4Al + 3O₂ → 2Al₂O₃**. Al: 4 = 2·2; O: 3·2 = 2·3. **Соединение**: два исходных вещества, один продукт. Здесь НОК применяется к счёту атомов O, а не для получения новой формулы продукта.

**L14, 7 минут (58–65).** Дана схема H₂O₂ → H₂O + O₂; разложение идёт в присутствии катализатора. Все формулы уже даны. Уравняйте и назовите тип. **Решение:** ставим 2 перед H₂O₂ и H₂O: **2H₂O₂ → 2H₂O + O₂**. H: 2·2 = 2·2 = 4; O: 2·2 = 2·1 + 2 = 4. **Разложение**: одно исходное вещество, два продукта. Слово «катализатор» обозначает данное условие над стрелкой; изучать механизм и добавлять его к списку реагентов в этой схеме не требуется. Не заменять H₂O на H₂O₂ и не вычёркивать O₂.

## Индивидуальная попытка и обсуждение, 65–78 минут

**L15.** В замкнутой системе нагревают 10 г CaCO₃. По условию вещество полностью разложилось на CaO и CO₂; масса CaO составляет 5,6 г, газ остался в системе. Найдите массу CO₂ и общую массу продуктов. Почему при выходе газа из открытого сосуда масса остатка не равна исходной массе? **Решение:** m(CO₂) = 10 − 5,6 = **4,4 г**; сумма продуктов 5,6 + 4,4 = **10 г**. В открытом сосуде часть вещества ушла в виде газа; сравнивать только остаток 5,6 г с исходными 10 г нельзя. За сумму/закон 1 учебный балл, массу газа 1, объяснение открытой системы 1. Число 5,6 г дано условием: получать его из коэффициентов пока не требуется.

**L16.** Дана схема H₂ + Cl₂ → HCl; реакция инициируется светом. Подберите наименьшие целые коэффициенты, проверьте H/Cl, назовите тип. **Решение:** **H₂ + Cl₂ → 2HCl**; H 2 = 2, Cl 2 = 2; **соединение**. За коэффициенты 1 учебный балл, проверку обоих элементов 1, тип с объяснением 1. **Только работа на бумаге**: никаких домашних опытов с газами.

Для поддержки: дать таблицы «слева/справа» или строку «начальная масса = масса первого продукта + масса второго». Для устойчивой базы внутри тех же минут спросить: «Коэффициенты 2 : 2 : 4 тоже сохраняют атомы в L16; почему ответ 1 : 1 : 2 предпочтителен?». **Ключ:** делим общий множитель 2, получаем наименьшие целые. Дополнительный вопрос не назначается как обязательная работа поверх времени.
