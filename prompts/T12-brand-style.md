# T12. Фирменный стиль: 3 эскиза на выбор

Небольшое задание: только эскизы, чтобы Мансур выбрал направление. Полный набор (все кадры, обложки, тема для видео) — следующим заданием, в одном выбранном стиле.

## Направление (от Мансура)

Референсы с Pinterest и разбор роликов: `docs/REFERENCE_REELS.md`. Коротко:
- светлый фон «под бумагу» или чёрно-белая гамма;
- крупный жирный текст, один яркий акцент (красный);
- 3D-объект или маскот в центре: колба, атом, молекула;
- субтитры по 1–2 слова, ключевое число выделено акцентом.

Формулы и ход решения — спокойные и читаемые; динамика — только в хуке и на переходах.

## Что сделать

Три стиля:
- **Стиль 1** — светлая бумага, чёрный + красный, 3D-объект.
- **Стиль 2** — чёрно-белый, фактура, кинетический текст.
- **Стиль 3** — спокойный учебный, больше места формулам.

Для каждого стиля:
1. **Палитра** (HEX) и **шрифты** с кириллицей и лицензией для коммерческого использования (например, OFL с Google Fonts).
2. **Аватарка:** PNG 1080×1080, должна узнаваться в круге 110 px. Можно сделать маскота.
3. **Два кадра Reels** (PNG 1080×1920) на материале `content/reels/R001-moles-h2so4/`:
   - обложка-хук: крупный заголовок, болевое слово в красной плашке;
   - шаг решения: `M(H_2SO_4) = 2\cdot1 + 32 + 4\cdot16 = 98` г/моль (через KaTeX) и строка субтитров.

Делай как удобнее: HTML + CSS + KaTeX с рендером в PNG или Remotion. На красоту исходников время не трать.

## Результат

- `content/brand/style-1/`, `style-2/`, `style-3/`: `avatar.png`, `frame-hook.png`, `frame-formula.png`.
- `content/brand/README.md`: по 2–3 строки о каждом стиле, палитра, шрифты, лицензии.
- `STATUS.md`: `нужно решение Мансура: выбрать стиль 1/2/3`.

## Критерии приёмки

- Формулы верные и набраны KaTeX, а не картинкой.
- На кадрах нет текста мельче 40 px.
- Шрифты и изображения разрешены для коммерческого использования.

## Чего не делать

- Не делать остальные кадры, обложки «Актуального», закреплённые посты и тему для видео: это следующее задание.
- Не входить в Instagram.
