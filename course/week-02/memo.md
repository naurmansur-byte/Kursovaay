# Формула и масса
= Mg(II), Cl(I) → MgCl₂
= Al(III), O(II) → Al₂O₃
- Индексы — **наименьшие целые**
- Валентность — **без знака**, не заряд иона
= Mᵣ(Al₂O₃) = 2·27 + 3·16 = 102
- Mᵣ — сумма Aᵣ с учётом **индексов**, без единиц
! Коэффициент не входит в Mᵣ одной молекулы или формульной единицы
> MgO и Al₂O₃: относительная формульная масса

# Доля и реакция
= ω(E) = N·Aᵣ(E) ÷ Mᵣ
- N — число атомов элемента **в одной формуле**
= MgO: ω(O) = 16/40 = 0,4 = 40 %
= 2Mg + O₂ → 2MgO (нагрев)
- **Соединение:** несколько веществ → одно; **разложение:** одно → несколько
- В замкнутой системе **масса сохраняется**
! Меняй коэффициенты, а не индексы
> Каждый элемент: число атомов слева = числу справа
