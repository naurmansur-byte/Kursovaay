# Входящие Мартина

Здесь всегда одна текущая задача. Её обновляет Макс. Мансур пишет Мартину одну и ту же фразу: «Сделай git pull и выполни prompts/INBOX.md».

Правила (см. `AGENTS.md`): одна задача за раз; только то, что в задаче; если лимит заканчивается — закоммить сделанное и отметь в `STATUS.md`, что осталось.

## Текущая задача — серия из 6 задач (решение Мансура 16.10: у Мартина полный лимит, делать больше за один запуск)

Выполняй задачи **по порядку, одну за другой**, без ожидания проверки Макса:

Порядок работы:

1. Перед каждой задачей — `git pull`. Макс выкладывает выжимки и задания T29–T32 по мере готовности.
2. Сделал задачу → строка в `STATUS.md` «ждёт проверки Макса» → коммит `TNN: …` → `git push`. Только потом бери следующую.
3. Если файла следующего задания ещё нет в `prompts/` — остановись и коротко напиши Мансуру: «T… сделаны, жду T…».
4. Если лимит кончается посреди задачи — закоммить готовые файлы и отметь в `STATUS.md`, что осталось.
5. Каждая задача — по своей выжимке и `docs/STYLE.md`. Правила из прошлых проверок: пробелы не склеивать; ключи «несколько ответов» разные; ДЗ — новые числа, не примеры конспекта; образец строки теста — заведомо неверными буквами; в материалах не писать «по выжимке» / «в выжимке».

(T27 принят 16.10 без правок: ключи, Гиллеспи и решётки верны — продолжай серию с T28.) (T26 принят 15.10: ключи, ABO, маршруты крови и расчёты верны, ошибки учебников не перенесены. Макс убрал две служебные пометки «в выжимке».)
