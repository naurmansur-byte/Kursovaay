## Что делать с картой

1. Выпиши три темы с наименьшей долей набранных баллов.
2. По каждой — раздел недели из таблицы и одно задание из ДЗ той недели заново.
3. На уроке разбора принеси вопросы по этим темам. Пробник 2 построен по тому же плану: сравни баллы по темам.
