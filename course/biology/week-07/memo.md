# Не смешивай процессы
- Вентиляция обновляет воздух; диффузия переносит газы через поверхность
- Клеточное дыхание преобразует вещества и энергию
= Вдох: диафрагма вниз → объём больше → давление ниже → воздух входит
= Спокойный выдох: расслабление → объём меньше → воздух выходит
- В лёгких O₂ в кровь, CO₂ в альвеолу; в тканях наоборот
= Vмин = ДО × частота; 1000 см³ = 1 л
! Минутная вентиляция — весь воздух, не поглощённый O₂
! ЖЕЛ не равна ДО и не включает остаточный объём

# Факты ЕНТ недели
- Насекомые — трахеи; рыбы — жаберные лепестки с капиллярами
- Лягушка — кожа и лёгкие; птицы — двойное дыхание, воздушные мешки
- Трахея — полукольца; надгортанник помогает закрыть гортань при глотании
- Учебный воздух: O₂ 20,95 → 16 %; CO₂ 0,03 → 4 %
- Газообмен альвеол/тканей — диффузия
- Центр — продолговатый мозг; рост CO₂ усиливает дыхательный ответ
- Вдох активный; спокойный выдох обычно пассивный
- ЖЕЛ — спирометр; туберкулёз — палочка Коха
