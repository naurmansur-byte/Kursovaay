# Как подключить Obsidian к этому проекту

Obsidian не «подключается» к Claude Code через API или плагин — он просто
открывает папку на диске как *vault* (хранилище) и показывает все `.md`-файлы
в ней со связями, тегами и графом. Скилы Claude Code (`.claude/skills/**/SKILL.md`)
— это обычные markdown-файлы, поэтому один и тот же каталог одновременно:

- читается Claude Code как список скилов, доступных в этом проекте;
- редактируется в Obsidian как обычные заметки, с графом связей, обратными
  ссылками и тегами.

Никакой отдельной интеграции ставить не нужно — важно только *что* открыть
как vault.

## Шаги

1. Установи Obsidian: https://obsidian.md (Win / macOS / Linux, есть портативная
   версия без установки).
2. В приложении: **Open folder as vault** → выбери корень этого репозитория
   (папку `Kursovaay` целиком, а не только `.claude/skills`). Так в графе будут
   видны связи между скилами, главами курсовой и источниками.
3. Если Obsidian спросит про доверие к содержимому vault — подтверди, это твой
   репозиторий.
4. В файловом дереве слева появится `.claude/skills/kursovaya-writing/` —
   открой `SKILL.md` и `context.md`, заполни под свою тему.

## Почему `.claude/skills/`, а не `~/.claude/skills/`

- `.claude/skills/` в корне репозитория — скилы **только для этого проекта**:
  видны Claude Code, когда сессия запущена внутри этой папки, и переезжают
  вместе с репозиторием (например, через `git clone` на другой машине).
- `~/.claude/skills/` в домашней папке — глобальные скилы, подключаются во
  всех проектах сразу. Не подходит, если скил должен жить именно с этим
  репозиторием.

## Структура репозитория для работы в Obsidian

- `plan.md` — план курсовой (создать по мере согласования структуры).
- `chapters/` — по одному файлу на главу (`chapters/01-vvedenie.md`, …).
- `sources.md` или отдельные заметки с тегом `#source` — список литературы;
  так можно строить обратные ссылки «глава → источник» прямо в графе Obsidian.

## Полезные, но необязательные плагины Obsidian

- **Templater** — шаблон для новой главы одной командой.
- **Dataview** — сводная таблица со статусом глав («черновик» / «готово»)
  прямо в заметке-плане.

## .gitignore

Локальные настройки Obsidian (`workspace.json`, кэш, раскладка панелей)
не имеет смысла коммитить — они не переносятся между машинами и часто
меняются. Каталог `.obsidian/` уже добавлен в `.gitignore` этого репозитория.
