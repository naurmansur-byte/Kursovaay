# Алгоритм и выбор модели

- 1) Уравнение или схема. 2) Всё в моль. 3) Недостаток. 4) Коэффициенты. 5) Величина с выходом. 6) Проверка смысла.
- Один реагент — прямой расчёт; оба реагента — избыток и недостаток.
- Смесь с общим продуктом — система: по массе смеси и по продукту.
- Цепочка — схема по сохраняющемуся элементу.
- Раствор с газом или осадком — масса раствора минус газ и осадок.
= Общий выход = произведение выходов стадий
! Отрицательное x или доля больше 100 % — ищи ошибку.

# Схемы, растворы, олеум

- N₂ → 2HNO₃; NH₃ → HNO₃; FeS₂ → 2H₂SO₄; S → H₂SO₄; Ca₃(PO₄)₂ → 2P.
- Al → 1,5 H₂; Mg, Fe, Zn → 1 H₂; Cu с HCl не реагирует.
- Масса раствора после реакции = сумма масс − газ − осадок.
- n(NaOH) : n(CO₂) = 1 : 1 → NaHCO₃; 2 : 1 → Na₂CO₃; между — смесь.
- Олеум: SO₃ + H₂O → H₂SO₄, 80 г → 98 г; кислота олеума тоже входит в итог.
= Руда: масса чистого = ω · масса образца; для сырья делим на долю и на выход
! Соль выбирают по количествам, а не по массам.

# Модели недель 4–22

- V = n · 22,4; D = M₁/M₂; M(воздуха) = 29.
- pV = nRT: R = 8,314; p — кПа, V — л, T — К (t + 273).
- ω = m(в-ва)/m(р-ра); η = m(практ.)/m(теор.).
- Электролиз CuSO₄: Cu на катоде, O₂ на аноде; 2Cu на 1O₂.
- Тепловой эффект пропорционален количеству вещества.
- Вант-Гофф: v₂/v₁ = γ^((t₂ − t₁)/10).
- Равновесие: стало = было − прореагировало; Ле Шателье.
- Формула: по ω, горению (n(H) = 2n(H₂O)), плотности, реакции.
