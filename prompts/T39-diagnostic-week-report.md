# T39. Диагностическая неделя 20–27 октября: отчёт родителю, лист подсчёта и правка «группы по 5»

Исполнитель: Мартин. Срочно: диагностическая неделя начинается 20.10, итоги родителям — 27.10. Учебники не нужны — всё по готовым файлам диагностики.

## Контекст (решения Мансура 17.10)

- Бесплатная **диагностическая неделя** 20–27 октября: до 20.10 ученик проходит входную диагностику (28 заданий по химии и 28 по биологии, по 40 минут), затем 4 урока по расписанию курса (биология 20 и 23.10, химия 22 и 26.10), ДЗ с проверкой, **27.10 — итоги родителю**: уровень A/B/C по каждому предмету, результат по 6 блокам, разбор ошибок, с чего начинать.
- Это **стартовая карта знаний, а не прогноз балла ЕНТ** — так и пишем.
- **Групп по 5 человек не будет.** Размер группы нигде не указываем — ни в материалах, ни в текстах.

## Прочитай

- `course/diagnostic/teacher.md` и `student.md` — химия: блоки, баллы, уровни A/B/C, рекомендации по блокам
- `course/biology/diagnostic/teacher.md` и `student.md` — биология: то же
- `docs/STYLE.md` — тон и правила текстов

## Что сделать

1. **Отчёт родителю — шаблон**, `course/diagnostic/parent-report.md`. Одна страница на ученика, оба предмета:
   - уровень по химии и по биологии (A — база устойчива, B — нужна адресная практика, C — нужна поддержка основы) и сумма из 28;
   - таблица 6 блоков каждого предмета: балл из максимума, уровень блока, одна строка «что получается / что подтянуть» — формулировки возьми из рекомендаций по блокам в `teacher.md`, сократи до понятных родителю;
   - 3–5 конкретных ошибок ученика (поле для заполнения) с пояснением простыми словами;
   - «С чего начинаем» — 2 шага по каждому предмету и уровень ДЗ (A/B/C);
   - строка «Это стартовая карта знаний, а не прогноз балла ЕНТ»;
   - **пример заполнения** с выдуманными баллами, явно подписанный «Пример»: химия 3,5 / 4 / 2,5 / 2 / 3 / 2 (сумма 17 → уровень B по правилам `teacher.md` — проверь), биология — подбери сам и проверь уровень по правилам.
2. **Лист подсчёта для преподавателя**, `course/diagnostic/score-sheet.md` + файл `course/diagnostic/score-sheet.csv` для импорта в Google Таблицы: строка = ученик (только имя и класс), столбцы = баллы по 28 заданиям химии и 28 биологии, суммы по блокам, уровень блока, сумма, общий уровень — **формулами** по правилам `teacher.md` (порядок C → A → B, пороги без округления). В `.md` — как импортировать, какие столбцы, 3 проверочных примера из таблиц `teacher.md` (уровни должны совпасть).
3. **Короткое сообщение родителю 27.10**, `course/diagnostic/parent-message.md`: 5–7 строк для Telegram/WhatsApp — итог, ссылка «подробный отчёт — во вложении», приглашение продолжить с 2 ноября. Без давления, без обещаний баллов, без скидки (цену Мансур говорит сам).
4. **Убрать «группы по 5» и размер групп** везде, где он упоминается как факт о курсе: `course/diagnostic/teacher.md` и `course/biology/diagnostic/teacher.md` (раздел про «четыре группы по пять» → «как подобрать уровень ДЗ и стартовую практику по результату»), `course/teacher-pack/00-start.md`, `course/PROGRAM.md` и `course/biology/PROGRAM.md` (если есть), `content/instagram/*.md`, `content/youtube/*.md`. Найди: `grep -rn "по 5\|по пять\|четыре группы\|4 групп" course content docs`. Числа «по 5» в задачах и фактах не трогай — только размер групп. Новый размер группы **не придумывай**.
