# Y002 — промо-ролик YouTube (концепция, 13.10.2026)

Решение Мансура: YouTube-ролик должен **заинтересовать курсом**, а не просто дать знание. Видео-урок Y001 («Моль за 10 минут», слайды + голос) — «слишком скучно, как презентация». Нужен настоящий ролик с моушн-эффектами, как Reels.

## Формат

- 16:9, 1920×1080, около 4 минут; стиль 2 (как Reels): кинетический текст, красные плашки, атом, удары, звуки (`public/sfx`), голос Edge TTS.
- Сборка — Remotion, переиспользовать `video/src/kit.jsx` и `scenes.jsx`, но под горизонтальный кадр: ширина и поля из `useVideoConfig`, а не 1080 (сейчас `Kinetic` подгоняет шрифт под 1080 − 2·SAFE.x).

## Сценарий по блокам

1. **Хук (0:00–0:15):** «40 заданий. 80 минут. Химия.» → плашка «Почему её боятся?»; атом, свист, удар.
2. **Боль (0:15–0:45):** три карточки «почему теряют баллы» — формулы без смысла / теряются в условии / ловушки; на каждую мини-пример (ловушка индекса 4: 50 вместо 98).
3. **«Вау» на задаче (0:45–2:30):** одна сложная задача ЕНТ (например, R002 — формула по продуктам сгорания) решается анимированно: числа влетают, стрелки, подсветка, ловушка красным, удар на ответе.
4. **Курс (2:30–3:30):** настоящие материалы влетают в кадр (слайды урока `exports/week-01/lesson-1-png`, конспект, памятки `exports/week-01/memo`); шкала «ноябрь → май: 23 темы + пробники»; «группы по 5», «2 урока в неделю», «ДЗ с проверкой».
5. **Призыв (3:30–4:00):** «Старт 1 ноября · группы по 5 человек · пиши в директ @himiya.prosto» + «Подпишись». Без цен, «осталось N мест» и обещаний балла.

## Факты, которые можно говорить

ЕНТ по химии: 40 заданий, около 80 минут (спецификация НЦТ 2026). Курс: онлайн (Google Meet), 2 урока по 90 минут в неделю, группы по 5, ДЗ с проверкой, Telegram, пробники, старт 1 ноября, программа ноябрь–май (23 темы + 2 пробника).
