# Неделя 20. Расчётный трек — решения

Проверить вместе с вариантом A/B/C после урока 40. Задачи авторские тренировочные; баллы трека учебные и не входят в 34 балла ДЗ. 2 балла — верная модель, ход и ответ; 1 — верная модель и одна вычислительная ошибка; 0 — неверная модель или нет решения. Если задачу не решила половина группы, разобрать её на ближайшем уроке в блоке вопросов.

### Задача 1 — 2 балла

**Ответ:** η = 80 %.

**Решение:** n(CH₃COOH) = 12 : 60 = 0,2 моль; n(C₂H₅OH) = 13,8 : 46 = 0,3 моль — кислота в недостатке. Теоретически эфир 0,2 × 88 = 17,6 г; η = 14,08 : 17,6 = 80 %.

Типичная ошибка: Считать по спирту: 26,4 г и 53 %. Коррекция: продукт — по недостатку.

### Задача 2 — 2 балла

**Ответ:** ω(CH₃COONa) = 12,8 %.

**Решение:** n(CH₃COOH) = 12 : 60 = 0,2 моль; n(NaHCO₃) = 16,8 : 84 = 0,2 моль — по уравнению. CH₃COONa 0,2 × 82 = 16,4 г; CO₂ 0,2 × 44 = 8,8 г. m(раствора) = 120 + 16,8 − 8,8 = 128 г; ω = 16,4 : 128 = 12,8 %.

Типичная ошибка: Не вычесть CO₂: 16,4 : 136,8 = 12,0 %. Коррекция: газ уходит из раствора.
