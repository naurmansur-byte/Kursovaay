# Экспорт учебного комплекта для проверки

Из корня репозитория:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install --no-input -r tools/export-requirements.txt
.venv/bin/python tools/export_lesson_kit.py --week week-01
```

В подготовленной облачной среде эти версии уже доступны; проверенный запуск: `python3 tools/export_lesson_kit.py`. Python 3.12, DejaVu Sans для PDF (`/usr/share/fonts/truetype/dejavu/`); python-docx 1.2.0, python-pptx 1.0.2, ReportLab 4.4.9. Экспорт не обращается к Google и не собирает данные учеников.

Результат в игнорируемой `exports/week-01/`: отдельные DOCX ученика и преподавателя, PDF конспекта и PPTX с заметками. В ученическую версию quiz ключ не включается. Исходный Markdown остаётся источником содержания; при правках экспорт повторить. Загружает/импортирует владелец в свою папку проекта, реальную ссылку записывает в STATUS.md. Проверить вёрстку после импорта: Word/Docs могут иначе переносить строки.

PowerPoint использует установленный Максом стиль 2 из [STYLE](../docs/STYLE.md): фон `#151515`, текст `#F3F0E8`, акцент `#F13A43`, заголовки Unbounded, основной текст Manrope. Шрифты записаны по имени, в PPTX не встроены: для верного отображения нужно установить Unbounded и Manrope на компьютере просмотра; при подстановке шрифта проверить переносы. Готовые файлы текущего задания копировать из `exports/week-NN/` в `deliverables/TNN/` перед коммитом.

Проверено 12.10.2026: контейнеры DOCX/PPTX открываются соответствующими библиотеками, 16 слайдов сохраняют заметки, PDF конспекта занимает четыре страницы A4. Публикации и предметного утверждения это не означает. Для других недель заполнить структуру из `course/LESSON_KIT_TEMPLATE.md`; заголовки конспекта «Страница N из …» задают явные разрывы, слайды имеют блоки «Текст ученику» и «Заметки преподавателю».
