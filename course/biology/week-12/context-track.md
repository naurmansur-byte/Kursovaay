15 минут после урока 24. Задание в формате ЕНТ 26–30: прочитай контекст — митоз в корешке лука — и ответь на четыре вопроса, в каждом один верный ответ. Ответы пришли строкой в Telegram вместе с вариантом A/B/C: `К: 1… 2… 3… 4…`. Решения открывай после попытки.

**Как читать опыт:** что меняли → что было одинаковым → контроль → что показали данные → вывод только в пределах данных.

### Контекст

В препарате кончика корня лука подсчитали 200 клеток. У лука 2n = 16. Данные условные.

| Фаза | Число клеток |
|---|---|
| интерфаза | 160 |
| профаза | 20 |
| метафаза | 8 |
| анафаза | 5 |
| телофаза | 7 |

**1. Один ответ.** Какая доля клеток препарата в интерфазе?

- А) 16 %.
- Б) 20 %.
- В) 50 %.
- Г) 80 %.

**2. Один ответ.** В какой фазе двухроматидные хромосомы выстроены на экваторе?

- А) Метафаза.
- Б) Профаза.
- В) Анафаза.
- Г) Телофаза.

**3. Один ответ.** Сколько хромосом в каждой дочерней клетке после митоза?

- А) 8.
- Б) 16.
- В) 32.
- Г) 4.

**4. Один ответ.** Какой вывод верен?

- А) Все клетки лука делятся одновременно.
- Б) Анафаза у всех растений длится одну минуту.
- В) В этом препарате большинство клеток — в интерфазе.
- Г) Интерфаза — фаза митоза.
