# R001 — вариант B: Динамичный

**Черновик сценария, 12.10.2026.** Авторская задача, не материал НЦТ. Решение и химический чек-лист — [solution.md](solution.md); условие — 49 г чистой H₂SO₄.

Шесть сцен: вопрос → условие → смысл метода → расчёт и ошибка → ответ и проверка → ответ и приглашение. Озвучка: **109 слов**, ориентир **43,6 с** при 150 слов/мин. Счёт — словесные токены без знаков пунктуации; ЕНТ считается одним токеном, но произносится тремя названиями букв. Фактическое аудио может быть длиннее. Точность тайминга проверяется и корректируется после синтеза в T06; речь не обрезать. Последняя сцена — 16 слов, около 6,4 с; включает ответ и точный CTA.

Предложение дизайна: светлый фон, тёмный текст, отдельные акценты для данных и результата. Один голос для всех стилей; стиль Мансур пока не выбрал. Каждая формула в экранном столбце дана LaTeX для KaTeX; последовательные строки не обязаны быть видны одновременно. Расположение субтитров и размер шрифта проверяются по реальному рендеру на телефоне.
