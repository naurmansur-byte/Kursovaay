# Передача следующему ИИ

## Приоритет

Последний запрос владельца: очистить текущее содержимое Kursovaay и загрузить контекст для продолжения с другим ИИ. Сделано через замену дерева файлов одним обычным коммитом; история прежнего проекта сохранена.
Это документационный старт проекта, а не готовое приложение.

Последние решения после опроса:
- Учебные материалы и программу Мансур планирует доделывать с другим ИИ.
- В текущем диалоге работа сосредоточена на Reels.
- Для другого ИИ требуется техническая инструкция по реализации видео.
- Репозиторий выбран владельцем: https://github.com/naurmansur-byte/Kursovaay
- Предложено начать с одной задачи в трёх стилях. Конкретная задача и окончательный стиль ещё не выбраны.

## Подтверждённые требования к видео

Русский язык, школьники 11 класса Казахстана, ЕНТ. ИИ-озвучка, формулы, задачи и анимация; ведущий в кадре не обязателен.
Instagram: полностью объяснить одно задание/ошибку/понятие. YouTube: 7–10 минут на тему или тип задач.
Цель публикаций: 5 коротких роликов и 1 длинное видео в неделю. Это план, не действующее расписание автоматизации.
Три стиля для сравнения: спокойный пошаговый, динамичный, объяснение через аналогию с лёгким юмором.
Призыв: написать в личные сообщения для записи на курс.
Мансур утверждает материалы и публикует их. Автопубликацию и подключения аккаунтов не считать настроенными.

## Первая задача по видео

1. Изучить VIDEO_PRODUCTION.md.
2. Взять один проверенный сценарий, если он предоставлен. Если нет — предложить одну авторскую учебную задачу, пометить её происхождение, решить и проверить; не называть её официальным заданием ЕНТ.
3. Подготовить одинаковое химическое содержание в трёх стилях, меняя только подачу.
4. Выбрать доступный стек, проверить его текущую документацию, стоимость и наличие инструментов. Не подписывать платные сервисы без согласования покупки.
5. Реализовать один воспроизводимый короткий ролик или, если озвучка недоступна, явно обозначенный черновик с временным звуком/без звука.
6. Передать видео, сценарий, исходники и команду рендера. После выбора стиля сделать пакетный процесс.
Не разрабатывать большую систему до появления первого просмотренного ролика.

## Если владелец поручает учебное направление

Начать с полного образца «Количество вещества. Моль. Молярная масса», затем проверить с преподавателем и только после этого масштабировать.
Состав: карта навыков/задач, конспект, работа до урока, два плана по 90 минут, презентация, домашка разных уровней, решения, контроль.
Готового комплекта пока нет. Источники и конкретные ориентиры есть в SOURCES.md.
Программа ноябрь 2026 — май 2027, 4 группы по 5, два урока в неделю. Не считать 56 или 64 занятия утверждёнными.
Преподаватель найден и может участвовать. Ответственный за окончательную предметную проверку ещё не закреплён.
