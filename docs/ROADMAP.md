# Дорожная карта запуска «ХимБио просто»

Утверждено владельцем 12.10.2026. Этот документ важнее более ранних планов в `docs/NEXT_AGENT.md` и `docs/PROJECT_HANDOFF.md`, если они противоречат друг другу.

## Цель

Запустить курс подготовки к ЕНТ по химии **строго 1 ноября 2026**: 2 урока по 90 минут в неделю, Google Meet + Telegram. Параллельно вести Instagram (Reels) и YouTube для набора учеников.

## Главное следствие срока

К 1 ноября невозможно подготовить материалы на 2–3 месяца вперёд. Поэтому:
- к старту готовы **программа всего курса** (каркас) и **уроки первых 2 недель**, проверенные преподавателем;
- дальше работаем «скользящим запасом»: в неделю N идут уроки, преподаватель проверяет неделю N+1, агент готовит неделю N+2;
- **образец комплекта — уроки 1-й недели**, а не тема «Моль». «Моль» делается в общем порядке программы.

## Роли

- **Макс (Claude)** — руководитель работ: работает с Мансуром напрямую, планирует, пишет задания (`prompts/`), проверяет результат и критерии приёмки, выборочно пересчитывает химию.
- **Мартин (ИИ-агент-исполнитель)**: по одной небольшой задаче за раз, у него тоже есть лимит; выполняет задания из `prompts/`, коммитит результат в этот репозиторий, выкладывает версии для учеников и преподавателя на Google Диск, обновляет `STATUS.md`.
- **Мансур**: передаёт задания, принимает решения, ведёт запись и публикации, утверждает материалы.
- **Преподаватель**: проверяет химию и уроки до выдачи ученикам.

## Как устроена работа

1. Claude кладёт задание в `prompts/TNN-*.md`.
2. Мансур пишет агенту: «Выполни prompts/TNN-….md».
3. Агент делает работу, коммитит её и обновляет `STATUS.md`.
4. Мансур пишет Claude: «Проверь TNN».
5. Claude отвечает «принято» или пишет список правок (новым заданием или правкой старого).

Структура репозитория:
- `prompts/` — задания;
- `course/` — программа, диагностика, уроки по неделям (`course/week-01/` …);
- `content/instagram/`, `content/reels/<id>/`, `content/youtube/<id>/` — контент;
- `video/` — проект Remotion;
- `exports/` — рендеры, в Git не попадают (храним на Диске);
- `STATUS.md` — состояние всех заданий и решения, которые ждут владельца.

## Неделя 1 (12–18 октября): основа и старт набора

- Решения Мансура: список в `STATUS.md`.
- T01 — программа и календарь (ноябрь–май, 90 минут).
- T02 — входная диагностика с ключами и правилами распределения по группам.
- T03 — образец комплекта: неделя 1, уроки 1–2 (после T01). Сразу передаётся преподавателю.
- T04 — Instagram: профиль, предложение курса, ответы в директ, анкета записи.
- T05 — пилотный Reels: сценарий одной задачи в трёх стилях.
- T06 — видеоконвейер Remotion + KaTeX + Edge TTS, рендер трёх вариантов пилота (после T05).

## Неделя 2 (19–25 октября): проверка образца и поток контента

- Преподаватель проверяет T03; после правок комплект становится шаблоном.
- T07 — уроки недели 2 по шаблону.
- Мансур выбирает стиль Reels; T08 — пакет из 5 Reels в неделю по темам первых недель курса.
- T09 — первое YouTube-видео (7–10 минут).
- Открывается запись: анкета → диагностика → ответы в директ.

## Неделя 3 (26 октября – 1 ноября): подготовка к старту

- Диагностика записавшихся, распределение по 4 группам.
- T10 — уроки недели 3; преподаватель проверяет неделю 2.
- T11 — оргпакет: правила для учеников и родителей, расписание, Telegram (4 группы + канал), ссылки Meet, порядок сдачи ДЗ, проверка записи Meet.
- 1–2 ноября — первые уроки.

## После старта (каждую неделю)

- Скользящий запас уроков и рубежные проверки по программе.
- 5 Reels и 1 YouTube-видео в неделю пакетом; темы привязаны к неделям курса.
- Раз в неделю Claude проверяет `STATUS.md` и выдаёт следующие задания.

## Риски

- **Провести набор учеников за 3 недели.** Контент должен выходить с первой недели. Решение о старте при неполном наборе принимает Мансур.
- **Проверка преподавателем — узкое место.** Сразу договориться о времени на проверку.
- **Точность химии.** Ничего не выдаётся ученикам и не публикуется без проверки; авторские задачи не выдаются за официальные.
- **Лицензия Edge TTS** для коммерческих публикаций: проверить до первой публикации.
