# Справочная карта условий

- Свет: алканы — замещение галогеном; бензол — присоединение (гексахлоран).
- FeCl₃ / FeBr₃: бензол, толуол — замещение в кольце.
- Конц. HNO₃ + конц. H₂SO₄: нитрование бензола, толуола (тротил).
- Ni, Pt: гидрирование алкенов, алкинов; бензол — при нагреве и давлении.
- H₂SO₄ / H₃PO₄: алкен + вода → спирт. HgSO₄: ацетилен + вода → альдегид.
- 600 °C: 3C₂H₂ → C₆H₆. Аммиачный Ag₂O: осадок с концевой тройной связью.
= Бромная вода: алкены, диены, алкины — да; алканы, бензол — нет
! KMnO₄: алкены, алкины, толуол — да; алканы, бензол, полиэтилен — нет.

# Факты ЕНТ недели

- Алкены CₙH₂ₙ, σ + π, sp²; цис-транс у бутена-2; Марковников, 1869: H — к CH₂=.
- Полиэтилен — термопласт, предельный; n = M(полимера) / M(звена).
- Лебедев, 1932 — бутадиен и синтетический каучук; каучук + сера → резина.
- Алкины CₙH₂ₙ₋₂, sp, 180°; CaC₂ + 2H₂O → C₂H₂; Кучеров, 1881 — альдегид.
- Бензол: Фарадей 1825, Кекуле 1865; 0,140 нм; C₈H₁₀ — 4 изомера.
- Природный газ — до 98 % CH₄; коксование без воздуха — кокс, смола, аммиачная вода, газ.
- Бензин 40–200, лигроин 150–250, керосин 180–300, газойль 250–350, мазут > 350 °C.
- Перегонка — физическая, крекинг — химический (Шухов); октановое: гептан 0, изооктан 100.
