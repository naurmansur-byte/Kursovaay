### Тетрадь — 18 минут

**G9. Фото решения.** Пройди ключ и запиши путь по номерам ступеней для трёх растений: а) корневище, спорангии на нижней стороне листьев; б) хвоя, семена лежат открыто на чешуях шишек; в) в воде зелёная пластина без органов.

```
1. Тело — слоевище, нет органов → водоросли
0. Есть органы и ткани → 2
2. Есть цветок и плод → покрытосеменные
0. Цветков нет → 3
3. Семена открыто на чешуях шишек → голосеменные
0. Семян нет, споры → 4
4. Корней нет, ризоиды, коробочка → моховидные
0. Корневище, споры на листьях → папоротниковидные
```

На экскурсии нашли: А — животное с 3 парами ног, 1 парой усиков и твёрдыми надкрыльями; Б — животное с 4 парами ног без усиков; В — растение со стержневым корнем, сетчатым жилкованием и цветком из 5 лепестков с чашечкой; Г — гриб с плодовым телом из шляпки и ножки. Отнеси каждый организм к группе (класс или группа грибов) и назови по два признака, по которым ты это сделал.
