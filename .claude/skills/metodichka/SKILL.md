# Методичка — источник правил оформления

Хранит правила из официальной методички курсовой и делает их удобными для
сверки на каждом шаге. Скил `kursovaya-writing` при работе над текстом
опирается на этот скил как на источник правил — сначала сверяется с ним,
и только потом с общими умолчаниями по ГОСТ.

## Файлы

- `rules.md` — сжатая выжимка правил, извлечённая из методички. Основной
  источник, с которым нужно сверяться на каждом шаге.
- `source.<pdf|docx>` — оригинал методички (появится, когда пользователь
  пришлёт файл), лежит рядом для сверки, если извлечение в чём-то
  расходится с оригиналом.

## Если rules.md пуст или методички ещё нет

Правила ещё не загружены. Работай по разумным умолчаниям (см.
`kursovaya-writing`: ГОСТ 7.32-2017 для структуры, ГОСТ Р 7.0.100-2018
для списка литературы), но при первой уместной возможности напомни
пользователю прислать файл методички — чтобы дальше работать по точным
требованиям его вуза/кафедры, а не по общим умолчаниям.

## Когда пользователь присылает файл методички

1. Сохрани присланный файл как `source.<расширение>` в этой же папке.
2. Прочитай его целиком и извлеки в `rules.md` конкретные, проверяемые
   правила:
   - структура работы и обязательные разделы;
   - требования к оформлению (шрифт, интервал, поля, нумерация страниц);
   - объём (в страницах/словах), в т.ч. по главам, если указано;
   - требования к списку литературы и цитированию;
   - сроки и этапы сдачи, если есть;
   - любые специфичные требования кафедры/научного руководителя.

   Не выдумывай ничего, чего нет в тексте методички — если пункт не
   описан, явно отметь это как «не указано в методичке» вместо того,
   чтобы додумывать.
3. Кратко сообщи пользователю, что именно извлёк, и уточни неясные места,
   если методичка сама по себе противоречива или расплывчата.

## Если пользователь присылает новую версию методички

Перезапиши `source.*` и полностью пересобери `rules.md` заново — не
дописывай поверх старых правил, чтобы не остались противоречащие друг
другу пункты.
