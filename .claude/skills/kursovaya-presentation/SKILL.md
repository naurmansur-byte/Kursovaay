# Презентация для защиты курсовой

Собирает `.pptx`-презентацию по готовому тексту курсовой. Работает только
от присланного пользователем файла — сама курсовая не пишется в рамках
этого скила (см. `kursovaya-writing`).

## Шаг 0. Проверить требования методички

Загляни в `../metodichka/rules.md`. Если там описаны требования именно к
презентации/защите (обязательные разделы, регламент по времени, число
слайдов, фирменный шаблон вуза) — используй их вместо структуры и правил
ниже. Если в методичке про презентацию ничего нет — работай по умолчаниям
этого скила.

## Шаг 1. Получить исходный файл

Презентация строится по файлу готовой курсовой, который присылает
пользователь (DOCX/PDF/текст) — отдельно на каждый запрос, этот скил сам
файлы курсовой не хранит и не ищет по проекту. Если файла нет — попроси
его прислать, не собирай презентацию по памяти или по `context.md`.

Сохрани присланный файл как `source.<расширение>` в папке `presentation/`
в корне репозитория — на случай, если понадобится пересобрать презентацию
позже.

## Шаг 2. Извлечь суть

Прочитай файл целиком (используй скилы `docx`/`pdf` для извлечения текста,
если формат этого требует) и выдели:
- тему, актуальность, цель и задачи;
- объект и предмет исследования;
- методы (если описаны отдельно);
- по каждой главе — не пересказ, а 2–4 ключевых тезиса/результата;
- общие выводы (по каждой задаче — краткий ответ, как в заключении);
- практическую значимость/рекомендации, если они есть в тексте.

Не выдумывай факты, цифры или выводы, которых нет в присланном файле.

## Шаг 3. Структура слайдов (если методичка не задаёт другую)

1. Титульный слайд — тема, вуз/кафедра, автор, научный руководитель, город/год
2. Актуальность
3. Цель и задачи
4. Объект и предмет исследования
5. Методы исследования (если есть в тексте)
6…N. По 1–2 слайда на главу — только ключевые тезисы и результаты
N+1. Общие выводы
N+2. Практическая значимость/рекомендации (если применимо)
Последний. Слайд «Спасибо за внимание» / вопросы

## Правило количества слайдов

Не меньше 10 и не больше 20. Число подбирай под глубину содержания —
короткую работу не растягивай пустыми слайдами до 20, многослойную не
сжимай ниже 10.

## Правила стиля — соблюдать жёстко

- Белый фон (#FFFFFF), чёрный текст (#000000). Никаких градиентов, тёмных
  подложек, декоративных фонов.
- Один слайд — одна мысль. Короткие тезисы, не сплошные абзацы из курсовой.
- Крупный читаемый шрифт: заголовки от ~28–32 пт, основной текст от
  ~18–20 пт — презентация должна легко читаться комиссией с расстояния.
- Один шрифт на всю презентацию, единая сетка отступов и заголовков на
  каждом слайде.
- Простые графики/таблицы допустимы, только если в курсовой реально есть
  данные, которые стоит показать (например, сравнение показателей). Никакого
  клипарта, эмодзи, теней, лишних рамок и декоративных элементов.

## Как собирать файл

Собирай итоговый `.pptx` через `pptx`-скил этого окружения (python-pptx),
не самописными скриптами. Сохрани результат в
`presentation/kursovaya-presentation.pptx` в корне репозитория.
