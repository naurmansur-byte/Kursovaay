# Написание курсовой работы

Скил только для этого проекта. Хранится в `.claude/skills/kursovaya-writing/` и
виден Claude Code лишь внутри репозитория Kursovaay — в отличие от глобальных
скилов из `~/.claude/skills/`, которые подключаются во всех проектах сразу.

## Перед началом

Загляни в `context.md` рядом с этим файлом — там тема, дисциплина, вуз,
научный руководитель и требования к оформлению. Пока он не заполнен, работай
по разумным умолчаниям (ГОСТ 7.32-2017 для структуры пояснительной записки,
ГОСТ Р 7.0.100-2018 для списка литературы) и уточняй у пользователя то, что
реально влияет на структуру, объём или срок сдачи.

## Типовая структура курсовой

1. Титульный лист
2. Содержание
3. Введение — актуальность, цель, задачи, объект/предмет, методы
4. Основная часть — обычно 2–3 главы, у каждой свои подпункты и вывод
5. Заключение — ответы на задачи, поставленные во введении
6. Список использованных источников
7. Приложения (если есть)

## Как вести проект

- Один файл плана (`plan.md`) — обновляй его по мере согласования структуры
  с научным руководителем.
- Каждая глава — отдельный файл (`chapters/01-vvedenie.md`, `chapters/02-...md`).
  Так в Obsidian видно прогресс по главам и связи между ними в графе.
- Источники — в `sources.md` или отдельными заметками с тегом `#source`, чтобы
  строить обратные ссылки «глава → источник».

## Ограничения

- Не выдумывай факты, статистику или цитаты источников — только то, что дал
  пользователь или что подтверждено загруженными материалами.
- Академическая честность: перефразируй, а не копируй без указания источника.
