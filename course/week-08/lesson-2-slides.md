# Классы и pH
? Как ионы объясняют свойства и кислотность?
↳ Реакцию разобрали. Сравним кислоту, основание и воду.
> 35–45 классы/вода/формулы pH, 45–48 L9, 48–51 ключ.

## Понятие: Классы на языке ионов
CuO + 2H⁺ → Cu²⁺ + H₂O; Cu(OH)₂ + 2H⁺ → Cu²⁺ + 2H₂O.
CO₂ + 2OH⁻ → CO₃²⁻ + H₂O; Cu²⁺ + 2OH⁻ → Cu(OH)₂↓.
2Al + 6H⁺ → 2Al³⁺ + 3H₂↑ — разбавленная неокисляющая кислота.
Нагревание: Cu(OH)₂ → CuO + H₂O; CaCO₃ → CaO + CO₂.
2KClO₃ → 2KCl + 3O₂ при нагревании.
> Соль и кислота реагируют при наличии движущей силы; правило металла не переносить на HNO₃.

## Понятие: Вода и показатель
2H₂O ⇄ H₃O⁺ + OH⁻; вода — слабый амфотерный электролит.
При 25 °C [H⁺][OH⁻] = 10⁻¹⁴; нейтральные концентрации 10⁻⁷.
pH = −lg[H⁺]; при 25 °C кислота < 7, нейтрально 7, щёлочь > 7.
Сильная одноосновная кислота: [H⁺] ≈ c в разбавленном растворе.
Щёлочь: сначала [OH⁻], затем [H⁺] = 10⁻¹⁴/[OH⁻].
> Шкала 0–14 обычная школьная, не абсолютный предел; у слабой кислоты c не равно [H⁺].

# Гидролиз
? Почему соль меняет среду воды?
↳ Кислотность измерили. Объясним её у солей.
> 51–58 четыре типа/первые ступени, 58–61 L10, 61–64 ключ.

## Схема: Четыре типа соли
![Сильные родители: нет гидролиза; слабая кислота: анион/OH⁻; слабое основание: катион/H⁺; Al₂S₃ полностью разлагается](pics/hydrolysis.png)
> Гидролиз — взаимодействие соли с водой; для любых двух слабых родителей среду и полноту безусловно не обобщать.

## Понятие: Первая ступень
NaCl, KNO₃, BaCl₂: сильные родители, нет гидролиза, нейтрально.
CO₃²⁻ + H₂O ⇄ HCO₃⁻ + OH⁻: щелочная среда.
Zn²⁺ + H₂O ⇄ ZnOH⁺ + H⁺: кислая среда.
Fe³⁺ + H₂O ⇄ FeOH²⁺ + H⁺: кислая среда.
Al₂S₃ + 6H₂O → 2Al(OH)₃↓ + 3H₂S↑: полное разложение.
> Средняя соль и нейтральный раствор — разные понятия; проверять заряд обеих сторон.

## Практика: L10

ZnCl₂: Zn²⁺ + H₂O ⇄ ZnOH⁺ + H⁺, кислая, лакмус красный.
> Сначала самостоятельная попытка, затем раскрыть решение.

## Схема: Признаки ионов
![Цвета пламени и осадков таблицы 12; Zn/Al-гидроксиды в избытке щёлочи растворяются](pics/ion-signatures.png)

## Понятие: Реагенты и эффекты
Ag⁺: Cl⁻ белый, Br⁻ желтоватый, I⁻ и PO₄³⁻ жёлтые осадки.
OH⁻: Cu²⁺ голубой; Fe²⁺ зелёный, буреет; Fe³⁺ бурый.
Zn²⁺/Al³⁺: белые студенистые гидроксиды, растворимые в избытке OH⁻.
Ba²⁺ + SO₄²⁻: белый; Ca²⁺ + CO₃²⁻: белый.
Fe³⁺ + роданид: кроваво-красная окраска; PbI₂ жёлтый, Cr(OH)₃ зелёный.
> Cu(OH)₂ и Fe(OH)₃ не растворяются в избытке щёлочи в условиях этой проверки.

## Понятие: Пламя и газы
Na⁺ жёлтое; K⁺ фиолетовое через кобальтовое стекло.
Li⁺ малиновое; Sr²⁺ карминово-красное; Ca²⁺ кирпично-красное; Ba²⁺ жёлто-зелёное.
NH₄⁺ + OH⁻: аммиак; CO₃²⁻ + H⁺: CO₂, мутнит известковую воду.
SO₃²⁻ + H⁺: SO₂; NO₃⁻ с Cu и концентрированной H₂SO₄: бурый газ/голубой раствор.
H⁺ и OH⁻ определяют индикаторами.
> Разбирать описания наблюдений; прямое определение токсичных газов по запаху не проводить.

## Понятие: Углубление A — буфер
Буфер: слабая кислота и её соль либо слабое основание и его соль.
CH₃COO⁻ + H⁺ → CH₃COOH.
CH₃COOH + OH⁻ → CH₃COO⁻ + H₂O.
Небольшая добавка связывается, pH меняется мало; ёмкость ограничена.
Кровь: бикарбонатные, фосфатные и белковые буферные системы.
> Буферная ёмкость характеризует количество добавки для изменения pH; она не бесконечна.

## Понятие: Углубление A — титрование
HCl + NaOH → NaCl + H₂O, отношение 1:1.
c(HCl)V(HCl) = c(NaOH)V(NaOH).
Объёмы использовать в одинаковых единицах.
В эквивалентной точке сильной кислоты/щёлочи pH = 7 при 25 °C.
Кривая pH от объёма имеет резкий скачок около эквивалентности.
> Не переносить равенство без коэффициентов на любую реакцию.

## Понятие: Углубление A — масса ионов
Исходное количество растворённой соли n₀ = cV.
Количество ионов n = m/M.
Для AgNO₃ один Ag⁺ на одну распавшуюся единицу: α = n(Ag⁺)/n₀.
Нужны сведения об отсутствии других источников и потерь иона.
> При другом числе ионов в формуле учесть стехиометрический множитель.

## Понятие: Углубление A — совместный гидролиз
2AlCl₃ + 3Na₂S + 6H₂O → 2Al(OH)₃↓ + 3H₂S↑ + 6NaCl.
2Al³⁺ + 3S²⁻ + 6H₂O → 2Al(OH)₃↓ + 3H₂S↑.
Осадок и газ поддерживают протекание реакции до конца.
Это конкретная пара, не универсальное свойство любых двух солей.
> Уравнение анализировать на бумаге, без проведения опыта.
