# Неделя 17. Расчётный трек — решения

Проверить вместе с вариантом A/B/C после урока 34. Задачи авторские тренировочные; баллы трека учебные и не входят в 34 балла ДЗ. 2 балла — верная модель, ход и ответ; 1 — верная модель и одна вычислительная ошибка; 0 — неверная модель или нет решения. Если задачу не решила половина группы, разобрать её на ближайшем уроке в блоке вопросов.

### Задача 1 — 2 балла

**Ответ:** φ(CH₄) = 60 %.

**Решение:** Для газов объёмы относятся как количества. Пусть V(CH₄) = a, V(H₂) = b: a + b = 10; 2a + 0,5b = 14. b = 10 − a; 2a + 5 − 0,5a = 14; 1,5a = 9; a = 6 л, b = 4 л. φ(CH₄) = 6 : 10 = 60 %.

Типичная ошибка: Взять на H₂ один объём O₂ вместо половины. Коррекция: коэффициенты по кислороду — из уравнений.

### Задача 2 — 2 балла

**Ответ:** Na₂CO₃ 10,6 г и NaHCO₃ 16,8 г.

**Решение:** n(C₃H₈) = 0,1 моль → CO₂ 0,3 моль; NaOH 16 г = 0,4 моль; отношение 1,33 — обе соли. 2x + y = 0,4; x + y = 0,3 → x = 0,1, y = 0,2. Na₂CO₃ 10,6 г; NaHCO₃ 16,8 г.

Типичная ошибка: Взять CO₂ 0,1 моль, забыв три атома углерода. Коррекция: CO₂ — по углероду.
