# Ламарк, Дарвин, формы отбора

- Ламарк (1809): стремление к совершенству, упражнение органов — ошибка.
- Дарвин (1859): изменчивость + борьба за существование + естественный отбор.
- По Дарвину: признак уже был → борьба → выгодный выживает и размножается → доля растёт.
= Движущий — сдвиг; стабилизирующий — среднее; разделительный — крайние
- Внутривидовая борьба самая острая; выживает лучше приспособленный.
- Маскировка — фон; мимикрия — сходство с защищённым; демонстрация — напугать.
- Географическое = аллопатрическое; экологическое = симпатрическое; полиплоидия — сразу.
! Кладограмма: родство — по ближайшему общему узлу, длины ветвей нет.

- Гомологичные — одно происхождение; аналогичные — одна функция; рудимент — у всех, атавизм — у отдельных.
