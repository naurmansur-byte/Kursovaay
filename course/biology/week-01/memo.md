# Узнаём клетку
= Клетка → ткань → орган
- Орган → система органов → организм
- Прокариот: **ДНК есть, оформленного ядра нет**
- Мембрана — обмен; стенка — опора снаружи
- Рибосома — белок; митохондрия — дыхание и АТФ
- Хлоропласт — фотосинтез; крупная вакуоль — тургор
- ЭПС — синтез и перемещение; Гольджи — сортировка и упаковка
! Вирус — неклеточная форма; у растения не каждая клетка с хлоропластами
> Ядро хранит основную часть ДНК эукариотической клетки

# Размер и вещества
= 1 мм = 1000 мкм
- мм → мкм: **×1000**; мкм → мм: **÷1000**
= Размер = шкала × число её длин
- Вода — растворитель многих веществ, среда реакций
- Высокая теплоёмкость — меньше быстрых колебаний температуры
- Испарение воды — отвод тепла
- Fe — гемоглобин; Mg — хлорофилл; Ca — минеральная основа костей
! ×400 — увеличение, не размер; вода — не энергетический запас
> Размер читай по шкале на том же рисунке

# Факты ЕНТ
- Р. Гук (1665) — термин «клетка», срез пробки
- А. ван Левенгук — впервые увидел бактерии и простейших
- М. Шлейден (1838) и Т. Шванн (1839) — клеточная теория
- Р. Вирхов — «Всякая клетка — от клетки», деление
- Д. И. Ивановский (1892) — вирусы, табачная мозаика
- Аппарат Гольджи — имя учёного К. Гольджи
! ДНК может быть в ядре, митохондриях и пластидах; в вакуоли — нет
