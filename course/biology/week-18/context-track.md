15 минут после урока 36. Задание в формате ЕНТ 26–30: прочитай контекст — определительный ключ — и ответь на четыре вопроса, в каждом один верный ответ. Ответы пришли строкой в Telegram вместе с вариантом A/B/C: `К: 1… 2… 3… 4…`. Решения открывай после попытки.

**Как читать опыт:** что меняли → что было одинаковым → контроль → что показали данные → вывод только в пределах данных.

### Контекст

Признаки четырёх организмов.

| Организм | Ядро | Клеточная стенка | Хлоропласты | Запасное вещество |
|---|---|---|---|---|
| 1 | нет | есть | нет | — |
| 2 | есть | из хитина | нет | гликоген |
| 3 | есть | из целлюлозы | есть | крахмал |
| 4 | есть | нет | нет | гликоген |

**1. Один ответ.** К какому царству относится организм 2?

- А) Растения.
- Б) Бактерии.
- В) Животные.
- Г) Грибы.

**2. Один ответ.** Какой организм — бактерия?

- А) 1.
- Б) 2.
- В) 3.
- Г) 4.

**3. Один ответ.** К какому царству относится организм 3?

- А) Грибы.
- Б) Животные.
- В) Растения.
- Г) Бактерии.

**4. Один ответ.** Почему грибы не относят к растениям?

- А) У них нет ядра.
- Б) У них хитин и гликоген, нет хлоропластов.
- В) Они одноклеточные.
- Г) У них нет клеточной стенки.
