# Входная диагностика: основы химии

**Черновик для проверки преподавателем и Claude.** 28 авторских заданий проекта «Химия просто», 40 минут. Это учебная диагностика, а не официальный вариант НЦТ и не прогноз балла ЕНТ. Все задания составлены для этого комплекта; из чужих пробников они не копировались.

Имя: ____________________  Класс: ____________________  Контакт для ответа: ____________________

Другие персональные сведения не нужны. Результат нужен для выбора стартовой практики и подходящей группы; оцениваем текущие навыки, а не способности ученика.

## Перед началом

- Работай самостоятельно, без учебника, поисковика и калькулятора. Можно использовать черновик. Если не знаешь ответ, пропусти задание и вернись к нему позже.
- В задании «один ответ» отметь одну букву. В задании «несколько ответов» отметь **все** правильные буквы; их не менее двух. В соответствии запиши четыре пары, например `1–C, 2–A, 3–D, 4–B`. В каждом таком задании отдельно указано, можно ли повторять буквы.
- На чтение инструкции и финальную проверку оставь 4 минуты. Ориентиры по блокам: 4 + 6 + 5 + 8 + 5 + 8 = 36 минут. Можно распределить время иначе. Через 40 минут прекрати работу.
- **Подсчёт известен заранее:** каждое задание даёт максимум 1 балл, всего 28. Один ответ: 1 за верный, иначе 0. Несколько ответов: 1 за полный верный набор; 0,5, если отмечен хотя бы один верный вариант, пропущены другие верные и не отмечен ни один неверный; иначе 0. Соответствие: по 0,25 за каждую верную пару. Пустой ответ — 0; отрицательных баллов нет. Это собственная система диагностики, не правила оценивания НЦТ.

Относительные атомные массы для расчётов (без единиц): **H = 1; C = 12; N = 14; O = 16; Na = 23; Mg = 24; Al = 27; S = 32; Cl = 35,5; Ca = 40; Fe = 56.** Молярную массу выражай в г/моль, массу — в г, количество вещества — в моль. В расчётных заданиях речь о чистых веществах.
