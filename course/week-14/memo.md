# Алгоритмы недели

- Al: прочитай среду, концентрацию и температуру; проверь плёнку, затем выбери продукт и коэффициенты.
- Вода без плёнки: 2Al + 6H₂O → 2Al(OH)₃ + 3H₂; разбавленные HCl и H₂SO₄ дают соль Al³⁺ и H₂.
- Водная щёлочь: 2Al + 2NaOH + 6H₂O → 2Na[Al(OH)₄] + 3H₂; при сплавлении Al₂O₃ с NaOH образуется NaAlO₂.
- Al³⁺ + 3OH⁻ → Al(OH)₃↓; избыток H⁺ даёт Al³⁺, избыток OH⁻ — [Al(OH)₄]⁻. H₂ при растворении гидроксида не выделяется.
- Комплекс: скобки → центр → лиганды → координационное число → заряд. У однодентатных лигандов число донорных атомов равно числу лигандов.
- K₄[Fe(CN)₆]: Fe(+2), шесть CN⁻, внутренняя сфера 4−, снаружи четыре K⁺; при диссоциации скобки сохраняются.
- Домна: Fe₂O₃ → Fe₃O₄ → FeO → Fe; CO восстанавливает, кокс даёт тепло и CO, CaO связывает SiO₂ в шлак.
- Расчёт: масса чистого вещества → моли → коэффициенты → масса или объём; выход учитывай после теоретического результата.

# Факты ЕНТ недели

- В земной коре Al — третий по распространённости элемент и первый металл; ρ = 2,7 г/см³, t плавления 660 °C; у Al₂O₃ — около 2050 °C.
- Корунд — Al₂O₃; рубин — красная, сапфир — синяя разновидность. Сырьё для Al — бокситы; в Казахстане — Павлодарский алюминиевый завод.
- Холодные концентрированные HNO₃ и H₂SO₄ пассивируют Al. Круг амфотерных оксидов и гидроксидов: Be, Zn, Al, Cr(III).
- При сплавлении со щёлочью образуется NaAlO₂, в водном растворе — Na[Al(OH)₄].
- «Провал» электрона: Cr — 3d⁵4s¹, Cu — 3d¹⁰4s¹. CrO — основный, Cr₂O₃ — амфотерный, CrO₃ — кислотный.
- А. Вернер — 1893 год. Жёлтая кровяная соль выявляет Fe³⁺, красная — Fe²⁺; Cu(OH)₂ голубой, Fe(OH)₂ зеленоватый, Fe(OH)₃ бурый.
- Гематит — Fe₂O₃, магнетит — Fe₃O₄, сидерит — FeCO₃; чугун содержит более 2 % C, сталь — менее 2 % C.
- Гемоглобин содержит Fe, хлорофилл — Mg, витамин B₁₂ — Co; CO образует с гемоглобином карбоксигемоглобин HbCO.
