# Таблица распознавания

- Na → H₂: спирты и фенол.
- NaOH: реагирует только фенол.
- Бромная вода → белый осадок; FeCl₃ → фиолетовый: фенол.
- Cu(OH)₂ без нагревания → ярко-синий раствор: многоатомные спирты.
- Cu(OH)₂ при нагревании → красный Cu₂O: альдегиды.
- Ag₂O (аммиачный), нагрев → серебряное зеркало: альдегиды; кетоны — нет.
= Первичный спирт ⇄ альдегид → кислота; вторичный спирт ⇄ кетон
! Галогеналкан + водная щёлочь → спирт; + спиртовая → алкен (Зайцев).

# Факты ЕНТ недели

- Спирты CₙH₂ₙ₊₁OH; метанол очень ядовит (64,5 °C), этанол — 78,3 °C; водородные связи.
- 2C₂H₅OH + 2Na → 2C₂H₅ONa + H₂; растворы спиртов не меняют индикатор.
- Сильный нагрев → этилен; избыток спирта → диэтиловый эфир.
- Метанол из CO + 2H₂; этанол — брожение и гидратация этилена (H₃PO₄, 7–8 МПа).
- Этиленгликоль — антифриз, лавсан; глицерин — нитроглицерин (сложный эфир).
- Фенол: NaOH — да; кумольный способ → фенол + ацетон.
- Метаналь = формальдегид; этаналь = ацетальдегид; пропанон = ацетон; формалин 35–40 %.
- Фреоны разрушают озон; Монреальский протокол, 1987.
