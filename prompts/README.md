# Задания для агента-исполнителя

Задания пишет Claude, выполняет второй ИИ-агент. Порядок работы описан в [docs/ROADMAP.md](../docs/ROADMAP.md).

## Общие правила для каждого задания

1. Перед работой прочитай `AGENTS.md`, `docs/ROADMAP.md` и файлы, перечисленные в задании.
2. Сохраняй результат по путям, указанным в задании. Тексты — в Markdown в репозитории; версии для учеников и преподавателя (Google Docs / Slides) — в папку проекта на Диске: https://drive.google.com/drive/folders/1qJn6MY58O14n3WTJhJi1coP1HqPbB6u3
3. Всё, что ты сделал, — черновик со статусом «ждёт проверки», пока его не приняли Claude и преподаватель.
4. Если не хватает решения владельца, не придумывай его: оставь пометку `[НУЖНО РЕШЕНИЕ: …]` и внеси вопрос в `STATUS.md`.
5. После работы:
   - обнови строку задания в `STATUS.md` (статус `ждёт проверки Claude`, пути, ссылки на Диск, что проверено, что не получилось);
   - сделай коммит с сообщением `TNN: краткое описание` и отправь его в `main`.
6. Ответь Мансуру коротко: что сделано, где лежит, какие вопросы остались.
