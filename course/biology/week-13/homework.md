Проследи цикл: материнская клетка споры в коробочке → спора → предросток → зелёный гаметофит → яйцеклетка → зигота. Для каждой запиши набор и число хромосом в одном обычном ядре; укажи место мейоза и оплодотворения.

**C10. Фото решения.** Даны два ряда стадий: майский жук — яйцо → личинка → куколка → взрослый жук; богомол — яйцо → личинка → взрослая особь. Назови тип превращения каждого и стадию, которая их различает. Затем расположи этапы раннего развития хордового: гаструла, зигота, бластула, нейрула; укажи, на какой из них появляется нервная трубка.
