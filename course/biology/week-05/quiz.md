## Только преподавателю — отдельный ключ
Отделить перед выдачей; 78–88 минуты урока 10. Q1–Q3 по 1 минуте, Q4 2, Q5 1,5, Q6 3,5 — всего 10. Q1/Q2 факты, Q3 возврат клетки.

Q1 Б: мальтоза. Q2 В: A, D, E, K. Q3 А: лизосомы. По 1 за ровно одну верную букву, иначе 0. Ошибка: конечный продукт вместо промежуточного, группы витаминов, клеточный/органный уровни.

Q4 АБД. 2 точный набор, 1 одна лишняя/пропущенная буква, 0 две ошибки и больше; замена верной неверной — две ошибки, пусто 0. Ворсинки/перистальтика/кровь верны, желчь не фермент, пепсин только начинает, сычуг четвёртый отдел.

Q5 А2 Б4: цинга/рахит. 2 обе пары, 1 одна, 0 ни одной. Пустой пункт или несколько цифр для пункта 0 за него.

Q6: ① амилаза даёт мальтозу; мальтаза далее глюкозу.② пепсин начинает белки до пептидов; окончательное расщепление в тонком кишечнике с трипсином/кишечными ферментами.③ тонкий кишечник, в кровь. По 1 за часть: по 0,5 за каждый из двух её компонентов. Пустая часть 0; противоречащее объяснение не полный балл. Это учебные критерии открытой задачи, Q1–Q5 тестовые. Максимум 1+1+1+2+2+3=10.
