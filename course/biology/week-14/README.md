Первая карточка памятки содержит компактную таблицу всех 64 кодонов: по две семьи из четырёх кодонов в каждой из восьми строк; внутри семьи третье основание идёт в порядке У / Ц / А / Г. Новые числа/последовательности отличаются от образцов. Шесть предупреждений источника и дополнительные границы формулировок отражены преподавателю; первичный учебник с ошибочной таблицей не используется как ключ.
