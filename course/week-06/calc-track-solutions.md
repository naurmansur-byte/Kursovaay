# Неделя 6. Расчётный трек — решения

Проверить вместе с вариантом A/B/C после урока 12. Задачи авторские тренировочные; баллы трека учебные и не входят в 34 балла ДЗ. 2 балла — верная модель, ход и ответ; 1 — верная модель и одна вычислительная ошибка; 0 — неверная модель или нет решения. Если задачу не решила половина группы, разобрать её на ближайшем уроке в блоке вопросов.

### Задача 1 — 2 балла

**Ответ:** ω(Cu) = 45,8 %: в смеси 6,5 г Zn и 5,5 г Cu.

**Решение:** Cu правее водорода и с HCl не реагирует; газ даёт только цинк: Zn + 2HCl → ZnCl₂ + H₂↑. n(H₂) = 2,24 : 22,4 = 0,1 моль = n(Zn). m(Zn) = 0,1 × 65 = 6,5 г; m(Cu) = 12 − 6,5 = 5,5 г; ω(Cu) = 5,5 : 12 = 0,458, то есть 45,8 %.

Типичная ошибка: Делить газ на всю смесь или искать медь по водороду. Коррекция: сначала по ряду активности решить, кто реагирует.

### Задача 2 — 2 балла

**Ответ:** m(Mg) = 4,8 г, m(Fe) = 5,6 г.

**Решение:** Оба металла левее водорода, каждый даёт 1 моль H₂ на 1 моль металла. n(H₂) = 6,72 : 22,4 = 0,3 моль. Пусть n(Mg) = x, n(Fe) = y: x + y = 0,3; 24x + 56y = 10,4. Умножим первое на 24: 24x + 24y = 7,2; вычтем: 32y = 3,2, y = 0,1; x = 0,2. m(Mg) = 0,2 × 24 = 4,8 г; m(Fe) = 0,1 × 56 = 5,6 г; проверка: 4,8 + 5,6 = 10,4 г.

Типичная ошибка: Приписать весь водород магнию: 0,3 × 24 = 7,2 г. Коррекция: два неизвестных — два уравнения, по массе и по газу.
