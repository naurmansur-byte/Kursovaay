# Лист подсчёта входной диагностики

[CSV для Google Таблиц](score-sheet.csv) содержит заголовки и одну пустую строку с формулами. Строка — один ученик: только имя, класс и учебные баллы. Реальные результаты хранить в закрытой таблице; в репозиторий их не добавлять. Уровни описывают стартовую карту знаний, а не прогноз балла ЕНТ.

## Импорт и ввод

1. Создать пустую Google Таблицу. В «Файл → Настройки» выбрать регион **США**, сохранить; использовать английские названия функций. Это нужно для десятичной точки и запятых в формулах CSV. Часовой пояс можно оставить местный.
2. «Файл → Импортировать → Загрузить»: выбрать CSV, разделитель — **запятая**, включить преобразование текста в числа и формулы. Импортировать на новый лист. Если в расчётной ячейке виден текст `=IF…`, проверить эту настройку и повторить импорт.
3. **До ввода результатов** протянуть только диапазон формул **BG2:CH2** вниз на нужное число строк. Ссылки относительные, номер строки должен меняться. Поля A:BF заполнять отдельно; после ввода не копировать чужие баллы вместе с формулами.
4. A — имя, B — класс; C:AD — баллы заданий химии 1–28, AE:BF — биологии 1–28. Вносить уже проверенные преподавателем баллы за задание, а не буквы ответов, проценты или итог формы из 112. При шкале формы ×4 сначала разделить баллы каждого задания на 4.
5. Пустая ячейка означает «ещё не проверено». Проверенный пропуск ученика обозначать **0**. Полный предмет требует 28 числовых оценок; до этого общий балл и уровень пусты. Второй предмет можно проверить позже: он рассчитывается независимо.
6. В этой региональной настройке вводить дроби через точку: `0.25`, `0.5`, `0.75`. Для показа родителю можно применить к числам русский формат после завершения ввода; перед дальнейшим импортом соблюдать исходную настройку. Формулы не округляют суммы и пороги.

Проверка значения встроена в каждую сумму блока. Неподходящая дробь, текст, отрицательный балл или число больше 1 дают **ПРОВЕРЬ БАЛЛЫ**, затем такую же отметку в общем результате. Исправить исходную ячейку; вручную менять формулу или итог не нужно. Формулы рассчитаны на обычные числовые баллы и пустые ячейки.

| Формат задания | Разрешённые баллы | Химия: номера | Биология: номера |
|---|---|---|---|
| Один ответ | 0; 1 | 1, 2, 5, 7, 9, 10, 11, 14, 15, 16, 19, 20, 23, 24, 25, 26 | 1, 2, 3, 5, 6, 8, 10, 12, 14, 15, 19, 21, 22, 24, 25, 27 |
| Несколько ответов | 0; 0,5; 1 | 4, 6, 12, 17, 21, 27 | 7, 11, 16, 17, 20, 26 |
| Соответствие, четыре пары | 0; 0,25; 0,5; 0,75; 1 | 3, 8, 13, 18, 22, 28 | 4, 9, 13, 18, 23, 28 |

Баллы ставить по [ключу химии](teacher.md) и [ключу биологии](../biology/diagnostic/teacher.md). В частности, в нескольких ответах непустое подмножество верных без неверной отметки даёт 0,5; любая неверная отметка — 0. Соответствие: по 0,25 за правильную пару. Лист не проверяет буквы и не заменяет проверку ответа преподавателем.

## Столбцы и блоки

| Блок / номера / максимум | Химия | Балл / уровень | Биология | Балл / уровень |
|---|---|---|---|---|
| 1 / 1–4 / 4 | Математика | BG / BH | Математика | BU / BV |
| 2 / 5–9 / 5 | Частицы и запись | BI / BJ | Клетка | BW / BX |
| 3 / 10–13 / 4 | Валентность | BK / BL | Вещества клетки | BY / BZ |
| 4 / 14–18 / 5 | Уравнивание | BM / BN | Питание | CA / CB |
| 5 / 19–23 / 5 | Классы | BO / BP | Дыхание и транспорт | CC / CD |
| 6 / 24–28 / 5 | Молярная масса и количество вещества | BQ / BR | Схемы и график | CE / CF |
| Общий результат / 1–28 / 28 | Сумма / уровень | BS / BT | Сумма / уровень | CG / CH |

Уровень блока: сначала C при результате ниже 50 % максимума; затем A при результате не ниже 80 %; иначе B. Для максимума 4 сравнивать с 2 и 3,2; для максимума 5 — с 2,5 и 4. Не заменять 3,2 округлённым порогом 3 и не округлять балл ученика.

Общий уровень в обоих предметах определяется строго **C → A → B**:

1. C, если сумма <14 **или** блок 1 <2 **или** блок 2 <2,5.
2. Если первое условие не сработало: A, если сумма ≥22,4 **и каждый блок** не ниже 50 % своего максимума.
3. Иначе B. Уровень ДЗ и стартовую практику уточнить по конкретным ошибкам и объяснению ученика.

## Три контрольных профиля

Профили взяты из таблицы «Общий уровень: C → A → B» в [биологическом ключе](../biology/diagnostic/teacher.md). Максимумы и общие правила химии совпадают, поэтому ожидаемые результаты для обоих предметов одинаковы. Это служебные примеры, не результаты учеников; в CSV нет заполненных личных строк.

| Баллы блоков 1–6 | Сумма | Ожидаемый уровень | Почему |
|---|---:|---|---|
| 3; 4; 3; 4; 4; 4,25 | 22,25 | B | Сумма ниже 22,4; округлять до 22,5 нельзя |
| 3; 4; 3; 4; 4; 4,5 | 22,5 | A | Общий порог достигнут, каждый блок не ниже половины |
| 1,75; 5; 4; 5; 5; 5 | 25,75 | C | Математика ниже 2: первое правило важнее высокой суммы |

Для проверки импорта временно поставить в 28 заданий баллы с нужными суммами по блокам; оценки должны быть разрешены их форматом. После сверки удалить входные значения, сохранив формулы. Быстрый контроль: все 0 → 0/C, все 1 → 28/A; один незаполненный номер → общий результат пустой; 0,5 в одиночном выборе → ПРОВЕРЬ БАЛЛЫ. Проверить оба предмета и новую строку после протягивания.

Переносить в [отчёт родителю](parent-report.md) суммы и уровни вместе с наблюдениями уроков и проверенного ДЗ диагностической недели 20–27 октября. Итоги — 27 октября; не добавлять к сумме входного теста баллы за посещение или ДЗ. Отчёт не содержит обещания балла ЕНТ.

Формулы и контрольные профили проверены локально по правилам ключей. Импорт в реальную Google Таблицу здесь не выполнялся; перед вводом результатов выполнить контроль выше. PDF не собирается.
