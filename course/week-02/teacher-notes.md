# Неделя 2. Заметки преподавателю

**Статус: черновик, ждёт проверки Макса и преподавателя.** Эти заметки сопровождают два плана, конспект, ДЗ и контроль. Предметная проверка преподавателем и испытание темпа на реальной группе ещё не проведены. Объяснения и все задания авторские; тестовый формат не означает происхождения из банка НЦТ.

Главная задача — связать запись состава с проверяемым вычислением. На уроке 3 сначала объясняем заданную валентность, бинарную формулу, относительные массы, массовую долю, замкнутую систему, коэффициенты и два типа реакций. Урок 4 только применяет уже объяснённое: **20 минут повторения + 70 минут ДЗ/практики/контроля**, включая 10-минутный quiz. Все продукты реакций даны; самостоятельное предсказание продуктов не требуется.

## Предметные границы и формулировки

Внутренние ориентиры: Оспанова М. К., Аухадиева К. С., Белоусова Т. Г., «Химия. 8 класс», Мектеп, 2018: §5, с.17–21; §6, с.22–24; §7, с.25–27; §8, с.28; §9, с.31. Сведения о фактическом чтении и проверке по оглавлению находятся в [SOURCES](../../docs/SOURCES.md) и [README недели](README.md); здесь новая дата чтения не заявляется. Текст источника не перепечатываем; исходные термины уточняем для научной точности.

Не вводим электронное строение, степени окисления, классификацию веществ, растворимость, моль/молярную массу, расчёты масс по уравнению, окислительно-восстановительные процессы, замещение или обмен. «Типы реакций» на этой неделе означают только **соединение и разложение**. Для сложных вопросов сохранять формулировку ученика и отмечать будущую тему, не расширять обязательную нагрузку.

| Точка точности | Как говорить и проверять |
|---|---|
| Валентность | В простых бинарных примерах равны произведения индекса на заданную валентность. Значения даны условием; валентность и индекс — разные величины. Не объявлять валентность элемента постоянной для всех веществ. |
| Наименьшие индексы | По данным Ca(II)/O(II) получаем CaO, не Ca₂O₂. Это получение простой формульной записи по условию; не правило для произвольного сокращения заданных молекулярных формул. |
| Aᵣ | Относительное числовое сравнение; использовать справку H 1, O 16, C 12, Mg 24, Al 27, Ca 40, Na 23, Cl 35,5. Без единиц; не масса образца в г. |
| Mᵣ | Сумма N·Aᵣ по одной формуле, без единиц. H₂O — относительная молекулярная масса; MgO, MgCl₂, Al₂O₃, CaO, Na₂O — относительная формульная масса. Коэффициент не входит в Mᵣ одной единицы. |
| ω(E) | Вклад элемента N·Aᵣ(E) делим на всю Mᵣ. N здесь — число атомов по индексу. Для процента умножаем долю на 100%; не смешивать 0,4 с 0,4%. |
| Сохранение массы | Масса **всех** веществ в замкнутой системе сохраняется. Выход газа меняет массу остатка открытого сосуда, но газ не исчезает. Полное превращение и перечень продуктов в массовых задачах даны. |
| Уравнивание | Только коэффициенты перед целыми формулами; проверяем каждый элемент. НОК атомных счётов может помочь, но формулы продуктов уже заданы. Итоговые коэффициенты — наименьшие положительные целые. |
| Соединение/разложение | Считать разные вещества, а не атомы и не коэффициенты. Несколько веществ → одно: соединение; одно → несколько: разложение. |
| Условия реакции | Нагрев, катализатор, свет — заданные условия, не дополнительные коэффициенты. Механизм не изучаем. Реакции обсуждаем на бумаге; домашние опыты с нагревом и газами не назначаем. |

## Частые ошибки и запасные объяснения

| Ошибка/сигнал | Сценарий объяснения | Новый короткий вопрос и ключ |
|---|---|---|
| Валентность автоматически записана своим индексом | Выписать два столбца «валентность / число атомов». Сравнить суммы, а не отдельные числа. | Mg(II), Cl(I): **MgCl₂**, 1·2 = 2·1 = 2. |
| Mg₂O₂ оставлено как простая формула | Найти НОК(2, 2) = 2 и разделить на каждую валентность; либо сократить излишнее отношение 2 : 2 до 1 : 1. | Ca(II), O(II): **CaO**, 1·2 = 1·2. |
| Составляет трёхэлементную формулу по бинарному правилу | Обвести данные формулы, отдельно назвать два элемента в выбранном бинарном задании. CaCO₃ для реакции уже дано. | «Что нужно получать по валентностям: Mg/Cl или уже данную CaCO₃?» — только Mg/Cl, **MgCl₂**. |
| Пропущен индекс в Mᵣ | Таблица «элемент / индекс / Aᵣ / произведение». Сначала считаем по строкам, потом суммируем. | Na₂O: 2·23 + 16 = **62**, без единиц. |
| В Mᵣ включён коэффициент | Разделить «одна формульная запись» и «несколько записанных единиц». | «Mᵣ одной молекулы H₂O в 2H₂O?» — **18**, коэффициент 2 не включаем. |
| К относительной массе приписаны г | Сравнение числа с относительной шкалой отделить от взвешивания образца. Масса образца нужна как отдельное данное. | «Mᵣ(MgCl₂)?» — 24 + 2·35,5 = **95**, без единиц; масса образца не известна. |
| У MgO говорит «молекула» | Числа в сумме сохраняем, исправляем название: относительная формульная масса. | «Как назвать расчёт 40 + 16 для CaO?» — **относительная формульная масса 56**. |
| В числителе доли взял одно Aᵣ без индекса | Обвести выбранный элемент во всей формуле, посчитать все его атомы. | Al₂O₃: вклад O = 3·16 = **48**, Mᵣ = **102**; ω(O) ≈ **47,1%**. |
| Знаменатель содержит только другой элемент | Написать над дробью «часть / целое»; целое включает оба вклада. | MgO: ω(Mg) = 24/(24 + 16) = **0,6 = 60%**. |
| 0,4 названо 0,4% | Подписать «1 = 100%», затем «0,4 = 40%». При записи процента умножаем на 100. | CaO: 16/56 ≈ **0,2857**, или **28,6%**. |
| Закон применяет только к остатку после выхода газа | На бумаге нарисовать границу системы и стрелку выходящего вещества; добавить массу газа к остатку. | «Было 10 г, осталось 5,6 г, других потерь нет. Сколько газа вышло?» — **4,4 г**; остаток + газ = 10 г. |
| Меняет индекс, чтобы сошёлся O | Закрыть внутри рамки всю формулу продукта; место для нового числа только перед рамкой. | Ca + O₂ → CaO: **2Ca + O₂ → 2CaO**, Ca 2 = 2, O 2 = 2. |
| Проверяет только один элемент | Два независимых столбца счёта. После каждого коэффициента пересчитать каждый символ. | Al + O₂ → Al₂O₃: **4Al + 3O₂ → 2Al₂O₃**; Al 4 = 4, O 6 = 6. |
| Называет реакцию разложением из-за большого коэффициента | Считать разные вещества слева/справа, не число их единиц. | H₂ + Cl₂ → 2HCl: **соединение**, два вещества → одно. |
| Считает O₂ второй исходной молекулой при разложении | Разделить две стороны стрелки и подписать «исходное / продукты». | 2H₂O₂ → 2H₂O + O₂: **разложение**, одно вещество → два; H 4 = 4, O 4 = 4. |

Выбрать один-два коротких вопроса по реальной ошибке; вся таблица не назначается как новое ДЗ. Эти примеры заменяют часть коррекции в пределах бюджета, а не увеличивают 150 минут.

## Критерии проверки и обратная связь

Для формулы: **заданные валентности → наименьшие индексы → проверка равенства**. Для относительной массы и доли: **прочитанный состав → произведения N·Aᵣ → сумма → вклад/целое → форма ответа**. Для уравнения: **сохранены все формулы → наименьшие коэффициенты → проверен каждый элемент → тип по числу веществ**. Для массы системы: **граница → полный перечень веществ → сумма с одинаковыми единицами**.

Различать причину ошибки: чтение индекса, выбор алгоритма, арифметика, термин/единица. Верное выражение с ошибкой умножения не означает отсутствия предметного понимания; арифметику всё равно исправляем. Один неверный исходный индекс не считать несколькими независимыми пробелами во всех последующих числах. Критическую подмену формулы при уравнивании отмечать отдельно: даже случайное равенство атомов не решает исходную задачу.

**Выход урока 3:** L6–L8, максимум 8 учебных баллов в [плане](lesson-1-plan.md). По шагам видны формула, относительная масса, доля, коэффициенты и тип. Сумма — обратная связь, не утверждённый норматив уровня. Если нет самостоятельного объяснения, верный ответ с доски не подтверждает освоение.

**ДЗ:** G1–G8 и **один** A/B/C; полные критерии в [решениях](homework-solutions.md). Повторение недели 1: G1/G2 и A1 либо B1 либо C1 — **3 из 12 назначаемых ID, 25%**. Между уроками G1–G3 (15 минут), после урока 4 G4–G8 и выбранный вариант (50 минут).

**Контроль:** Q1–Q6, 10 минут, максимум **13 баллов**, ключ и частичные баллы в [quiz](quiz.md). Сигналы по навыкам: Q1 формула, Q2 Mᵣ/ω, Q3 коэффициенты, Q4 два типа, Q5 масса системы, Q6 неизменность индексов. Ориентир 80% соответствует **11 из 13**, но не отменяет проверки конкретных шагов; это учебный ориентир данного контроля, не балл ЕНТ и не новый порог T02. Повторную проверку делать на новых условиях из преподавательской части quiz или из таблицы выше.

Личная обратная связь: «Получилось: __. Первая ошибка: __. Исправь шаг __; затем реши новый пример __». Ответы учеников и персональные результаты в открытый Git не сохраняем.

## Как выбирать A/B/C

Направленность совпадает с [T02](../diagnostic/teacher.md): **A — углубление при устойчивой базе, B — закрепление конкретных навыков, C — поддержка с короткими шагами**. A не означает самое лёгкое задание и не обещает экзаменационный балл. Учитываем письменный ход и объяснение, не только сумму контроля.

A подходит, если ученик самостоятельно составляет простую формулу, различает Mᵣ и ω, сохраняет индексы при уравнивании и объясняет проверку. B — если алгоритм в целом узнаёт, но допускает отдельные ошибки в индексах, доле или коэффициентах. C — если нужна таблица или разобранный образец и проговаривание одного шага. При нескольких пробелах ученик общей группы B/A может получить C для текущего навыка.

Один вариант — **30 минут**, общая часть — **35 минут**. Замена маршрута делается в пределах этих 30 минут, не назначается второй вариант. Самостоятельный бюджет: **25 + 20 + 65 + 25 + 15 = 150 минут**. Когда ученик не укладывается, записывает последнюю выполненную задачу; учитель сокращает однотипные упражнения и сохраняет необходимые шаги.

## Адаптация, если база почти с нуля

Сохраняем последовательность и 90-минутные таблицы, меняем объём самостоятельных попыток и опору. Все обязательные понятия объясняются на уроке 3, но освоение каждого проверяется отдельно; не переносим пропущенное объяснение в новую лекцию урока 4.

Этот комплект не обещает закрыть все пробелы «с нуля» за два урока.

## Коррекция и повторение в недельном бюджете

**25 минут коррекции:** 5 сравнить собственные шаги с ключом; 10 заново решить максимум две ошибочные задачи с пояснением; 5 выполнить один новый аналог из quiz или таблицы ошибок; 5 записать правило и оставшийся вопрос. При нескольких пробелах сначала чтение индекса и процент, затем формула/баланс. Не требовать весь список повторной проверки каждому.

**15 минут повторения:** 5 воспроизвести алгоритмы по памяти; 5 новая бинарная формула и её относительная масса; 5 один процент или проверка атомов и типа по новому условию. Пример выбирается по реальному пробелу из таблицы выше, ответы раскрываются после попытки. Это повторение тех же навыков, без тем недели 3.

## Что преподаватель проверяет перед выдачей

1. Индексы, заданные валентности, все Aᵣ и вычисления Mᵣ/ω; у относительных масс нет единиц.
2. Правильное название молекулярной/формульной массы; бинарное правило не перенесено на готовые трёхэлементные формулы.
3. Сохранены исходные продукты реакций, совпал счёт каждого элемента; два типа определены по числу веществ.
4. В массовых задачах указана замкнутая система, газ не исчезает, все необходимые данные уже даны.
5. Реальный темп: уроки по 90 минут, урок 4 = 20 + 70, контроль 78–88, итог 88–90; самостоятельная работа 150 минут и один маршрут ДЗ.
6. При выдаче отделены ученические версии от ключей; в презентации раскрытие ответов скрыто до попытки.

Арифметический пересчёт при разработке не заменяет проверку преподавателя и принятие Максом. Создание текста [slides-outline](slides-outline.md) не подтверждает загрузку в Google Slides; реальные результаты передачи отмечаются отдельно в STATUS.md.
