## 5. Привязка к нашей программе

Ниже — методическое распределение источников, предложенное для нашего курса. Точная привязка к параграфам пока готова только для перечисленных разделов 8 класса.

Недели 1–6. База, формулы, классы, моль, расчёты и растворы: учебник 8, § 5–9, 15–19, 40–50. Для самых ранних пробелов дополнить учебником 7 после получения текста. Выход продукта, примеси и сложные смеси требуют дополнительных материалов.

Недели 9–10. Электролиты, ионные уравнения, pH, гидролиз: подобрать разделы 9–11 ЕМН. § 40–41 учебника 8 дают только входную базу по растворам.

Недели 11–12. ОВР и электролиз: подобрать разделы 9–11 ЕМН; необходимы проверенные алгоритмы и разбор исключений.

Недели 13–14. Термохимия: учебник 8, § 22–23. Для кинетики и равновесия подобрать материал 10–11 ЕМН.

Недели 15–20. Неорганика: учебник 8, § 11–14, 24–29, 42–55 как старт; дальнейшая систематика и свойства элементов — после изучения 9–11 ЕМН.

Недели 21–27. Органика: подобрать разделы 9–11 ЕМН по фактическим оглавлениям. Книга 8 класса эту часть курса не закрывает.

Недели 28–29. Комплексные расчёты: собственные подборки по уже пройденным типам задач, с проверкой преподавателем.

Недели 30–32. Итоговая практика: официальный образец, наши варианты по спецификации и журнал индивидуальных ошибок.

## 6. Как из источника сделать урок

Для каждого занятия заполняем карточку: тема → требование спецификации → учебник, издание, параграф → объяснение своими словами → разобранные примеры → самостоятельная работа → домашняя работа → ответы и критерии → типичные ошибки.

Сначала преподаватель проверяет смысл, условия реакций, единицы и решения. Затем материал используется в презентации и заданиях ученика. ИИ помогает подготовить черновик; единственным источником фактов он не служит.

Учебник — основа объяснений, НЦТ — ориентир содержания и формата, собственные проверенные задачи — практика. Публичная загрузка издателем не означает права переиздавать весь учебник в нашем платном курсе; готовим собственные конспекты и указываем источники.
