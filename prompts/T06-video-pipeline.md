# T06. Видеоконвейер и рендер пилота

Начинай после T05 и после того, как Мансур выбрал стиль в T12. Весь вид роликов (цвета, шрифты, субтитры, движение) бери из выбранного стиля в `content/brand/` и держи в одном файле темы.

## Цель

Воспроизводимый способ делать ролики из сценария: одна команда → MP4. Первый результат — три варианта пилота `R001` для выбора стиля.

## Стек (выбран владельцем)

- **Remotion** (React) — анимация и рендер;
- **KaTeX** — формулы;
- **Edge TTS** — русская озвучка для пилота (голоса `ru-RU-SvetlanaNeural` / `ru-RU-DmitryNeural`).

## Прочитай

- `docs/VIDEO_PRODUCTION.md` — разделы 2, 5, 6, 7
- `content/reels/R001-moles-h2so4/` — сценарии из T05
- Актуальную официальную документацию Remotion и выбранного пакета Edge TTS (установка, лицензия)

## Что сделать

1. Проверь условия лицензии Remotion для нашего случая и условия использования Edge TTS для коммерческих публикаций. Итог запиши в `video/README.md`. Если с Edge TTS есть сомнения — внеси вопрос в `STATUS.md` как решение Мансура. Пилот это не блокирует.
2. Создай проект в `video/`:
   - сцены описываются данными (JSON или TS) по сценарию, чтобы следующие ролики делались без правки кода;
   - профиль 1080×1920, 30 кадров/с, H.264 + AAC;
   - оформление — из выбранного стиля T12 (файл темы), без своих цветов и шрифтов;
   - формулы через KaTeX, без растровых картинок формул.
3. Озвучка: сгенерируй аудио из `tts.md`; длительность сцен бери из фактической длины аудио, а не из таблицы. Субтитры — по таймингам слов; они не должны перекрывать формулы.
4. Отрендерь `R001-A`, `R001-B`, `R001-C` в `exports/`. MP4 загрузи на Диск в папку проекта (подпапка «Reels / R001»).
5. Заполни `content/reels/R001-moles-h2so4/review.md` по `docs/QUALITY_CHECKLIST.md`: что проверено и что нет.

## Результат

- `video/` — исходники и `video/README.md` с проверенными командами установки и рендера.
- Три MP4 на Диске, ссылки в `STATUS.md`.
- `content/reels/R001-moles-h2so4/review.md`.

## Критерии приёмки

- Команда из `video/README.md` на чистой копии репозитория воспроизводит рендер.
- MP4 открывается: 1080×1920, 30 кадров/с, звук есть и совпадает с текущим экраном.
- Формулы и индексы читаются с телефона.

## Чего не делать

- Не подключать платные сервисы и не вводить платёжные данные.
- Не коммитить MP4, аудио, ключи и `node_modules` (они уже в `.gitignore`).
- Не публиковать ролики.
